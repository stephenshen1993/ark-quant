# 账户再平衡：使用与验收

更新：2026-10-08。投资规则以[仓位与再平衡规则](../体系/仓位与再平衡规则.md)为准。

## 使用入口

1. **概览**：按账户总资产查看广发35%、华泰25%、平安30%、资金账户10%的目标。券商账户内现金属于该账户；投顾目标为零，已扣账在途单列且只计一次。
2. **账户**：核对六个账户的实际持仓、可用现金、冻结现金及投顾持有余额和确认赎回在途。资金账户可登记其他不可调拨金额，不能重复包括已登记未扣账调拨。证券参考价格沿用当前自动定价流程。
3. **计划**：生成完整计划，查看本次账户间调拨及账户内订单。可用资金不足时按有效缺口比例分配；超过目标的账户仅按本轮补池需求分摊回款，不提前筹集下一轮资金。预计回流与实际到账分开，回款不足时查看剩余缺口。原策略容量、榜单及风控要求不变。

## 已发起调拨

在来源账户展开“已发起调拨与不可用资金”，填写接收账户、金额及是否已从余额扣除。只登记已实际发起的动作，不把计划建议提前登记。

- **尚未扣账**：来源余额仍包含该金额，系统扣除可调拨预算；接收方不重复申请，但不能用于购买。
- **已扣账、尚未到账**：来源余额填扣账后的实际金额，系统单列在途计入总资产一次；接收方仍不能将其用于购买。
- **到账或撤销**：移除来源记录，并更新相关账户实际余额。相关账户全部核对完成后再生成计划，避免将到账余额和在途重复计量。

银证转入须实际到账后才可下单；回款还须核验券商可取状态。系统不自动提交交易、申赎和转账。

## 资金与小额

10%是资金账户的静态目标，动态供款不额外保留10%或固定金额。已到账但冻结、已承诺和不可用的资金不得重复安排。每个账户剩余缺口不足1000元不新增调拨；按比例分配后不足1000元的份额留在资金账户，不二次分配。

账户内费用预留从原预算保留，不额外向资金账户申请；交易取整余款留在原账户，不因超过1000元自动回池。平安内部纳指与501312按2∶1处理，未成交卖单不支持同批买单。

## 旧计划与验证

规则版本和账户事实变化使原计划失效；旧计划仅供历史查询。根据最新事实重新生成，不自动继续执行旧计划。

验证使用内存数据库和隔离浏览器数据，覆盖资金守恒、预算不足、在途防重、冻结与占用、小额门槛、实际可回款约束及页面录入。验证不代表外部资金已经转账或订单已经成交。
