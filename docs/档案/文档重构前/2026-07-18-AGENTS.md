## Common Commands

Set up the local Python environment:

```bash
python3 -m venv .venv
source .venv/bin/activate
python3 -m pip install -r requirements.txt
```

Run the current strategy:

```bash
python3 -m strategies.cb_rotation.run
```

Quick trial with fewer bonds:

```bash
python3 -m strategies.cb_rotation.run --max-universe 30
```

Run with explicit config and current positions:

```bash
python3 -m strategies.cb_rotation.run \
  --config config/cb_rotation.json \
  --positions portfolios/current_cb_positions.csv
```

Run the regression suite:

```bash
python3 -m unittest discover -s tests
```
