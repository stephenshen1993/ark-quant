# 投资记录与绩效口径

> 状态：正式口径真源
> 职责：统一资产类别、策略、账户、金额、外部资金流、累计盈利、分红和绩效比较的业务语义。
> 真源范围：回答“记录的事实是什么、金额如何归属、收益如何比较”。
> 不负责：仓位目标、策略参数、数据库表、API 字段和页面格式。
> 最后复盘：2026-07-18

## 1. 基本原则

- 默认币种为人民币，金额单位为元。
- 账户、策略和资产类别必须分开记录。
- 国别是资产或策略的风险暴露属性。
- 券商、银行和基金平台的真实成交、持仓与余额优先于系统派生结果。
- 计划值、估值值和事实值必须区分。
- 家庭生活资金和生活备用金不进入投资资产口径。

本文定义投资体系中的业务语义，不要求 ark-quant 自建或承载全部记录。当前长期投资账本继续由有知有行投资账本承载，既有三年多手工历史暂不迁移；ark-quant MVP 只接收生成本次资金调拨计划和交易计划所必需的最新事实，不承担成交记账、资金流历史或绩效账本职责。

## 2. 三类概念

| 概念 | 定义 | 示例 |
| --- | --- | --- |
| 资产类别 | 实际持有的投资资产类型 | 股票、可转债、基金、现金 |
| 策略或组合 | 决策和资金归属单元 | 资金调拨策略、小市值股票、多因子可转债、长钱投顾组合 |
| 账户或通道 | 托管、结算和执行位置 | 广发、华泰、雪球基金托管、浦发 |

一个账户未来可以承载多个策略，一个策略也可以跨多个账户执行。新增账户不自动意味着新增策略；只有新增了不同的决策逻辑或资产角色，才需要新增策略或目标金额规则。

## 3. 当前承载关系

| 策略或组合 | 资产类别 | 当前承载通道 | 国别 | 国内再平衡 |
| --- | --- | --- | --- | --- |
| 小市值股票 | 股票 | 广发账户 | 国内 | 是 |
| 多因子可转债 | 可转债 | 华泰账户 | 国内 | 是 |
| 长钱投顾组合 | 基金 | 雪球基金托管 | 国内 | 是 |
| 现金池 | 现金 | 浦发银行 | 国内 | 是 |
| 海外长钱投顾组合 | 基金 | 雪球基金托管 | 海外 | 否 |

当前一一承载时，策略或组合当前金额恰好等于承载账户或通道中的对应金额。未来承载关系变化后，必须按策略归属汇总，不能直接把整个账户当作单一策略。

## 4. 金额定义

| 指标 | 定义 |
| --- | --- |
| 总资产 | 一个账户、策略或组合归属的全部投资资产 |
| 持仓资产 | 当前证券持仓按最新可得价格估算的价值 |
| 可用现金 | 当前可以用于买入或调拨的现金 |
| 冻结现金 | 已属于账户资产但暂时不能使用的现金 |
| 余额 | 没有证券持仓的现金通道金额 |
| 市值 | 单个证券或一组证券持仓按价格估算的价值 |

股票账户：

```text
持仓资产 = Σ(股票股数 x 最新价格)
账户现金 = 可用现金 + 冻结现金
总资产 = 持仓资产 + 账户现金
```

可转债账户：

```text
持仓资产 = Σ(转债张数 x 最新价格)
账户现金 = 可用现金 + 冻结现金
总资产 = 持仓资产 + 账户现金
```

冻结现金计入总资产，但不能用于订单或资金调拨。

## 5. 全体系与国内总资产

全体系总资产：

```text
全体系总资产
= 小市值股票策略当前金额
 + 多因子可转债策略当前金额
 + 长钱投顾组合当前金额
 + 现金池当前金额
 + 海外长钱投顾组合当前金额
```

国内总资产：

```text
国内总资产
= 小市值股票策略当前金额
 + 多因子可转债策略当前金额
 + 长钱投顾组合当前金额
 + 现金池当前金额
```

海外长钱进入全体系总资产，不进入国内再平衡。

## 6. 外部资金流

以下资金流必须独立记录，不能被误算成投资收益或投资亏损：

| 类型 | 含义 | 对投资资产的影响 |
| --- | --- | --- |
| 新增本金 | 从体系外投入的长期投资资金 | 增加投资资产，不是收益 |
| 生活分红 | 将投资成果支付给家庭生活 | 减少投资资产，不是亏损 |
| 个人生产力投入 | 从现金池支付工具、学习、课程或设备 | 减少金融投资资产，不是资本市场亏损 |
| 账户间调拨 | 投资体系内部资金移动 | 不改变全体系总资产和收益 |

外部资金流至少记录日期、金额、类型、用途和事实来源。

外部资金流首先改变现金池和全体系事实，不自动触发 ark-quant 生成资金调拨计划或交易计划。下一次由人发起常态或临时检查时，最新事实自然进入计划计算。生活分红按既定台阶及时支付，与是否同时启动再平衡是两件独立的事。

## 7. 累计盈利与分红台阶

分红判断使用收盘后确认的全体系累计盈利，包含已实现盈利和持仓浮动盈亏。新增本金、生活分红和个人生产力投入必须经过现金流校正，不能因为入金或出金改变资本市场盈利判断。

概念上：

```text
现金流校正后的累计盈利
= 当前全体系投资资产
 + 历史外部流出
 - 历史外部投入本金
```

其中历史外部流出包括已经支付的生活分红和个人生产力投入。具体实现可以使用等价的账户净值或资金流算法，但结果必须保证外部流入、流出不会被误当成投资损益。

分红台阶记录：

```text
台阶间隔 = 25,000 元累计盈利
每个新台阶分红 = 2,500 元
```

系统或记录必须保存已经触发的最高台阶：

- 当前累计盈利首次超过下一个未触发台阶时，触发一次分红。
- 收益回落不撤销已经支付的分红。
- 重新涨回旧台阶不重复触发。
- 累计分红只能说明历史上触发过多少台阶，不能反推出当前盈利。

## 8. 绩效口径

### 8.1 资金加权收益率

资金加权收益率反映个人真实资金投入时点下的投资体验，适合回答“我实际赚了多少、资金使用效果如何”。它会受到入金和出金时点影响。

### 8.2 时间加权收益率

时间加权收益率剔除外部资金流时点的影响，适合评价投资体系自身表现，并与沪深 300 全收益指数进行可比的长期比较。

### 8.3 比较基准

全体系长期比较基准为沪深 300 全收益指数。比较原则：

- 使用包含分红再投资的全收益口径。
- 比较整个体系，不挑选单个高收益账户。
- 优先使用时间加权收益率。
- 关注长期和完整市场周期，不按单年胜负修改战略。
- 最大回撤与回本时间只作为观察指标，不是必须优于基准的硬目标。

## 9. 事实快照

生成一份可复核计划所使用的每类事实，应明确口径日期和更新时间：

- 账户金额快照保存总资产、可用现金、冻结现金或余额。
- 持仓快照保存代码、名称、数量和持仓日期。
- 温度和策略榜单保存数据基准日、来源和版本。
- 同一天可以多次保存事实，不能为了匹配交易计划人为改写事实时间。

这些计划输入快照服务于计算和复核，不等同于长期投资账本。真实成交、历史资金流和绩效继续以券商、银行、基金平台及当前有知有行投资账本中的人工记录为准。

交易计划如何选择事实快照见 [交易执行规则](交易执行规则.md)。
