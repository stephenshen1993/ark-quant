# 仓位与再平衡规则

> 状态：盘点中；结构性共识随讨论确认，具体比例、频率和阈值仍待验证
> 职责：把估值纪律翻译为各策略或组合的目标金额和资金调拨动作。
> 真源范围：国内目标金额、偏离判断、调拨顺序、长钱与海外增量安排。
> 不负责：战略信仰、股票/转债选标的规则、订单取整、API 或页面实现。
> 最后复盘：2026-07-18

## 1. 战术边界

战略层已经确定：市场越低估越增加进攻，市场越高估越保留现金并提高可转债等防守型进攻暴露。战术层需要继续盘清：具体温度来源、映射函数、目标比例、动作阈值、执行频率和摩擦控制。

当前已有公式来自体系形成期的一次经验性设定，尚未经过缜密推导。它不能因为已经写进代码、页面或配置就获得正确性；后续讨论必须从 [投资体系总纲](投资体系总纲.md) 的目标函数和角色约束出发。

## 2. 国内再平衡对象

资金调拨策略控制各策略或组合之间的资金流向，账户只是当前承载与执行通道。

| 国内再平衡对象 | 当前承载通道 | 作用 |
| --- | --- | --- |
| 小市值股票策略 | 广发账户 | 主要进攻核心 |
| 多因子可转债策略 | 华泰账户 | 防守型进攻 |
| 长钱投顾组合 | 雪球基金托管 | 国内基金、偏大盘风格、独立投顾策略 |
| 现金池 | 浦发银行 | 再平衡弹药、调拨中转和执行缓冲 |

海外长钱单独追踪，不进入国内再平衡。家庭生活备用金不属于投资资产。

当前一一承载时，可以用承载通道总资产近似策略或组合当前金额。未来一个账户承载多个策略，或一个策略跨多个账户时，必须按资金归属汇总，不能把账户直接当成策略。

## 3. 当前实现公式快照

> 状态：记录当前工具会如何计算，不代表新的战术共识。

设：

```text
T_raw = 全市场温度，范围 0-100
T_norm = T_raw / 100
国内总资产 = 小市值股票策略当前金额
          + 多因子可转债策略当前金额
          + 长钱投顾组合当前金额
          + 现金池当前金额
```

当前现金目标：

```text
现金池 = 国内总资产 x 20% x T_norm
```

当前非现金目标：

```text
B = 国内总资产 - 现金池

长钱投顾组合 = B x 20%
多因子可转债 = B x 80% x (30% + 0.4% x T_raw)
小市值股票 = B x 80% x (70% - 0.4% x T_raw)
```

2026-07-18 已确认：长钱固定锚定国内总资产的 `15%`，目标不直接随市场温度变化，也不另设比例容忍区间。因此，公式中的 `长钱投顾组合 = B x 20%` 只保留为当前实现事实，不再作为后续战术目标。完整的新公式尚未盘定前，不用局部改动替换现有实现。

当前仍未定型：

- 等权全市场温度首选来源停止维护或口径发生重大变化时，替代来源的切换校准方式。

### 3.1 已确认的中性估值锚点

```text
小市值股票策略 = 国内总资产 x 45%
多因子可转债策略 = 国内总资产 x 30%
长钱投顾组合 = 国内总资产 x 15%
现金池 = 国内总资产 x 10%
```

该锚点只回答“估值处于中性时希望持有什么”，不预先认定当前温度指标的 `50` 必然等于中性，也不决定极端估值下的上下限和映射方式。

中性现金从原候选 `5%` 调整为 `10%`，依据是近十年极端波动压力测试：`5%` 在 2018 年和 2024 年初小盘相对崩跌情景下，无法独立覆盖维持原目标所需的第一阶段股票补仓；`10%` 可以先完成第一阶段，再由相对高配的可转债和长钱分阶段回补。详细记录见 [近十年极端波动与现金池压力测试](../研究/资产配置/近十年极端波动与现金池压力测试.md)。

### 3.2 已确认的极低估值锚点

```text
小市值股票策略 = 国内总资产 x 62%
多因子可转债策略 = 国内总资产 x 20%
长钱投顾组合 = 国内总资产 x 15%
现金池 = 国内总资产 x 3%
```

长钱继续承担固定底仓和风格分散；现金池降至 `3%`，但不降到零：

```text
现金池底线 = 国内总资产 x 3%
```

这 `3%` 是交易、费用、结算和市场继续下跌时的执行缓冲，不是因为看空而保留的防守仓位。它仍按当时国内总资产动态计算，也不阻止现金池超过目标的部分继续调往低估资产。

可转债保留 `20%`，既继续参与上涨，也为小盘继续下跌保留策略分散和第二阶段调拨来源；其余 `62%` 交给小市值股票，明确体现极低估值时提高进攻的纪律。该结构是体系风险预算边界，不是从历史收益中优化出的所谓最优比例。

只有后续盘定的客观估值条件达到极低估值端点时，才允许使用该锚点；不能因主观感觉便宜直接切换，也不代表当前需要立即调仓。

### 3.3 已确认的极高估值基础锚点

```text
小市值股票策略 = 国内总资产 x 25%
多因子可转债策略 = 国内总资产 x 40%
长钱投顾组合 = 国内总资产 x 15%
现金池 = 国内总资产 x 20%
```

相对中性锚点，从小市值股票减少的 `20%` 由可转债和现金各承接 `10%`。现金完成部分利润兑现并提供立即可用的回撤应对资金；可转债降低单一小盘风格暴露但继续参与市场；小市值仍保留 `25%`，长钱继续固定为 `15%`，因此体系不会因高估判断完全退出市场。

这里的现金 `20%` 是估值映射高端的目标锚点，不是现金实际余额不得超过的硬上限。只有后续盘定的客观估值条件达到极高估值端点时，才允许使用该锚点；不能凭主观感觉提前降仓。

该结构是基础锚点而非无条件指令。若多因子可转债策略无法从完整有效的数据中筛出足够合格候选，基础可转债目标按第 3.6 节的可投资性安全阀缩减，未配置金额转入现金。体系不为可转债另建一套市场温度或精密择时模型。

### 3.4 已确认的三锚点映射

设标准化估值状态为 `x`，数值越大表示估值越高：

```text
x = -1：极低估值锚点
x =  0：中性估值锚点
x =  1：极高估值锚点
```

当输入低于 `-1` 或高于 `1` 时，分别按 `-1` 或 `1` 处理，不在端点之外继续外推仓位。

当 `-1 <= x <= 0`：

```text
小市值股票策略 = 国内总资产 × (45% - 17% × x)
多因子可转债策略 = 国内总资产 × (30% + 10% × x)
长钱投顾组合 = 国内总资产 × 15%
现金池 = 国内总资产 × (10% + 7% × x)
```

当 `0 <= x <= 1`：

```text
小市值股票策略 = 国内总资产 × (45% - 20% × x)
多因子可转债策略 = 国内总资产 × (30% + 10% × x)
长钱投顾组合 = 国内总资产 × 15%
现金池 = 国内总资产 × (10% + 10% × x)
```

该映射连续连接极低、中性和极高三个锚点，但允许中性两侧采用不同斜率。目标比例可以随估值连续变化，实际是否交易仍由动作阈值、资金可用状态和执行规则判断；不能把目标变化直接等同于每次都要下单。

### 3.5 已确认的估值输入

体系使用覆盖全部 A 股、以 PE 和 PB 等全市场估值的历史相对位置表达、数值越高表示估值越高的等权全市场温度作为体系级风险锚。等权口径用于反映多数股票的整体体感，降低少数大市值股票对全市场判断的支配。

当前首选数据源为有知有行公开的等权全市场温度，记为 `t`，范围为 `0` 至 `100`：

```text
x = clamp((t - 50) / 50, -1, 1)
```

因此：

```text
t =   0：x = -1，使用极低估值锚点
t =  50：x =  0，使用中性估值锚点
t = 100：x =  1，使用极高估值基础锚点
```

不再叠加单一指数 PE、PB、股债利差或中证1000等指标进行二次精密加工。温度只需要模糊但方向正确地反映 A 股大周期位置，不负责精准解释每个账户、策略、资产类别或风格的独立估值。

数据提供方属于可替换的数据来源，不是战略本身。当前来源停止维护时，可以切换到同样覆盖 A 股全市场、采用等权或能够等价反映多数股票体感、以可比较温度区间表达历史估值位置的可信来源。每次计划必须记录数据日、来源和温度值；同一计划不得混用不同来源。具体切换校准方式仍待盘定。

### 3.6 已确认的可转债可投资性安全阀

安全阀保护的是可转债组合能否按照既定分散和风险过滤安全构造，不判断可转债市场的精确估值，也不引入第二套温度体系。

设：

```text
B0 = 三锚点映射给出的可转债基础目标金额
N  = 数据完整有效时，通过全部硬性风险过滤的合格转债数量
M  = min(N, 20)
```

则：

```text
单只转债目标金额 = B0 / 20
可执行可转债目标金额 = B0 × M / 20
安全阀增加的现金目标金额 = B0 - 可执行可转债目标金额
最终现金目标金额 = 三锚点映射给出的基础现金目标金额 + 安全阀增加的现金目标金额
```

候选不足时，不把 `B0` 重新均分给剩余候选，不提高单只转债目标金额，也不放宽价格、规模、成交额、强赎、正股风险或剩余期限等硬过滤。未配置金额增加现金目标，不增加小市值或长钱目标；可转债无法承接防守型进攻任务时，不能反向提高更激进资产的风险暴露。

单只转债目标金额始终为 `B0 / 20`，即占可转债基础目标金额的 `5%`，低于当前单债 `8%` 上限。候选减少只降低可执行可转债总额，不改变单一发行人相对全体系的目标金额；单债上限的分母不能改为安全阀缩减后的可执行可转债金额。

只有数据日期一致、覆盖完整、关键风险字段有效并成功形成有效榜单时，`N < 20` 才能触发安全阀。数据缺失、过期或运行失败时停止生成计划，不能把“无法确认候选数量”当成 `N = 0`，也不能据此卖出既有转债。

当 `N` 恢复到 `20` 或以上时，可执行目标恢复为基础目标；是否实际补足仍由偏离阈值、资金可用状态和正常检查周期决定。合格候选及 `N` 的策略口径见 [多因子可转债策略规则](../策略/多因子可转债策略规则.md)。

## 4. 偏离口径

```text
偏离金额 = 当前金额 - 目标金额
偏离比例 = 偏离金额 / 国内总资产
目标偏离率 = 偏离金额 / 目标金额
```

正偏离表示相对高配，负偏离表示相对低配。偏离比例用于观察各部分对国内总资产的影响；目标偏离率用于判断某个目标是否需要动作。目标金额属于策略或组合，不属于账户；当前账户金额能够近似目标金额只是因为承载关系暂时一一对应。

资金调拨存在两类可以独立发生、也可以相互加强的成因：

```text
估值变化
-> 标准化估值状态 x 变化
-> 目标占比和目标金额变化
-> 产生目标移动型偏离

各部分涨跌不同步
-> 实际占比变化
-> 即使目标不变也会产生价格漂移型偏离
```

因此，全市场温度不需要精准覆盖每一个策略。某个策略相对下跌时，即使温度和目标占比基本不变，其实际占比下降也会形成低配并推动买入；若同时温度下降、目标占比提高，两类成因会共同扩大低配缺口。上涨时反向成立，由此形成规则化的被动低买高卖。

两类成因都只负责形成目标与偏离，不直接等于交易指令。实际动作仍需通过偏离阈值、资金可用状态、检查频率和执行规则过滤。

## 5. 当前动作阈值

> 状态：形成期规则；结构已经确认，具体数值仍需通过真实执行记录验证。

先把估值引起的目标变化、相对涨跌引起的价格漂移和同一检查周期内的其他目标变化全部合并，计算每个策略或组合相对动态目标金额的最终净调整需求：

```text
计划净调拨金额 = 动态目标金额 - 当前金额
```

当前动作阈值为：

| 调拨对象 | 形成实际调拨动作的条件 |
| --- | --- |
| 小市值股票策略 | 计划净调拨金额绝对值达到 `1000 元` |
| 多因子可转债策略 | 计划净调拨金额绝对值达到 `1000 元` |
| 长钱投顾组合 | 目标偏离率绝对值达到 `5%`，且计划净调拨金额绝对值达到 `1000 元`，见第 8 节 |
| 现金池 | 不单独设置偏离阈值；作为所有调拨的对手方和最终余项 |

阈值按每个策略或组合的最终净额分别判断，不能把不同去向的多笔小额需求相加凑成一次动作。例如股票和转债分别低配 `800 元`时，不能因为合计低配 `1600 元`就分别执行两笔小额调拨。

达到金额阈值只表示该资金调整值得进入执行检查，不代表资金已经可以移动。实际调拨还必须同时满足：

- 资金来源已经通过现金余额、申赎到账或账户内策略订单释放出真实可用资金。
- 资金去向为股票或可转债策略时，能够按对应账户内策略形成至少一笔合规订单；去向为长钱时能够形成合规申购；现金池作为目标去向时不要求生成证券订单。不能把资金调入证券账户后长期留作大额闲置现金。
- 同一策略或组合在同一检查周期只保留一笔净调拨方向，不能先调入再调出。

固定 `1000 元`控制的是少数策略或组合之间的资金移动。调拨对象数量不会随着证券持仓数量增加而同比增长，周度检查也已经限制了动作频率，因此不再叠加“国内总资产的一定比例”。该数值仍属于形成期战术参数，后续根据实际调拨次数、短期反向调拨、未执行偏离和资金闲置记录复盘，不升级为战略常数。

本节阈值只判断策略或组合之间是否形成账户间资金调拨需求，不直接约束账户内证券订单。小市值股票与多因子可转债如何使用已经归属于各自策略的资金，分别服从账户内策略规则和 [交易执行规则](交易执行规则.md)。

## 6. 调拨顺序

资金调拨计划必须表达以下先后依赖：

```text
先释放资金 -> 再调拨 -> 再买入
```

ark-quant MVP 负责把依赖关系写进计划，不跟踪人后来如何执行或记账。

当前判断顺序：

1. 根据温度计算四个国内对象的基础目标金额，再根据有效转债榜单计算可执行可转债目标和最终现金目标。
2. 先检查现金池是否能够补足需要动作的低配对象。
3. 现金不足时，由目标计算后相对高配的小市值或可转债通过卖出或少买释放资金；小盘相对崩跌的典型情形下，通常由高配可转债释放第二阶段资金。
4. 长钱达到其目标偏离阈值时，按平台允许的比例赎回，作为到账更慢的第三阶段资金。
5. 跨账户资金尚未可用时，只执行已经有现金覆盖的部分，不预支后续到账金额。
6. 资金实际可用后，才生成对应阶段的证券买入订单。
7. 海外长钱不作为国内调拨资金来源。

不能在资金尚未释放或到账时假设现金可用，也不能让股票和转债账户各自按独立满仓逻辑运行。

极端行情的默认资金顺序为：

```text
第一阶段：现金池立即执行
第二阶段：卖出相对高配的可转债或股票，跨账户资金可用后继续执行
第三阶段：达到偏离阈值的长钱赎回到账后完成剩余调拨
```

现金池不负责独自完成全部极端调仓；它负责在其他资产受交易、跨账户转账和基金赎回时效约束时，保证第一阶段仍能行动。

## 7. 现金池

现金池同时承担目标仓位、中转账户和执行缓冲：

- 中性估值目标为国内总资产的 `10%`。
- 极低估值下目标降至国内总资产的 `3%` 执行底线，不降到零；该底线不是防守仓位。
- 极高估值基础目标为国内总资产的 `20%`；这是估值映射高端锚点，不是实际余额硬上限。
- 高配时优先补充达到动作阈值的低配对象。
- 低配时由相对高配对象释放资金回补。
- 小幅偏离可以接受，并应保留取整、费用和价格变化所需冗余。
- 个人生产力投入需要综合现金情况、资本市场机会和事项重要性主观判断；资本市场极度低估时，优先取得低估资产。
- 生活分红按照总纲规则触发，一般在收盘确认后从现金池支付。

生产力支出和生活分红是外部资金流，记录口径见 [投资记录与绩效口径](投资记录与绩效口径.md)。

新增长期投资本金、生活分红和个人生产力支出只更新现金池及全体系的最新事实，不直接触发资金调拨计划或账户内交易计划。生活分红仍可按总纲在收盘确认后立即支付，但支付动作本身不等于启动一次再平衡。等人下一次发起常态检查或临时追加检查时，体系再读取更新后的现金池和全体系事实，按同一套目标、阈值和策略规则重新计算；不能因为发生外部资金流就绕过人工触发权自动调仓。

## 8. 长钱投顾组合

长钱投顾组合参与国内再平衡，但不追求精确到元。调拨计划给出方向和目标金额，实际执行按平台最小申赎比例近似。

已经确认的战术结构：

- 固定目标为国内总资产的 `15%`，而不是扣除现金后的非现金资产的一定比例。
- 目标比例不直接随市场温度伸缩，避免把长钱变成择时工具。
- 长钱是相对稳定、允许低频再平衡的国内底仓，不是永久冻结资产。
- 不直接维护固定金额或固定占比区间；每次检查都根据当时国内总资产重新计算动态目标金额。
- 长钱目标偏离率为 `(当前长钱金额 - 动态目标金额) / 动态目标金额`。只有目标偏离率绝对值达到 `5%`，且对应调整金额绝对值达到 `1000 元`，才触发再平衡；等价的金额门槛为 `max(1000 元, 动态目标金额 x 5%)`。`5%` 控制长钱是否参与再平衡，`1000 元`控制本次申赎是否值得执行，两者不能互相替代。`1%` 偏离阈值过窄，`10%` 对低波动投顾组合又偏宽，均不采用。
- 触发低配买入时，原则上申购至动态目标金额；若达不到平台硬性最低申购金额，则本次不执行。
- 触发高配卖出时，以当前长钱持仓的 `1%` 为步长。把 `0%` 和各整数卖出比例都作为候选，选择实际卖出金额最接近目标调整金额的一档。
- 温度变化主要由现金、小市值股票和多因子可转债承担。
- 极度低估时，长钱因其他部分下跌而高于固定目标的部分，可以按上述取整规则赎回并转向低估资产。

长钱不承担明显超额收益预期，也不因短期跑输单独申赎。申赎只响应体系级动态目标金额偏离。

示例：若某次检查计算出的长钱动态目标金额为 `60000 元`，则 `5%` 对应 `3000 元`，当前金额低于或等于 `57000 元`，或高于或等于 `63000 元`时进入申赎检查；实际赎回仍按平台 `1%` 步长取整。若动态目标金额较小，使 `5%` 不足 `1000 元`，则以 `1000 元`作为更高的金额门槛。目标金额会在下一次检查时随国内总资产重新计算，不沿用本例数值。

## 9. 海外长钱增量

海外长钱的国别分散角色属于战略；具体投入规则属于战术。

当前形成期临时做法是：每月新增长期投资本金的 `1/3` 投入海外长钱，其余进入国内体系。该比例是经验性选择，不设战略目标占比，也不因国内外短期强弱临时改变。

## 10. 作战周期

作战周期控制的是“人何时要求体系重新计算”，不改变目标金额、偏离阈值、资金调拨顺序或账户内策略答案。当前采用弹性触发机制：

```text
人决定触发一次常态或临时检查
-> 工具使用同一套体系规则重新计算
-> 生成资金调拨计划和交易计划
-> ark-quant 本次职责结束，由人自行审核和执行
```

常态节奏以大约每周、约每 `5` 个交易日检查一次作为参考，不固定星期，也不要求每个自然周必须完成。节假日、工作安排或其他现实原因可以使检查提前、顺延或跳过；不为了补足形式上的周度次数使用过期数据补做计划。

当市场在较短时间内出现明显非理性暴涨暴跌、风格严重分化或其他值得重新核算的变化时，人可以临时追加一次检查。主观判断只决定“现在是否重新计算”，不能临时改变目标公式、调拨阈值、现金底线、调拨顺序或账户内策略，也不能凭感觉指定计划金额。

常态检查和临时追加检查均使用最近已完成交易日的完整收盘数据生成计划，原则上指导下一个交易日开盘执行，不在盘中反复重算。同一计划必须标记触发类型、临时触发原因、数据日和生成时间；MVP 不跟踪计划最终是否执行或如何执行。

检查触发和计划执行目前都由人掌握。工具只负责快速、可重复地计算资金调拨计划和交易计划，不自动监控市场后触发计划，也不连接券商或基金平台自动下单。人工如何处理计划不进入 ark-quant MVP；下一次检查直接根据届时最新的真实账户、持仓和现金事实重新计算，不接续旧计划状态。

具体输入窗口、订单约束、暂停条件和计划交付边界见 [交易执行规则](交易执行规则.md)。

## 11. 待盘清问题

后续按以下顺序推演：

1. 资金调拨计划与交易计划如何表达资金前置依赖，但不扩展为执行状态管理。
2. 等权全市场温度替代来源的切换校准方式。
3. 公式和形成期动作阈值如何通过历史情景、回测与外部实盘记录验证。
