# 仓位与再平衡规则

> 状态：盘点中；当前公式、比例、频率和阈值均为待验证战术
> 职责：把估值纪律翻译为各策略或组合的目标金额和资金调拨动作。
> 真源范围：国内目标金额、偏离判断、调拨顺序、长钱与海外增量安排。
> 不负责：战略信仰、股票/转债选标的规则、订单取整、API 或页面实现。
> 最后复盘：2026-07-18

## 1. 战术边界

战略层已经确定：市场越低估越增加进攻，市场越高估越保留现金并提高可转债等防守型进攻暴露。战术层需要继续盘清：具体温度来源、映射函数、目标比例、动作阈值、执行频率和摩擦控制。

当前已有公式来自体系形成期的一次经验性设定，尚未经过缜密推导。它不能因为已经写进代码、页面或配置就获得正确性；后续讨论必须从 [投资体系总纲](投资体系总纲.md) 的目标函数和角色约束出发。

## 2. 国内再平衡对象

资金调拨策略控制各策略或组合之间的资金流向，账户只是当前承载与执行通道。

| 国内再平衡对象 | 当前承载通道 | 作用 |
| --- | --- | --- |
| 小市值股票策略 | 广发账户 | 主要进攻核心 |
| 多因子可转债策略 | 华泰账户 | 防守型进攻 |
| 长钱投顾组合 | 雪球基金托管 | 国内基金、偏大盘风格、独立投顾策略 |
| 现金池 | 浦发银行 | 再平衡弹药、调拨中转和执行缓冲 |

海外长钱单独追踪，不进入国内再平衡。家庭生活备用金不属于投资资产。

当前一一承载时，可以用承载通道总资产近似策略或组合当前金额。未来一个账户承载多个策略，或一个策略跨多个账户时，必须按资金归属汇总，不能把账户直接当成策略。

## 3. 当前战术公式快照

> 状态：临时执行参考，待重新推导。

设：

```text
T_raw = 全市场温度，范围 0-100
T_norm = T_raw / 100
国内总资产 = 小市值股票策略当前金额
          + 多因子可转债策略当前金额
          + 长钱投顾组合当前金额
          + 现金池当前金额
```

当前现金目标：

```text
现金池 = 国内总资产 x 20% x T_norm
```

当前非现金目标：

```text
B = 国内总资产 - 现金池

长钱投顾组合 = B x 20%
多因子可转债 = B x 80% x (30% + 0.4% x T_raw)
小市值股票 = B x 80% x (70% - 0.4% x T_raw)
```

这一公式表达了正确的战略方向，但以下内容尚未定型：

- 现金最高 20% 是否合理。
- 长钱占非现金资产 20% 是否合理，以及温度是否应影响长钱比例。
- 小市值和可转债的基准比例与切换斜率是否合理。
- 温度与目标之间是否适合线性映射。
- 极端温度下是否需要上下限或分段响应。

## 4. 偏离口径

```text
偏离金额 = 当前金额 - 目标金额
偏离比例 = 偏离金额 / 国内总资产
```

正偏离表示相对高配，负偏离表示相对低配。目标金额属于策略或组合，不属于账户；当前账户金额能够近似目标金额只是因为承载关系暂时一一对应。

## 5. 当前动作阈值

> 状态：形成期默认值，待结合资产规模、交易成本和执行体验验证。

| 动作 | 当前默认阈值 |
| --- | ---: |
| 股票/转债调拨 | `max(1000 元, 国内总资产 x 0.2%)` |
| 长钱申购/赎回 | `max(3000 元, 国内总资产 x 0.5%)` |
| 现金池偏离 | `max(1000 元, 国内总资产 x 0.2%)` |

公式给出目标锚点，不代表每一元偏离都要执行。阈值以下允许保留误差，避免交易、申赎和心智摩擦。

## 6. 调拨顺序

资金调拨必须服从：

```text
先释放资金 -> 再调拨 -> 再买入 -> 最后写回事实
```

当前判断顺序：

1. 计算四个国内对象的目标金额和偏离。
2. 先检查现金池是否能够补足需要动作的低配对象。
3. 现金不足时，由相对高配的小市值或可转债通过卖出或少买释放资金。
4. 长钱明显高配时，按平台允许的比例赎回并回到现金池。
5. 资金实际可用后，才生成账户内证券买入订单。
6. 海外长钱不作为国内调拨资金来源。

不能在资金尚未释放或到账时假设现金可用，也不能让股票和转债账户各自按独立满仓逻辑运行。

## 7. 现金池

现金池同时承担目标仓位、中转账户和执行缓冲：

- 高配时优先补充达到动作阈值的低配对象。
- 低配时由相对高配对象释放资金回补。
- 小幅偏离可以接受，并应保留取整、费用和价格变化所需冗余。
- 个人生产力投入需要综合现金情况、资本市场机会和事项重要性主观判断；资本市场极度低估时，优先取得低估资产。
- 生活分红按照总纲规则触发，一般在收盘确认后从现金池支付。

生产力支出和生活分红是外部资金流，记录口径见 [投资记录与绩效口径](投资记录与绩效口径.md)。

## 8. 长钱投顾组合

长钱投顾组合参与国内再平衡，但不追求精确到元。调拨计划给出方向和目标金额，实际执行按平台最小申赎比例近似。

长钱不承担明显超额收益预期，也不因短期跑输申赎。其具体目标比例属于本轮战术盘点的重要待决问题。

## 9. 海外长钱增量

海外长钱的国别分散角色属于战略；具体投入规则属于战术。

当前形成期临时做法是：每月新增长期投资本金的 `1/3` 投入海外长钱，其余进入国内体系。该比例是经验性选择，不设战略目标占比，也不因国内外短期强弱临时改变。

## 10. 作战周期

当前形成期默认做法是每周选择一个有时间的盘后或次日盘前窗口检查一次，完成后当周原则上不追加盘中操作。周度、月度、偏离触发或混合方式均尚未完成比较，不能把当前频率视为最终战术。

具体输入窗口、订单约束、暂停条件和执行后写回见 [交易执行规则](交易执行规则.md)。

## 11. 待盘清问题

后续按以下顺序推演：

1. 长钱是否保持相对稳定比例，以及它与温度的关系。
2. 中性估值下小市值、可转债、长钱和现金的基准关系。
3. 极低、极高估值下各对象的上下限。
4. 温度映射采用线性、分段还是其他方式。
5. 再平衡采用固定检查、偏离触发还是混合机制。
6. 动作阈值如何覆盖真实摩擦成本。
7. 跨账户结算和多日调拨如何表达。
8. 公式如何通过历史情景、回测与实盘记录验证。
