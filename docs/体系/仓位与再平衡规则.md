# 仓位与再平衡规则

> 状态：当前真源 v2026-08；资金调拨与再平衡手册
> 职责：把投资体系总纲中的估值纪律和 A/B/C 组合职责翻译为目标金额、偏离判断、资金调拨和现金池行为。
> 真源范围：全体系顶层 A/B/C 目标、A 组合内部目标、偏离阈值、半带宽修复、可执行预算、现金池边界、B/C 执行约束和检查节奏。
> 不负责：战略信仰、账户内选标的规则、证券订单取整、API、数据库、页面展示或自动下单。
> 最后核对：2026-08-05

## 1. 规则边界

本文件只回答“长期投资资产应当分到哪里、偏离到什么程度才动作、资金如何通过现金池流转”。战略目标、长期信念和概念边界以 [投资体系总纲](投资体系总纲.md) 为准；账户内买卖规则见 [交易执行规则](交易执行规则.md)、[小市值股票策略规则](../策略/小市值股票策略规则.md) 和 [多因子可转债策略规则](../策略/多因子可转债策略规则.md)。

代码、配置、API、数据库和页面只描述工具事实。它们与本文件冲突时，应登记到实现差距，而不能反向修改当前真源。口径状态分类见 [当前真源 v2026-08 口径台账与分类规则](../工程/口径台账/2026-08-当前真源口径台账与分类规则.md)。

家庭生活备用金不属于投资资产。A、B、C 加总构成本规则计算的全部长期投资资产。

## 2. 父子层级

全体系先按职责划分为三个顶层组合，再在 A 组合内部区分账户内策略和现金池。顶层组合不是账户、资产类别，也不是把账户重新命名为策略。

| 层级 | 对象 | 当前构成 | 当前承载/执行结构 | 规则含义 |
| --- | --- | --- | --- | --- |
| 顶层组合 | A：自主管理组合 | 小市值股票策略、多因子可转债策略、现金池 | 广发账户、华泰账户、资金账户/银行现金 | 核心进攻与主动超额来源 |
| 顶层组合 | B：海外长钱组合 | 海外基金投顾组合 | 当前基金托管通道 | 海外长期收益、国别与货币分散、第二收益来源 |
| 顶层组合 | C：国内长钱组合 | 国内基金投顾组合 | 当前基金托管通道 | 国内长钱底仓、偏大盘风格补充、可信投顾托管 |
| A 内部 | 小市值股票策略 | A 股小市值股票 | 广发账户 | A 组合下属策略，不是与 A 并列的顶层组合 |
| A 内部 | 多因子可转债策略 | 可转债 | 华泰账户 | A 组合下属策略，不是与 A 并列的顶层组合 |
| A 内部 | 现金池 | 可转账现金和执行缓冲 | 资金账户/银行现金 | A 组合下属现金目标，同时承担全体系调拨中转 |

当前一一承载时，可以用承载通道总资产近似策略或组合当前金额。未来一个账户承载多个策略，或一个策略跨多个账户时，必须按资金归属汇总，不能把账户直接当成策略或组合。

因此，资金调拨计算和展示必须保持两层结构：

```text
全体系
-> A 组合、B 组合、C 组合
-> A 组合内部再展开为小市值股票、可转债、现金池
```

主动组合和广发、华泰、资金账户是父子关系，不是并列关系。任何表格、计划或说明都不能把 A 组合与其下属账户摆在同一个“账户/组合”维度中求和。

## 3. 估值输入

体系使用覆盖全部或绝大多数 A 股、按个股等权或以中位数等方式等价反映多数股票体感、以全市场估值的历史相对位置表达且数值越高表示估值越高的温度作为体系级风险锚。该口径用于降低少数大市值股票对全市场判断的支配。

当前首选数据源为有知有行公开的等权全市场温度，记为 `t`，范围为 `0` 至 `100`。同一个 `t` 同时进入顶层 A/B/C 映射和 A 组合内部映射：

```text
x = clamp((t - 50) / 50, -1, 1)
```

代表含义：

```text
t =   0：x = -1，使用极低估值锚点
t =  50：x =  0，使用中性估值锚点
t = 100：x =  1，使用极高估值基础锚点
```

不再叠加单一指数 PE、PB、股债利差或中证 1000 等指标进行二次精密加工。温度只需要模糊但方向正确地反映 A 股大周期位置，不负责精准解释每个账户、策略、资产类别或风格的独立估值。

数据提供方属于可替换来源，不是战略本身。替代来源需要同时满足：

- 覆盖全部或绝大多数 A 股，而不是以单一市值加权指数代替全市场。
- 按个股等权，或以中位数等方法等价反映多数股票的估值体感。
- 表达全市场估值在长期历史中的大致相对位置，方向为数值越低越便宜、越高越昂贵。
- 来源可信、口径基本透明并能持续更新。

换源属于低频人工治理动作，不建立多来源平均、投票或自动故障转移。正常状态只有一个主来源，同一计划不得混用不同来源。来源短期未更新时，本次估值驱动检查等待来源恢复；只有确认来源长期不再更新、口径发生重大变化或信任基础变化时，才由人启动换源审查。

新来源经人工确认后，从下一次正常检查开始直接使用其 `0` 至 `100` 温度，不追补来源失效期间的动作，不回溯重算，不人为平滑，也不因旧来源恢复而自动切回。每次计划必须记录数据日、来源和温度值；发生换源时另行记录原来源、新来源、切换原因、生效日期、新来源口径概要和切换时可信来源所处的大致估值区间。

## 4. 顶层 A/B/C 目标

设：

```text
u = clamp(t / 50, 0, 1)
V = A、B、C 当前金额之和，即全体系长期投资总资产
```

顶层目标占比为：

```text
A 组合目标占比 = 70% - 5% × u
B 组合目标占比 = 15% + 5% × u
C 组合目标占比 = 15%
```

目标金额为：

```text
A 组合目标金额 = V × A 组合目标占比
B 组合目标金额 = V × B 组合目标占比
C 组合目标金额 = V × C 组合目标占比
```

代表性位置：

| 全市场温度 | A 组合 | B 组合 | C 组合 |
| ---: | ---: | ---: | ---: |
| `0` | `70%` | `15%` | `15%` |
| `10` | `69%` | `16%` | `15%` |
| `20` | `68%` | `17%` | `15%` |
| `30` | `67%` | `18%` | `15%` |
| `40` | `66%` | `19%` | `15%` |
| `50-100` | `65%` | `20%` | `15%` |

`70/15/15` 是 A 股极低估值下允许提高 A 组合进攻权重的上边界；`65/20/15` 是温度达到中性及以上时的常态中心。B 不因 A 股温度高于 `50` 而继续机械增加，因为“A 股更贵”不能推出“海外更便宜”；A 组合内部会继续通过提高可转债和现金比例降低进攻暴露。

当 A 低于动态目标时，新增长期投资本金可以优先补 A；当 A 已达到或超过 `70%` 时，不能借“砸锅卖铁”之名无限挤压 B、C。当前持仓占比只用于计算偏离，不能因为 A 过去表现较好、自然漂移到某个比例，就把该比例直接确认为目标。

## 5. A 组合内部目标

A 组合内部由小市值股票策略、多因子可转债策略和现金池构成。三者是 A 的下属结构，其目标金额之和应当等于本次使用的 A 金额基数。

### 5.1 三个估值锚点

A 组合内部沿用股票、可转债和现金风险预算，并从旧国内四部分结构中剔除固定 `15%` 的国内长钱后，按剩余 `85%` 归一化：

| A 股估值状态 | 小市值股票策略 | 多因子可转债策略 | 现金池 |
| --- | ---: | ---: | ---: |
| 极低 | `62 / 85`，约 `72.94%` | `20 / 85`，约 `23.53%` | `3 / 85`，约 `3.53%` |
| 中性 | `45 / 85`，约 `52.94%` | `30 / 85`，约 `35.29%` | `10 / 85`，约 `11.76%` |
| 极高 | `25 / 85`，约 `29.41%` | `40 / 85`，约 `47.06%` | `20 / 85`，约 `23.53%` |

极低估值时现金目标仍不降到零；它用于交易、费用、结算、市场继续下跌时的执行缓冲和不同承载通道之间的流动性桥接，不是因为看空而保留的防守仓位。中性现金锚点和新结构资金链的依据见 [近十年极端波动与现金池压力测试](../研究/资产配置/近十年极端波动与现金池压力测试.md) 与 [全体系仓位与资金链压力测试](../研究/资产配置/全体系仓位与资金链压力测试.md)。

### 5.2 连续映射

当 `-1 <= x <= 0`：

```text
小市值股票策略占 A = (45% - 17% × x) / 85%
多因子可转债策略占 A = (30% + 10% × x) / 85%
现金池占 A = (10% + 7% × x) / 85%
```

当 `0 <= x <= 1`：

```text
小市值股票策略占 A = (45% - 20% × x) / 85%
多因子可转债策略占 A = (30% + 10% × x) / 85%
现金池占 A = (10% + 10% × x) / 85%
```

分式中的分子与分母都是比例，例如 `45% / 85% = 52.94%`。映射连续连接 A 组合内部的三个锚点，并允许中性两侧使用不同斜率。

### 5.3 理想目标与可执行目标

观察全体系理想结构时：

```text
小市值股票策略理想目标金额 = A 组合目标金额 × 小市值股票策略占 A
多因子可转债基础理想目标金额 = A 组合目标金额 × 多因子可转债策略占 A
现金池基础理想目标金额 = A 组合目标金额 × 现金池占 A
```

全体系理想目标只用于判断顶层偏离，不直接作为 A 内部周度计划的预算。A 内部可执行预算使用已经成为事实的 A 组合当前金额，并扣除本次已经批准的 A 净调出：

```text
A_current = 计划输入时已经成为事实的 A 组合当前金额
Delta_A   = 本次部分可执行顶层方案中 A 的调整金额；调入为正，调出为负
Q_out     = max(0, -Delta_A)，即 A 在本次顶层方案中的净调出金额
A_exec    = A_current - Q_out
```

本次 A 内部可执行目标为：

```text
小市值股票策略可执行目标金额 = A_exec × 小市值股票策略占 A
多因子可转债可执行基础目标金额 = A_exec × 多因子可转债策略占 A
现金池可执行基础目标金额 = A_exec × 现金池占 A
```

没有触发顶层调出时，`Q_out = 0`，A 内部按 A 当前实际金额配置，不能用 A 理想目标较低为由在周度检查中暗中提前执行季度卖出。A 为净调入时，B、C 尚未到账的计划赎回不增加 `A_exec`；资金真实进入现金池后，已经自然包含在下一次计划的 `A_current` 中。

`Q_out` 使用 A 在顶层部分可执行方案中的净变化，不能把同一方案中 B、C 的调入和调出分别当作两次 A 预算变化。A 向 B、C 的实际申购只能使用当时真实可用现金；若需要先卖出 A 内证券释放资金，本次只生成相应卖出，待资金真实可用后由下一次计划重算。

### 5.4 可转债可投资性安全阀

安全阀保护的是可转债组合能否按照既定分散和风险过滤安全构造，不判断可转债市场的精确估值，也不引入第二套温度体系。

设：

```text
B0 = 本次使用的 A 组合金额基数 × 可转债占 A 比例
N  = 数据完整有效时，通过全部硬性风险过滤的合格转债数量
M  = min(N, 20)
```

观察全体系理想目标时，A 组合金额基数使用 A 理想目标金额；生成 A 内部可执行计划时，使用 `A_exec`。现金基础目标采用同一个金额基数，不能在同一份计划中混用理想 A 与可执行 A。

则：

```text
单只转债目标金额 = B0 / 20
可执行可转债目标金额 = B0 × M / 20
安全阀增加的现金目标金额 = B0 - 可执行可转债目标金额
最终现金目标金额 = A 组合内部映射给出的基础现金目标金额 + 安全阀增加的现金目标金额
```

候选不足时，不把 `B0` 重新均分给剩余候选，不提高单只转债目标金额，也不放宽价格、规模、成交额、强赎、正股风险或剩余期限等硬过滤。未配置金额增加现金目标，不增加小市值、B 或 C 的目标；可转债无法承接防守型进攻任务时，不能反向提高更激进资产的风险暴露。

只有数据日期一致、覆盖完整、关键风险字段有效并成功形成有效榜单时，`N < 20` 才能触发安全阀。数据缺失、过期或运行失败时停止生成计划，不能把“无法确认候选数量”当成 `N = 0`，也不能据此卖出既有转债。合格候选及 `N` 的策略口径见 [多因子可转债策略规则](../策略/多因子可转债策略规则.md)。

## 6. 偏离口径

顶层偏离只在 A/B/C 之间计算：

```text
顶层组合偏离金额 = 顶层组合当前金额 - 顶层组合目标金额
顶层组合偏离比例 = 顶层组合偏离金额 / 全体系总资产
```

A 内部偏离只在小市值股票、可转债和现金池之间计算：

```text
A 内部可执行偏离金额 = 策略或现金当前金额 - A 内部可执行目标金额
A 内部可执行偏离比例 = A 内部可执行偏离金额 / A_exec

目标偏离率 = 偏离金额 / 目标金额
```

正偏离表示相对高配，负偏离表示相对低配。顶层先判断 A、B、C 相对全体系理想目标的偏离，A 内部再判断小市值、可转债和现金相对本次 `A_exec` 的偏离，两层不能混用分母。目标金额属于策略或组合，不属于账户；当前账户金额能够近似目标金额只是因为承载关系暂时一一对应。

任一次计算都必须同时满足两层守恒：

```text
A、B、C 目标金额之和 = 全体系总资产
A、B、C 当前金额之和 = 全体系总资产

小市值、可转债、现金可执行目标金额之和 = A_exec
小市值、可转债、现金当前金额之和 = A 组合当前金额
```

当 `Q_out = 0` 时，A 内部当前金额和可执行目标金额都加总为 A 当前金额。已经批准顶层调出时，两者的差额恰好是 `Q_out`，该差额用于形成必要卖出或现金调出，而不是会计错误。顶层未执行偏离继续保留为现实偏离，不能通过改用 A 理想目标金额把它伪装成已经再平衡。

资金调拨存在两类可以独立发生、也可以相互加强的成因：

```text
估值变化
-> 顶层 A/B 目标和 A 内部目标同时变化
-> 产生目标移动型偏离

各部分涨跌不同步
-> 实际占比变化
-> 即使目标不变也会产生价格漂移型偏离
```

两类成因都只负责形成目标与偏离，不直接等于交易指令。实际动作仍需通过偏离阈值、资金可用状态、检查频率和执行规则过滤。

## 7. 动作阈值

顶层采用“月度软偏离修复、季度硬偏离卖仓”的非对称机制。新增本金可以持续纠偏，但只有越过顶层硬偏离范围，才允许为了再平衡卖出或赎回老仓。A 组合内部继续使用独立的周度形成期阈值，两层不能混用。

### 7.1 A 内部周度阈值

先把估值引起的目标变化、相对涨跌引起的价格漂移和同一检查周期内的其他目标变化全部合并，计算每个策略或现金池相对动态目标金额的最终净调整需求：

```text
完整净调整缺口 = 动态目标金额 - 当前金额
```

当前动作阈值为：

| A 组合内部对象 | 形成实际调拨动作的条件 |
| --- | --- |
| 小市值股票策略 | 完整净调整缺口绝对值达到 `1000 元` |
| 多因子可转债策略 | 完整净调整缺口绝对值达到 `1000 元` |
| 现金池 | 不单独设置偏离阈值；作为所有调拨的结算对手方和实际资产的最终余项 |

阈值按每个对象的最终净额分别判断，不能把不同去向的多笔小额需求相加凑成一次动作。例如股票和转债分别低配 `800 元` 时，不能因为合计低配 `1600 元` 就分别执行两笔小额调拨。

完整净调整缺口用于判断该对象是否进入执行检查，不等于本次必然调拨的金额。本次调拨金额还会受真实可用资金、现金保留目标、其他有效缺口和最小可执行动作限制。

固定 `1000 元` 控制的是 A 组合内部少数策略之间的资金移动。该数值仍属于形成期战术参数，后续根据实际调拨次数、短期反向调拨、未执行偏离和资金闲置记录复盘，不升级为战略常数。

本节阈值只判断 A 组合内部是否形成账户间资金调拨需求，不直接约束账户内证券订单。小市值股票与多因子可转债如何使用已经归属于各自策略的资金，分别服从账户内策略规则和 [交易执行规则](交易执行规则.md)。

### 7.2 顶层软偏离：月度新增本金修复

每月由人决定是否发起一次增量分配检查。新增本金进入现金池只更新事实，不自动触发计划；触发后使用当时最新温度、全体系金额和可执行约束重算。

软偏离不设比例免动作区间：

- A 低配时，新增本金留在 A，并按 A 内部可执行目标使用；B 或 C 低配时，可以从现金池申购相应组合。
- 多个顶层组合同时低配时，原则上按各自有效低配缺口占全部有效低配缺口的比例分配。
- 单个实际分配金额不足 `1000 元` 时跳过；比例分配后无法形成合规动作时，按目标偏离率由低配最严重到最轻分配。
- 软偏离只使用已经真实到账的新增本金和可用现金，不为了月度修复卖出任何 A、B、C 老仓。
- QDII 限购、暂停申购或其他约束使 B 无法执行时，保留 B 的低配事实，不先卖出资金来源，也不购买未经审查的替代产品。其他组合没有合理去向时，剩余资金留在现金池，但不标记为 B 专属待投资金。

### 7.3 顶层硬偏离：季度卖仓触发线

设顶层组合 `i` 的目标占比、当前占比、偏离和外侧带宽分别为：

```text
w_i = 顶层动态目标占比
p_i = 顶层当前占比
d_i = p_i - w_i
h_i = min(3 个百分点, w_i × 10%)
```

已确认的外侧允许范围为：

| 动态目标 | 外侧允许范围 |
| --- | --- |
| A = `65%` | `62%-68%` |
| A = `70%` | `67%-73%` |
| B = `15%` | `13.5%-16.5%` |
| B = `20%` | `18%-22%` |
| C = `15%` | `13.5%-16.5%` |

季度检查使用已经发生的月度修复和当时真实资产，不预估未来新增本金：

- 所有组合都满足 `|d_i| <= h_i` 时，不卖老仓，实际偏离继续保留。
- 任一组合满足 `|d_i| > h_i` 时，才允许启动顶层部分再平衡；触发条件使用严格大于，恰好位于外侧线不动作。
- 低配去向因 QDII 限购或其他约束无法执行时，不为该去向先卖出高配组合；但一个去向受限不能自动取消其他本来可以执行的低配修复。
- B 的申购限制只阻止 B 的申购动作，不阻止符合规则的 B 赎回，也不改变 A、C 各自原本的理想修复金额。
- 顶层卖仓触发后，实际资金仍服从现金池星型调拨、真实可用资金和平台申赎颗粒度，不建立组合间直接调拨。

### 7.4 触发后的半带宽修复

顶层越过外侧线后，不一次回到目标中心，也不只停在容易再次越线的外侧边界，而是把偏离同比例收缩到半带宽以内。设：

```text
r = min{ h_i / (2 × |d_i|) | d_i != 0 }

修复后占比 p'_i = w_i + r × d_i
```

因为至少一个组合已经越过外侧线，所以 `0 < r < 0.5`。三个偏离使用同一个 `r`，修复后占比仍加总为 `100%`，且所有组合都进入各自半带宽以内。

代表性修复区间为：

| 动态目标 | 外侧触发线 | 修复后进入 |
| --- | --- | --- |
| A = `65%` | `62%-68%` | `63.5%-66.5%` |
| A = `70%` | `67%-73%` | `68.5%-71.5%` |
| B = `20%` | `18%-22%` | `19%-21%` |
| B 或 C = `15%` | `13.5%-16.5%` | `14.25%-15.75%` |

半带宽公式先生成不考虑申购限制的完整理想方案。设组合 `i` 的理想调整金额为：

```text
Delta_i = (p'_i - p_i) × V
```

`Delta_i > 0` 表示理想调入，`Delta_i < 0` 表示理想调出。某个低配去向本次不能买入时，按以下规则得到部分可执行方案：

1. 删除该去向的调入动作，目标、理想缺口和完整理想方案仍照常展示。
2. 其他能够执行的低配去向最多保留各自在完整理想方案中的原调入金额；不能把受限去向跳过的金额额外分给其他组合。
3. 把完整理想方案中的高配调出金额按原比例同步缩小，使实际计划调出总额恰好等于剩余可执行调入总额；任何来源都不能超过其原理想调出金额。
4. 删除受限去向后没有其他可执行调入时，本次顶层调出全部归零，不能为了形式上降低高配而把资金先堆进现金池。
5. 部分执行后的剩余偏离如实保留；下一次检查仍从最新真实金额完整重算，不接续本次被删除的调入动作。

这套处理不重新归一化 A/B/C 目标，也不把 B 的渠道限制变成 A 的额外进攻授权。它只回答本次完整理想方案中哪些动作真正能够同时成立。完整理想方案、部分可执行方案和执行后仍会保留的偏离必须同时展示，避免把执行约束伪装成目标变化。

## 8. 资金调拨与现金池

资金调拨只保留以现金池为中心的星型关系：

```text
A 内部小市值股票当前承载通道 <-> 现金池
A 内部可转债当前承载通道 <-> 现金池
B 组合当前承载通道 <-> 现金池
C 组合当前承载通道 <-> 现金池
```

现金池在归属上属于 A 组合，同时承担全体系调拨中转通道。买入 B、C 会使 A 中的现金和 A 总金额同步减少，赎回 B、C 到账会使 A 中的现金和 A 总金额同步增加；这正是顶层 A/B/C 之间的资金移动，不需要再虚构一个独立于三个组合之外的第四部分。

不建立“可转债直接调往小市值”“B 直接调往 A”之类的直连关系，也不追踪现金的来源归属。某笔现金是原有余额、证券卖出所得、基金赎回到账还是新增长期投资本金，不改变下一次计划的计算。计划只使用届时已经成为事实的账户、持仓和现金金额。

### 8.1 现金池目标状态

现金池同时承担目标仓位、中转账户和执行缓冲：

- 观察理想结构时，现金基础目标是 A 理想目标金额乘以现金占 A 比例；生成计划时，改用 `A_exec` 乘以该比例。不能直接以旧的国内总资产为分母，也不能在同一计划中混用两种 A 金额基数。
- 极低、中性、极高估值时，现金分别约占 A 组合的 `3.53%`、`11.76%`、`23.53%`；按对应顶层 A 目标折算，分别约占全体系的 `2.47%`、`7.65%`、`15.29%`。
- 可转债候选不足触发安全阀时，无法配置的金额在 A 内部继续增加现金目标，因此真实目标可能高于上述基础值。
- 极低估值下现金目标仍不降到零；该目标是计划终态目标，不是防守仓位，也不是执行过程中每一时点实际余额的硬保证。
- 极高估值基础目标不是实际余额硬上限。
- 小幅偏离可以接受，并应保留取整、费用和价格变化所需冗余。

### 8.2 执行流动性边界

现金池可以用当前真实余额承担流动性桥梁，但不能冻结或透支：

- 当前真实可转账现金是唯一的立即购买力。冻结资金、尚未卖出证券的预计所得、未到账赎回和未来新增本金均不能增加即时上限。
- 本次标记为立即可执行的现金池调出不得超过当前真实可转账现金。
- 当前现金低于动态目标不自动禁止调出；若当前真实现金足以完成有效低配动作，且计划终态现金能够由已批准高配来源恢复到目标附近，可以先调出。
- 没有已批准高配来源可以恢复终态现金，或者当前真实余额不足时，限制本次立即动作。
- 顶层和 A 内部共用同一个即时现金上限：

  ```text
  顶层立即调出 + A 内部立即调出 <= 当前真实可转账现金
  ```

- 顶层已经批准的 B、C 调入先占用其所需现金，剩余真实现金才可用于 A 内部股票或可转债调入；不能分别计算两次可用现金。
- 若低配动作总额超过当前真实可转账现金，只把当前现金能够支持的部分标记为立即可执行；尚未获得现金支持的部分不伪装成当前购买力，也不建立跨计划待办。
- 高配对象卖出、赎回或调出的资金实际回到现金池后，只成为新的现金事实。人下一次触发时使用最新事实完整重算，不接续旧计划的剩余缺口。

### 8.3 一轮计划的计算顺序

每次计划独立执行以下计算：

1. 根据温度计算 A、B、C 顶层理想目标和当前偏离。
2. 根据触发类型应用动作阈值：月度增量检查只形成真实现金支持的软偏离修复；季度或临时顶层检查只有越过外侧线才形成半带宽部分再平衡。
3. 确定本次已经批准的顶层调入、调出金额。达到动作条件的高配对象可以生成减持或赎回计划，实际释放的资金只能回到现金池，不在本次计划中预先指定给某个低配对象。
4. 由部分可执行顶层方案中 A 的净调出金额计算 `A_exec`，再按 A 内部映射计算小市值、可转债和基础现金可执行目标；最后根据有效转债榜单计算可执行可转债目标和最终动态现金目标。A 为净调入时不预先增加 `A_exec`，等资金真实到账后由下一次计划吸收。
5. 现金池按一轮计划的最终净状态校验，而不是先把动态现金目标冻结。设本次已经通过规则和阈值的高配对象计划调入现金池金额为 `I`，现金池计划调往低配对象的金额为 `O`：

   ```text
   计划后现金池金额 = 当前现金池金额 + I - O
   ```

6. A 没有等待顶层净调入时，计划后金额应回到最终动态现金目标附近，允许平台颗粒度、交易单位、费用和最小动作造成小幅残差。A 是顶层净调入方时，B、C 的赎回尚未计入 `A_exec`，因此本次只生成赎回来源计划，不在同一计划中预先安排赎回款的 A 内部用途。
7. 若同一层的当前真实可转账现金足以覆盖所有有效低配缺口，则分别分配完整缺口；若不足，原则上按各自有效低配缺口占该层全部有效低配缺口的比例分配。
8. 按缺口比例得到的单个分配额无法形成一笔合规动作时，改为按该层目标偏离率由低配最严重到最轻排序；目标偏离率相同时优先绝对缺口更大者。按该顺序依次分配，每个对象最多分配其完整缺口。不足以分配给下一个对象的剩余资金保留在现金池。
9. 计划终态只是各项计划动作全部成功时的校验结果，不是对实际成交的保证。来源卖出失败或部分到账时，已完成的合规买入不为了恢复数学目标而强制反向卖出；去向买入失败时，已经到账的资金继续留在现金池。

新增长期投资本金、生活分红和个人生产力支出只更新现金池及全体系的最新事实，不自动触发资金调拨计划或账户内交易计划。生产力支出和生活分红的记录口径见 [投资记录与绩效口径](投资记录与绩效口径.md)。

## 9. B/C 组合执行约束

### 9.1 C：国内长钱组合

C 组合参与顶层再平衡，但不追求精确到元。调拨计划给出方向和目标金额，实际执行按平台最小申赎比例近似；投顾组合内部持有什么、如何再平衡由投顾策略负责，不由 ark-quant 生成交易计划。

已确认规则：

- 固定目标为全体系总资产的 `15%`。
- 目标比例不直接随市场温度伸缩，避免把长钱变成择时工具。
- C 是相对稳定、允许低频再平衡的国内底仓，不是永久冻结资产。
- 每次顶层检查都根据当时全体系总资产重新计算动态目标金额，不维护固定金额。
- C 的顶层软偏离和硬偏离均服从第 7 节，不再使用旧的 `目标偏离率 5% + 调整金额 1000 元` 双阈值。
- 触发 C 低配买入时，按软偏离可用资金或半带宽修复金额申购；若达不到平台硬性最低申购金额，则本次不执行。
- 触发 C 高配卖出时，以当前 C 持仓的 `1%` 为步长，把 `0%` 和各整数卖出比例都作为候选，选择实际卖出金额最接近半带宽调整金额的一档。

C 不承担明显超额收益预期，也不因短期跑输单独申赎。申赎只响应体系级动态目标金额偏离。

### 9.2 B：海外长钱组合

B 的国别分散和第二收益来源角色属于战略；具体目标占比、投入与再平衡规则属于战术。B 的动态目标为全体系的 `15%` 至 `20%`，随 A 股温度从极低向中性平滑提高；B 不在 A 股极低估值时被清空，也不在 A 股高估时机械突破 `20%`。月度新增本金按顶层软偏离修复当时的低配，不再机械按 `1/3` 分流。

QDII 限购、暂停申购或额度不足只影响 B 的增量承载能力，不改变 B 的目标、当前金额和低配事实，也不等于现有投顾组合停止管理。每次计划只根据本次可验证的真实申购能力，把 B 归入以下状态：

| 状态 | 判定 | 体系动作 |
| --- | --- | --- |
| 不可买 | 本次可确认申购额不足 `1000 元` 或暂停申购 | 保留 B 低配，不卖资金来源，不生成待办 |
| 部分恢复 | 可以形成至少 `1000 元` 实际申购，但不足以完成有效修复 | 使用真实可用现金分步修复，不超过半带宽目标 |
| 正常可买 | 可以承接本次体系算出的完整有效调整 | 恢复正常月度软偏离和季度硬偏离规则 |

不根据明天或下个月可能获得的额度预生成计划，也不把多日可能出现的小额限额相加成尚不可执行的未来购买力。状态由每次计划重新判断，不维护跨计划额度状态机。

截至 2026-07-14 的外部事实是：当前海外长钱因 QDII 基金单日可买金额不足 `100 元` 暂停新买入，但既有组合仍继续内部配置和再平衡。这是当前执行事实，不是永久规则；来源见 [海外长钱暂停买入说明](https://youzhiyouxing.cn/lite-posts/3148) 和 [QDII 额度说明](https://youzhiyouxing.cn/materials/2217)。

额度恢复属于执行能力变化，不是海外资产低估信号，也不自动授权卖老仓。人可以临时发起一次“B 可用性恢复”的顶层检查，但本次只使用当时真实可用现金；下一次正常季度检查时，B 仍低于外侧线且当时确实可买，才允许按半带宽规则卖老仓并修复。

### 9.3 B 替代载体审查

暂时限购本身不足以否定 B 或启动换仓。只有以下任一条件成立时，才启动替代载体审查：

1. 现有投顾永久或长期停止新增服务，投资逻辑、底层结构或服务方式发生实质变化。
2. 管理人信任、治理、投顾服务或持续管理能力发生实质性破坏。
3. B 连续两个季度低于当期硬偏离下限，且现有载体始终无法把 B 修复到半带宽内侧。

替代载体不按短期收益率加权打分，必须同时承接 B 的完整职责：海外市场平均水平长期收益、主要成熟市场覆盖、内部防守资产和再平衡、透明稳定的风险来源、可信管理人、可接受的费率与流动性，以及与 A/C 不严重重复的风险暴露。

合格的新载体只是 B 的新增承载通道，不新增顶层组合，也不复制 B 的目标：

```text
B 当前金额 = Σ 所有承载通道中归属于 B 的金额
```

截至 2026-06 的当前研究证据中，交银环球精选混合 QDII 约九成为股票、主要配置美股和港股且存在主动风格漂移风险，不具备 B 所需的完整全球分散、防守资产和投顾再平衡职责，因此不能直接作为 B 的等价替代。产品事实变化后可以重新审查；来源见 [产品说明](https://youzhiyouxing.cn/n/lite-posts/3104) 和 [海外长钱全球配置说明](https://youzhiyouxing.cn/materials/1944)。

## 10. 检查节奏与迁移

检查节奏控制的是“人何时要求体系重新计算”，不改变目标金额、偏离阈值、资金调拨规则或账户内策略答案。当前采用弹性触发机制：

```text
人决定触发一次常态或临时检查
-> 工具使用同一套体系规则重新计算
-> 生成资金调拨计划和交易计划
-> ark-quant 本次职责结束，由人自行审核和执行
```

不同层级采用不同参考节奏：

- A 组合内部以大约每周、约每 `5` 个交易日检查一次作为参考，不固定星期，也不要求每个自然周必须完成。
- 月度新增本金以修复顶层低配为主要用途；资金到账不自动触发，由人在方便时发起增量分配检查。
- A/B/C 顶层目标原则上每季度检查一次，不跟随 A 内部周度检查来回搬动老仓；只有越过外侧线才允许卖老仓。

节假日、工作安排或其他现实原因可以使检查提前、顺延或跳过；不为了补足形式上的次数使用过期数据补做计划。当市场在较短时间内出现明显非理性暴涨暴跌、风格严重分化或其他值得重新核算的变化时，人可以临时追加 A 内部或顶层检查。主观判断只决定“现在是否重新计算”，不能临时改变目标公式、调拨阈值、现金保留目标、调拨规则或账户内策略。

B 的可执行状态从不可买恢复为部分恢复或正常可买时，人也可以临时追加一次顶层检查；该检查只使用真实可用现金，不因额度变化卖老仓。

新规则启用时，不因为当前结构立即偏离新的常态中心就一次性卖出数万元老仓。首次迁移先经历一个完整季度：最多进行三次月度新增本金修复，不因迁移本身卖老仓；到第一次季度顶层检查时，再用届时温度、真实金额、外侧带宽和半带宽公式决定是否需要部分再平衡。

常态检查和临时追加检查均使用最近已完成交易日的完整收盘数据生成计划，原则上指导下一个交易日开盘执行，不在盘中反复重算。同一计划必须标记触发类型、临时触发原因、数据日和生成时间；MVP 不跟踪计划最终是否执行或如何执行。

检查触发和计划执行目前都由人掌握。工具只负责快速、可重复地计算资金调拨计划和交易计划，不自动监控市场后触发计划，也不连接券商或基金平台自动下单。人工如何处理计划不进入 ark-quant MVP；下一次检查直接根据届时最新的真实账户、持仓和现金事实重新计算，不接续旧计划状态。

## 11. 废弃与仅历史口径

- 旧国内四部分分配公式。
- 每月新增长期投资本金固定 `1/3` 投入海外长钱。

这些口径只用于追溯形成期、解释迁移或登记实现差距；分类依据见 [当前真源 v2026-08 口径台账与分类规则](../工程/口径台账/2026-08-当前真源口径台账与分类规则.md)。如果代码、页面或旧文档仍按这些口径工作，后续应在实现差距清单中记录，不能在本规则手册中继续作为当前计算依据。
