# 仓位与再平衡规则

> 状态：当前真源 v2026-09-29
> 职责：定义全体系目标、检查节奏、净调整需求和共享资金预算。
> 账户内选股、选债和委托取整另见策略与执行规则。

## 2026-09-28 阶段规则（当前生效）

用户已确认本阶段完整维护方案。原A/B/C目标、温度映射、月度新钱专用分配与季度半带修复退出当前目标生成。

| 投资方向 | 目标比例 |
| --- | ---: |
| 小市值股票 | 35% |
| 纳指方向 | 20% |
| 501312 | 10% |
| 主动转债 | 25% |
| 直接现金 | 10% |

1. 比例在本阶段固定，目标金额随最新全体系总资产变化；全局目标不受A股温度变化影响。单独复盘并确认修改后才更新比例。
2. 随既有周度计划统一检查各方向。净调整需求绝对值不足1000元暂不调整；达到1000元列入目标缺口；当前迁移阶段先用已有现金补低配，高配减持以后逐步安排，不一次性到位。现金不设独立触发器。本规则不覆盖原账户内部换股换债及硬风险处置。
3. 新钱只进入现金池。下次统一计划按最新事实重新计算；旧投顾目标为0，确认赎回应收只计一次资产、不计即时购买力，待迁移余额不会要求补回旧权重。
4. 策略当前金额采用证券市值。银行和券商直接现金统一计入现金；投顾和基金内部现金不重复穿透加入。平安是纳指与501312共用的账户，不能复制成两份现金预算。
5. 有效低配需求按缺口比例分享当批可用预算。分配后不足1000元暂留现金，不递归重分配；不能执行的方向保留缺口，不改配其他资产。各账户先抵扣自己的已可用现金，再计算银行需转入金额；券商可买资金不自动等于可跨账户转出资金。
6. 所有即时调入之和不得超过资金池已有未占用现金。10%现金为整轮目标终态，可在资金桥接过程中暂时偏离；只有本轮成立的释放方案用于终态推算，未到账赎回、未成交卖单、未来工资均不直接供买单使用。释放失败时更新事实重算，旧计划失效。
7. 目标差额不是证券委托。原股票、转债策略在预算内生成具体订单；基金按核实后的代码、限价、交易单位生成数量。费用、整手、小额免调与到账差异允许留下未完成缺口。

周度和1000元是执行简化选择，不宣称回测最优或保证增厚收益。所有计划由方舟统一产出，人工核对并在外部执行；没有自动下单或新建定时任务。

证券账户300～1,000元现金区间与小额费用处理遵循[交易执行规则](交易执行规则.md)的2026-09-29更新；预留现金在上述10%现金目标内，整手余款通过调拨回池，不为余额新增证券交易。

## 2026-09-29 迁移阶段确认

用户确认：先用现有现金，目标回流分阶段安排；本轮实际净新增投入多少，就优先从国内长钱赎回多少。目标比例不变，但目标差额不是本期全部操作。银行已有现金可以立即纳入本期预算；后续减持、投顾赎回及其预期款项不能增加本期购买力。资金到账并更新事实后，再由方舟统一计算下一期。

基金参考行情缺失不阻止资金预算；保留相应预算，待系统获取公开价格后计算参考份额。参考订单不等于核实了实时溢价或实际委托限价。

## 计算与执行顺序

1. 校验全部账户事实。证券市值、直接现金、投顾剩余持有余额和赎回在途各计一次；未知账户和缺失行情不能按零处理。
2. 同一总资产乘五项比例得到目标金额，分位尾差归现金。待迁移投顾、在途和待归类资产目标为零；未知持仓须先归类，不自动卖出。
3. 按目标减当前市值取得净差额，应用1000元免调与实际可执行条件。该门槛用于方向配置变动，不用于每只证券，也不阻止为合规买单补足不足1000元的银行转账差额。
4. 高配差额只列后续目标，不直接生成一次性到位的配置减持或投顾赎回。当前先用已有现金配置平安；基金成交后按净新增投入匹配条件赎回，原有换股换债照常。即时买入只受已有银行现金与各自券商可用现金支持。冻结、赎回在途和别的券商尚未回池资金不成为本账户购买力。
5. 按有效低配缺口分享预算，先抵扣承载账户自己的可用现金，再计算现金池需转入的金额；现金池即时调出合计不得超过余额。同一平安账户两方向共用一份现金。
6. 股票和转债在新的策略预算内产生原策略订单；基金根据核实限价与单位取整。各券商回池金额还须受实际可释放与可取资金约束。
7. 人工完成动作后更新账户事实；下一次独立重算。预算差额不是实际成交，旧计划未完成量不自动续跑。

现金池统一中转。账户内两个基金一卖一买时，可以在计划中分别列出待到账转入与卖出后回池；它们不能互相抵销后掩盖当下资金需求。

## 复盘边界

阶段固定不等于永久固定。发生明确功能缺口或持久执行成本时，复盘后修改同一目标规则；不叠加另一套择时预算。不通过更密检查保证收益增强，也不因一次短期排名推倒配置。

## 2026-09-29 分批迁移补充（最新确认）

本轮按平安基金买入减卖出的净新增投入计算赎回参考上限，不按全部目标缺口赎回，不把银证转账中的现金预留算成投入。实际少买少赎、未买不赎；参考买单不是实际成交记录。

国内长钱优先；本轮以该账户尚未赎回的余额为限，不跨到海外长钱补足同一批。国内长钱退出后，后续批次再处理海外长钱。已有投顾赎回在途金额抵扣本批补池需求，不能重复申请；当前计划只是条件安排，用户应以实际成交和平台记录核对。

赎回申请后更新在途事实；到账后更新现金池和投顾余额，再生成下一批配置，不必等下一次周度换股换债。沿用已有有效榜单与执行日校验，不新增定时任务，也不允许跨过期执行窗口复用旧订单。原小市值和转债轮动继续；不为本次迁移主动削减到最终目标。
