# 仓位与再平衡规则

> 状态：当前真源 2026-10-08 统一账户再平衡
> 职责：定义账户目标、资金调拨和分批逼近规则。
> 真源范围：顶层账户配置；账户内策略不由本文件重新定义。
> 最后核对：2026-10-08

## 账户目标

| 账户 | 目标比例 |
| --- | ---: |
| 广发账户 | 35% |
| 华泰账户 | 25% |
| 平安账户 | 30% |
| 资金账户 | 10% |
| 国内长钱及海外长钱投顾 | 0% |

当前金额按账户总资产计算，包含账户内证券、可用和冻结现金，不穿透剔除暂存现金。所有资产和在途只计一次。10%仅属于资金账户，其他账户现金不能抵扣此目标。平安内部纳指与501312按2∶1配置；共享现金只计一次，内部偏离不额外触发跨账户补款。

目标金额随同一快照的组合总资产变化。目标比例不受温度或新钱来源改变，温度仅观察；未来调整目标须另行确认。

## 再平衡计算

随既有周度计划检查。按目标金额减账户当前配置金额计算偏差，并扣除实际已发起调拨对剩余需求的影响。只生成过建议不代表已安排。

超配账户按本轮资金账户补池需求分担回流，不一次收回全部超配余额；计划回流额不是当前可取额。低配账户只从资金账户获得转入，各账户之间不直接相互垫资。

资金账户动态调拨优先，不另设固定金额、5%或10%比例保留线。当次预算为实际已到账可调拨金额与外部有效合计缺口的较小值。冻结、不可用、已承诺资金和未到账回款不支持当次预算，各项不能重复扣除。

预算不足时按有效缺口比例分配，充足则补齐，多余资金留存。资金账户不参与分配自己的钱。允许资金账户暂时低于10%乃至用尽可调拨余额；不得透支。不存在海外优先、国内优先或“买多少赎多少”的特殊顺序。

本轮新回流上限为：资金账户目标金额减去本轮供款后预计余额，再扣除已实际发起的待回流金额；不足零按零处理。未扣账但已承诺转出的款项也须从该预计余额扣除。不可用现金仍属于资金账户资产，不能因不可用而重复补池。各有效超配账户按剩余超配缺口比例分担，最多回收各自超配额；分配后不足1000元不新增动作，不递归重分配。实际可释放不足时减少回流并保留本轮缺口，不提前安排下一轮补款。

旧投顾目标为零，未发起赎回的余额按同一规则参与本轮回流分摊；没有本轮补池需求就不新增赎回。实际申请、成交、可取与到账仍受外部平台约束，计划不代表已成交。

## 小额与精度

剩余账户偏差不足1000元不新增调拨，恰好1000元参与。符合门槛的低配账户按剩余缺口比例分配；向下取整到分，不超预算。分配后不足1000元的份额留在资金账户，不递归分给其他账户。已发起动作不因剩余差额低于门槛被撤销。

目标为零的投顾也适用门槛，可能暂留小额余额。交易单位、费用及取整留下的差额随下一次正常检查处理，不为凑齐比例额外交易。

## 在途与更新

资产计量、已安排调拨、可用预算是不同事实。已发起用于防重，已到账才可使用。现有投顾输入的“仍持有余额”不含“确认赎回在途”，两者合计为该来源含在途资产；赎回在途单列且不再安排赎回。

其他已发起调拨在来源账户登记接收账户、金额和是否已扣账。已扣账时来源余额与持仓填写扣除后的事实，系统另计在途资产一次；未扣账时该款仍在来源资产中，但应从来源可调拨预算排除。接收方缺口需扣除这笔已安排转入，但可用预算不增加。资金账户的其他不可用金额不能重复包含已登记未扣账调拨。

到账或撤销后更新来源记录和相关账户实际余额，再生成计划。不能在接收方记录已到账金额的同时仍保留来源在途。所有相关事实更新完整之前不得按混合快照执行新计划。系统不代提交转账，不推断外部成交。

## 计划交付

展示账户目标与偏差、本次调拨、资金账户调出后余额、预计回流及回流后的预计余额。预计回流不是当次购买力。订单取整导致无法释放全部目标金额时，显示实际预计可释放额与剩余差额，不自动向低配账户筹钱。

账户内卖出后换入遵守原策略；平安未成交卖单不作为同批买单资金。实际成交、到账、外部出入金或账户事实变化后独立重算，不自动续接旧计划。

每轮独立按当期事实计算供款与补池；资金账户10%只约束本轮回流补池上限，不限制当次可用现金供款。其他账户剩余低配和超配保留至下一轮重新计算，不提前形成下一轮调拨指令。费用、小额免调、执行限制及市场变化会留下偏差，不保证每轮偏差单调下降。
