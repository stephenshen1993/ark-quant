# 仓位与再平衡规则

> 状态：盘点中；顶层组合结构、目标映射、软硬偏离、半带宽修复、首次迁移、A 可执行预算、检查频率和估值来源治理已经确认
> 职责：把估值纪律翻译为各策略或组合的目标金额和资金调拨动作。
> 真源范围：全体系顶层组合目标、A 组合内部目标、偏离判断、调拨结构、现金不足处理和长钱投入安排。
> 不负责：战略信仰、股票/转债选标的规则、订单取整、API 或页面实现。
> 最后复盘：2026-07-18

## 1. 战术边界

战略层已经确定：市场越低估越增加进攻，市场越高估越保留现金并提高可转债等防守型进攻暴露。战术层已经盘清顶层与 A 内部目标映射、动作阈值、分层频率、主要资金可用性规则、QDII 执行约束和温度来源治理。

当前已有公式来自体系形成期的一次经验性设定，尚未经过缜密推导。它不能因为已经写进代码、页面或配置就获得正确性；后续讨论必须从 [投资体系总纲](投资体系总纲.md) 的目标函数和角色约束出发。

## 2. 顶层组合与承载关系

全体系先按职责划分为三个顶层组合，再在 A 组合内部区分策略和现金。顶层组合不是账户、资产类别，也不是把账户重新命名为策略。

| 顶层组合 | 内部构成 | 当前承载通道 | 作用 |
| --- | --- | --- |
| A：自主组合 | 小市值股票策略、多因子可转债策略、现金池 | 广发账户、华泰账户、浦发银行 | 利用 A 股市场有效性不足、机制优势和因子有效性主动争取超额收益，是核心收益来源 |
| B：海外长钱组合 | 海外基金投顾组合 | 当前基金托管通道 | 获取海外市场平均收益，分享全球企业增长并提供国别、货币和市场分散 |
| C：国内长钱组合 | 国内基金投顾组合 | 当前基金托管通道 | 获取国内市场平均收益，提供偏大盘风格对冲、策略多样性和心理稳定性 |

家庭生活备用金不属于投资资产。A、B、C 加总构成需要参与本规则计算的全部长期投资资产。

当前一一承载时，可以用承载通道总资产近似策略或组合当前金额。未来一个账户承载多个策略，或一个策略跨多个账户时，必须按资金归属汇总，不能把账户直接当成策略或组合。

## 3. 当前实现公式快照

> 状态：记录当前工具会如何计算，不代表新的战术共识。

设：

```text
T_raw = 全市场温度，范围 0-100
T_norm = T_raw / 100
国内总资产 = 小市值股票策略当前金额
          + 多因子可转债策略当前金额
          + 长钱投顾组合当前金额
          + 现金池当前金额
```

当前现金目标：

```text
现金池 = 国内总资产 x 20% x T_norm
```

当前非现金目标：

```text
B = 国内总资产 - 现金池

长钱投顾组合 = B x 20%
多因子可转债 = B x 80% x (30% + 0.4% x T_raw)
小市值股票 = B x 80% x (70% - 0.4% x T_raw)
```

2026-07-18 之后形成的顶层 A/B/C 结构和第 3.1 至 3.4 节目标公式已经取代这套国内公式，成为新的战术共识。上面的公式只保留为当前实现事实，不能继续用于反推体系；新规则如何落实必须整体评估，不能为了少改代码而保留与体系冲突的局部旧口径。

### 3.1 已确认的顶层 A/B/C 映射

设等权全市场温度为 `t`，范围为 `0` 至 `100`，并定义：

```text
u = clamp(t / 50, 0, 1)

A 组合目标占比 = 70% - 5% × u
B 组合目标占比 = 15% + 5% × u
C 组合目标占比 = 15%
```

代表性位置为：

| 全市场温度 | A 组合 | B 组合 | C 组合 |
| ---: | ---: | ---: | ---: |
| `0` | `70%` | `15%` | `15%` |
| `10` | `69%` | `16%` | `15%` |
| `20` | `68%` | `17%` | `15%` |
| `30` | `67%` | `18%` | `15%` |
| `40` | `66%` | `19%` | `15%` |
| `50-100` | `65%` | `20%` | `15%` |

`70/15/15` 不是按当前持仓倒推出来的常态目标，而是 A 股极低估值下允许提高 A 组合进攻权重的上边界；`65/20/15` 是温度达到中性及以上时的常态中心。B 不因 A 股温度高于 `50` 而继续机械增加，因为“A 股更贵”不能推出“海外更便宜”；A 组合内部会继续通过提高可转债和现金比例降低进攻暴露。

该映射也为“极低估值时优先把增量资金投入 A 股”划出边界：当 A 低于动态目标时，新增长期投资本金可以优先补 A；当 A 已达到或超过 `70%` 时，不能借“砸锅卖铁”之名无限挤压 B、C。当前持仓占比只用于计算偏离，不能因为 A 过去表现较好、自然漂移到某个比例，就把该比例直接确认为目标。

本轮决策时的投资账本快照约为 `A 71.24% / B 13.22% / C 15.54%`，天然接近 `70/15/15`；但用“当前资产减累计收益”粗略反推的历史净投入结构约为 `A 66.1% / B 16.5% / C 17.4%`。后者只能作为现金流不完整条件下的辅助推断，不能当作精确归因，却足以揭示 A 当前权重包含过去跑赢后的自然膨胀。由此确认：移仓幅度只影响迁移方法，不能反过来决定长期中心。

极低估值端点下，小市值股票约占全体系 `70% × 62 / 85 = 51.1%`，A 已具有足够强的进攻性；B 保留 `15%`、C 保留 `15%`，用于守住永久国别分散和国内风格对冲。决策时 B 的现有投顾产品内部约七成为海外权益，因此 B 占全体系 `15%` 时，穿透后的海外权益只有约 `10.5%`；这个产品快照不是永久参数，但说明把 `15%` 固定为常态中心容易使 B 从第二收益来源退化为辅助仓位。常态中心因此把 B 提至 `20%`。

### 3.2 已确认的 A 组合内部三锚点

A 组合内部沿用此前已确认的股票、可转债和现金风险预算，并从旧的国内四部分结构中剔除固定 `15%` 的国内长钱后，按剩余 `85%` 归一化：

| A 股估值状态 | 小市值股票策略 | 多因子可转债策略 | 现金池 |
| --- | ---: | ---: | ---: |
| 极低 | `62 / 85`，约 `72.94%` | `20 / 85`，约 `23.53%` | `3 / 85`，约 `3.53%` |
| 中性 | `45 / 85`，约 `52.94%` | `30 / 85`，约 `35.29%` | `10 / 85`，约 `11.76%` |
| 极高 | `25 / 85`，约 `29.41%` | `40 / 85`，约 `47.06%` | `20 / 85`，约 `23.53%` |

极低估值时现金目标仍不降到零；它用于交易、费用、结算、市场继续下跌时的执行缓冲和不同承载通道之间的流动性桥接，不是因为看空而保留的防守仓位。动态现金目标约束一轮计划完成后的目标余额，不是执行过程不可触碰的硬底线：现金池可以先用当前真实现金支持低配对象，相对高配的可转债或其他已批准来源再通过现金池补回最终目标。B、C 只有顶层规则成立且资金真实到账后才增加下一次 `A_current`，不能把未来赎回直接计入本次 A 预算。中性现金锚点和新结构资金链的依据见 [近十年极端波动与现金池压力测试](../研究/资产配置/近十年极端波动与现金池压力测试.md) 与 [全体系仓位与资金链压力测试](../研究/资产配置/全体系仓位与资金链压力测试.md)。这些比例是风险预算边界，不是从历史收益中优化出的所谓最优解。

### 3.3 已确认的 A 组合内部连续映射

设标准化估值状态为：

```text
x = clamp((t - 50) / 50, -1, 1)
```

当 `-1 <= x <= 0`：

```text
小市值股票策略占 A = (45% - 17% × x) / 85%
多因子可转债策略占 A = (30% + 10% × x) / 85%
现金池占 A = (10% + 7% × x) / 85%
```

当 `0 <= x <= 1`：

```text
小市值股票策略占 A = (45% - 20% × x) / 85%
多因子可转债策略占 A = (30% + 10% × x) / 85%
现金池占 A = (10% + 10% × x) / 85%
```

分式中的分子与分母都是比例，例如 `45% / 85% = 52.94%`。映射连续连接 A 组合内部的三个锚点，并允许中性两侧使用不同斜率。

### 3.4 已确认的完整目标金额计算

设：

```text
V = A、B、C 当前金额之和，即全体系长期投资总资产
a、b、c = 第 3.1 节给出的 A、B、C 目标占比
s、d、k = 第 3.3 节给出的小市值、可转债、现金占 A 的比例
```

则：

```text
A 组合目标金额 = V × a
B 组合目标金额 = V × b
C 组合目标金额 = V × c

小市值股票策略目标金额 = A 组合目标金额 × s
多因子可转债基础目标金额 = A 组合目标金额 × d
现金池基础目标金额 = A 组合目标金额 × k
```

这里计算的是全体系理想目标：顶层目标必须加总为全体系总资产，A 内部理想目标必须加总为 A 理想目标金额。可转债候选不足时，只按第 3.6 节在 A 内部把无法配置的可转债目标转入现金，不改变 A、B、C 的顶层目标。

全体系理想目标只用于判断顶层偏离，不直接作为 A 内部周度计划的预算。设：

```text
A_current = 计划输入时已经成为事实的 A 组合当前金额
Delta_A   = 本次部分可执行顶层方案中 A 的调整金额；调入为正，调出为负
Q_out     = max(0, -Delta_A)，即 A 在本次顶层方案中的净调出金额
A_exec    = A_current - Q_out
```

则本次 A 内部可执行目标为：

```text
小市值股票策略可执行目标金额 = A_exec × s
多因子可转债可执行基础目标金额 = A_exec × d
现金池可执行基础目标金额 = A_exec × k
```

没有触发顶层调出时，`Q_out = 0`，A 内部按 A 当前实际金额配置，不能用 A 理想目标较低为由在周度检查中暗中提前执行季度卖出。顶层已经批准 A 净调出时，才按调出后的 `A_exec` 生成必要卖单或现金安排。

`Q_out` 使用 A 在顶层部分可执行方案中的净变化，不能把同一方案中 B、C 的调入和调出分别当作两次 A 预算变化。例如 C 调出、B 调入且 A 仍为净调出时，只扣除 A 的净调出；现金池的立即执行能力再由第 6 节单独限制。反之，A 为净调入时，B、C 尚未到账的计划赎回不增加 `A_exec`；资金真实进入现金池后，已经自然包含在下一次计划的 `A_current` 中。A 向 B、C 的实际申购仍只能使用当时真实可用现金；若需要先卖出 A 内证券释放资金，本次只生成相应卖出，待资金真实可用后由下一次计划重算，不预支跨账户未来资金。

### 3.5 已确认的估值输入

体系使用覆盖全部或绝大多数 A 股、按个股等权或以中位数等方式等价反映多数股票体感、以全市场估值的历史相对位置表达且数值越高表示估值越高的温度作为体系级风险锚。该口径用于降低少数大市值股票对全市场判断的支配，不限定必须采用 PE、PB 或其他估值指标的某种固定算法。

当前首选数据源为有知有行公开的等权全市场温度，记为 `t`，范围为 `0` 至 `100`。同一个 `t` 同时进入第 3.1 节的顶层 A/B/C 映射和第 3.3 节的 A 组合内部映射：

```text
x = clamp((t - 50) / 50, -1, 1)
```

因此：

```text
t =   0：x = -1，使用极低估值锚点
t =  50：x =  0，使用中性估值锚点
t = 100：x =  1，使用极高估值基础锚点
```

不再叠加单一指数 PE、PB、股债利差或中证1000等指标进行二次精密加工。温度只需要模糊但方向正确地反映 A 股大周期位置，不负责精准解释每个账户、策略、资产类别或风格的独立估值。

数据提供方属于可替换的数据来源，不是战略本身。替代来源只需同时满足以下条件：

- 覆盖全部或绝大多数 A 股，而不是以单一市值加权指数代替全市场。
- 按个股等权，或以中位数等方法等价反映多数股票的估值体感。
- 表达全市场估值在长期历史中的大致相对位置，方向为数值越低越便宜、越高越昂贵。
- 来源可信、口径基本透明并能持续更新。

不同来源可以使用不同估值指标、样本过滤、历史窗口和汇总算法，不要求精确复制当前来源，也不对新旧温度做逐日历史拟合、误差阈值校准或数值平滑。换源属于低频人工治理动作，不建立多来源平均、投票或自动故障转移：正常状态只有一个主来源，同一计划不得混用不同来源。

首选来源短期未更新时，本次估值驱动检查等待来源恢复，不拿旧温度冒充最近完成交易日的新输入，也不按固定断更天数自动换源。只有确认来源长期不再更新、口径发生重大变化或信任基础变化时，才由人启动换源审查。审查只判断候选来源是否满足上述职责，以及它与其他可信全市场信号对当前低估、中估或高估的大方向是否基本一致；若出现一个判断极低估、另一个判断极高估等明显方向冲突，则暂停切换并重新核查，不用精密算法强行调和。

新来源经人工确认后，从下一次正常检查开始直接使用其 `0` 至 `100` 温度，不追补来源失效期间的动作，不回溯重算，不人为平滑，也不因旧来源恢复而自动切回。每次计划必须记录数据日、来源和温度值；发生换源时另行记录原来源、新来源、切换原因、生效日期、新来源口径概要和切换时可信来源所处的大致估值区间。

### 3.6 已确认的可转债可投资性安全阀

安全阀保护的是可转债组合能否按照既定分散和风险过滤安全构造，不判断可转债市场的精确估值，也不引入第二套温度体系。

设：

```text
B0 = 本次使用的 A 组合金额基数 × 可转债占 A 比例
N  = 数据完整有效时，通过全部硬性风险过滤的合格转债数量
M  = min(N, 20)
```

观察全体系理想目标时，A 组合金额基数使用 A 理想目标金额；生成 A 内部可执行计划时，使用第 3.4 节的 `A_exec`。现金基础目标采用同一个金额基数，不能在同一份计划中混用理想 A 与可执行 A。

则：

```text
单只转债目标金额 = B0 / 20
可执行可转债目标金额 = B0 × M / 20
安全阀增加的现金目标金额 = B0 - 可执行可转债目标金额
最终现金目标金额 = A 组合内部映射给出的基础现金目标金额 + 安全阀增加的现金目标金额
```

候选不足时，不把 `B0` 重新均分给剩余候选，不提高单只转债目标金额，也不放宽价格、规模、成交额、强赎、正股风险或剩余期限等硬过滤。未配置金额增加现金目标，不增加小市值、B 或 C 的目标；可转债无法承接防守型进攻任务时，不能反向提高更激进资产的风险暴露。

单只转债目标金额始终为 `B0 / 20`，即占可转债基础目标金额的 `5%`，低于当前单债 `8%` 上限。候选减少只降低可执行可转债总额，不改变单一发行人相对全体系的目标金额；单债上限的分母不能改为安全阀缩减后的可执行可转债金额。

只有数据日期一致、覆盖完整、关键风险字段有效并成功形成有效榜单时，`N < 20` 才能触发安全阀。数据缺失、过期或运行失败时停止生成计划，不能把“无法确认候选数量”当成 `N = 0`，也不能据此卖出既有转债。

当 `N` 恢复到 `20` 或以上时，可执行目标恢复为基础目标；是否实际补足仍由偏离阈值、资金可用状态和正常检查周期决定。合格候选及 `N` 的策略口径见 [多因子可转债策略规则](../策略/多因子可转债策略规则.md)。

## 4. 偏离口径

```text
顶层组合偏离金额 = 顶层组合当前金额 - 顶层组合目标金额
顶层组合偏离比例 = 顶层组合偏离金额 / 全体系总资产

A 内部可执行偏离金额 = 策略或现金当前金额 - A 内部可执行目标金额
A 内部可执行偏离比例 = A 内部可执行偏离金额 / A_exec

目标偏离率 = 偏离金额 / 目标金额
```

正偏离表示相对高配，负偏离表示相对低配。顶层先判断 A、B、C 相对全体系理想目标的偏离，A 内部再判断小市值、可转债和现金相对本次 `A_exec` 的偏离，两层不能混用分母。目标偏离率用于判断某个目标是否需要动作。目标金额属于策略或组合，不属于账户；当前账户金额能够近似目标金额只是因为承载关系暂时一一对应。

任一次计算都必须同时满足两层守恒：

```text
A、B、C 目标金额之和 = 全体系总资产
A、B、C 当前金额之和 = 全体系总资产

小市值、可转债、现金可执行目标金额之和 = A_exec
小市值、可转债、现金当前金额之和 = A 组合当前金额
```

当 `Q_out = 0` 时，A 内部当前金额和可执行目标金额都加总为 A 当前金额。已经批准顶层调出时，两者的差额恰好是 `Q_out`，该差额用于形成必要卖出或现金调出，而不是会计错误。顶层未执行偏离继续保留为现实偏离，不能通过改用 A 理想目标金额把它伪装成已经再平衡。

动作阈值不会产生“无人承接”的资金，只会允许实际比例暂时偏离理想中心。未达阈值的偏离仍留在对应策略或组合的实际持有中。现金池是会计上的最终余项和所有调拨的结算对手方，但不等于它在经济上独自承担每一笔免动作偏离。

资金调拨存在两类可以独立发生、也可以相互加强的成因：

```text
估值变化
-> 顶层 A/B 目标和 A 内部目标同时变化
-> 产生目标移动型偏离

各部分涨跌不同步
-> 实际占比变化
-> 即使目标不变也会产生价格漂移型偏离
```

因此，全市场温度不需要精准覆盖每一个策略或组合。某个策略或组合相对下跌时，即使温度和目标占比基本不变，其实际占比下降也会形成低配并推动买入；若同时温度下降、目标占比提高，两类成因会共同扩大低配缺口。上涨时反向成立，由此形成规则化的被动低买高卖。

两类成因都只负责形成目标与偏离，不直接等于交易指令。实际动作仍需通过偏离阈值、资金可用状态、检查频率和执行规则过滤。

## 5. 当前动作阈值

顶层采用“月度软偏离修复、季度硬偏离卖仓”的非对称机制。新增本金可以持续纠偏，但只有越过顶层硬偏离范围，才允许为了再平衡卖出或赎回老仓。A 组合内部继续使用独立的周度形成期阈值，两层不能混用。

### 5.1 A 组合内部动作阈值

先把估值引起的目标变化、相对涨跌引起的价格漂移和同一检查周期内的其他目标变化全部合并，计算每个策略或组合相对动态目标金额的最终净调整需求：

```text
完整净调整缺口 = 动态目标金额 - 当前金额
```

当前动作阈值为：

| A 组合内部对象 | 形成实际调拨动作的条件 |
| --- | --- |
| 小市值股票策略 | 完整净调整缺口绝对值达到 `1000 元` |
| 多因子可转债策略 | 完整净调整缺口绝对值达到 `1000 元` |
| 现金池 | 不单独设置偏离阈值；作为所有调拨的结算对手方和实际资产的最终余项 |

阈值按每个策略或组合的最终净额分别判断，不能把不同去向的多笔小额需求相加凑成一次动作。例如股票和转债分别低配 `800 元`时，不能因为合计低配 `1600 元`就分别执行两笔小额调拨。

完整净调整缺口用于判断该对象是否进入执行检查，不等于本次必然调拨的金额。本次调拨金额还会受真实可用资金、现金保留目标、其他有效缺口和最小可执行动作限制。进入执行检查后还必须同时满足：

- 资金来源已经通过现金余额、申赎到账或账户内策略订单释放出真实可用资金。
- 资金去向为股票或可转债策略时，能够按对应账户内策略形成至少一笔合规订单；去向为 B 或 C 时能够形成合规申购；现金池作为目标去向时不要求生成证券订单。不能把资金调入证券账户后长期留作大额闲置现金。
- 同一策略或组合在同一检查周期只保留一笔净调拨方向，不能先调入再调出。

固定 `1000 元`控制的是 A 组合内部少数策略之间的资金移动。调拨对象数量不会随着证券持仓数量增加而同比增长，大约周度一次的检查也已经限制了动作频率，因此不再叠加“A 组合资产的一定比例”。该数值仍属于形成期战术参数，后续根据实际调拨次数、短期反向调拨、未执行偏离和资金闲置记录复盘，不升级为战略常数。

本节阈值只判断 A 组合内部是否形成账户间资金调拨需求，不直接约束账户内证券订单。小市值股票与多因子可转债如何使用已经归属于各自策略的资金，分别服从账户内策略规则和 [交易执行规则](交易执行规则.md)。

不能把 A 内部的 `1000 元`阈值或旧的国内长钱 `5% + 1000 元`阈值直接当作顶层卖仓触发线。

### 5.2 顶层软偏离：月度新增本金修复

每月由人决定是否发起一次增量分配检查。新增本金进入现金池只更新事实，不自动触发计划；触发后使用当时最新温度、全体系金额和可执行约束重算。

软偏离不设比例免动作区间：

- A 低配时，新增本金留在 A，并按 A 内部可执行目标使用；B 或 C 低配时，可以从现金池申购相应组合。
- 多个顶层组合同时低配时，原则上按各自有效低配缺口占全部有效低配缺口的比例分配。
- 单个实际分配金额不足 `1000 元`时跳过；比例分配后无法形成合规动作时，按目标偏离率由低配最严重到最轻分配。
- 软偏离只使用已经真实到账的新增本金和可用现金，不为了月度修复卖出任何 A、B、C 老仓。
- QDII 限购、暂停申购或其他约束使 B 无法执行时，保留 B 的低配事实，不先卖出资金来源，也不购买未经审查的替代产品。其他组合没有合理去向时，剩余资金留在现金池，但不标记为 B 专属待投资金；下一次 A 内部检查仍按最新事实和 `A_exec` 正常计算。

### 5.3 顶层硬偏离：季度卖仓触发线

设顶层组合 `i` 的目标占比、当前占比、偏离和外侧带宽分别为：

```text
w_i = 顶层动态目标占比
p_i = 顶层当前占比
d_i = p_i - w_i
h_i = min(3 个百分点, w_i × 10%)
```

已确认的外侧允许范围为：

| 动态目标 | 外侧允许范围 |
| --- | --- |
| A = `65%` | `62%-68%` |
| A = `70%` | `67%-73%` |
| B = `15%` | `13.5%-16.5%` |
| B = `20%` | `18%-22%` |
| C = `15%` | `13.5%-16.5%` |

季度检查使用已经发生的月度修复和当时真实资产，不预估未来新增本金：

- 所有组合都满足 `|d_i| <= h_i` 时，不卖老仓，实际偏离继续保留。
- 任一组合满足 `|d_i| > h_i` 时，才允许启动顶层部分再平衡；触发条件使用严格大于，恰好位于外侧线不动作。
- 低配去向因 QDII 限购或其他约束无法执行时，不为该去向先卖出高配组合；但一个去向受限不能自动取消其他本来可以执行的低配修复。
- B 的申购限制只阻止 B 的申购动作，不阻止符合规则的 B 赎回，也不改变 A、C 各自原本的理想修复金额。受限时按第 5.4 节生成部分可执行方案。
- 顶层卖仓触发后，实际资金仍服从现金池星型调拨、真实可用资金和平台申赎颗粒度，不建立组合间直接调拨。

固定绝对 `5` 个百分点会让 B 在目标 `20%` 时跌到 `15%`仍不动作，单用相对目标 `10%`又会让 A 获得 `6.5-7` 个百分点的过宽空间；两者取舍后采用“相对 `10%`、绝对 `3` 个百分点封顶”。旧的相对 `5%` 双阈值对季度卖老仓过窄，不再使用。

### 5.4 触发后的半带宽修复

顶层越过外侧线后，不一次回到目标中心，也不只停在容易再次越线的外侧边界，而是把偏离同比例收缩到半带宽以内。设：

```text
r = min{ h_i / (2 × |d_i|) | d_i != 0 }

修复后占比 p'_i = w_i + r × d_i
```

因为至少一个组合已经越过外侧线，所以 `0 < r < 0.5`。三个偏离使用同一个 `r`，修复后占比仍加总为 `100%`，且所有组合都进入各自半带宽以内。代表性修复区间为：

| 动态目标 | 外侧触发线 | 修复后进入 |
| --- | --- | --- |
| A = `65%` | `62%-68%` | `63.5%-66.5%` |
| A = `70%` | `67%-73%` | `68.5%-71.5%` |
| B = `20%` | `18%-22%` | `19%-21%` |
| B 或 C = `15%` | `13.5%-16.5%` | `14.25%-15.75%` |

修复金额按当时全体系总资产换算。单个伴随调整不足 `1000 元`、无法满足平台颗粒度或无法真实执行时可以跳过；跳过后，剩余可执行调入和调出仍必须按下述部分执行规则保持收支平衡，不能留下没有去向的来源卖出。不能为了数学上精确落点制造无经济意义的小动作。C 的赎回继续按当前持仓 `1%` 步长选择最接近所需调整金额的一档。

半带宽公式先生成不考虑申购限制的完整理想方案。设组合 `i` 的理想调整金额为：

```text
Delta_i = (p'_i - p_i) × V
```

`Delta_i > 0` 表示理想调入，`Delta_i < 0` 表示理想调出。某个低配去向本次不能买入时，按以下规则得到部分可执行方案：

1. 删除该去向的调入动作，目标、理想缺口和完整理想方案仍照常展示。
2. 其他能够执行的低配去向最多保留各自在完整理想方案中的原调入金额；不能把受限去向跳过的金额额外分给其他组合。
3. 把完整理想方案中的高配调出金额按原比例同步缩小，使实际计划调出总额恰好等于剩余可执行调入总额；任何来源都不能超过其原理想调出金额。
4. 删除受限去向后没有其他可执行调入时，本次顶层调出全部归零，不能为了形式上降低高配而把资金先堆进现金池。
5. 部分执行后的剩余偏离如实保留；下一次检查仍从最新真实金额完整重算，不接续本次被删除的调入动作。

这套处理不重新归一化 A/B/C 目标，也不把 B 的渠道限制变成 A 的额外进攻授权。它只回答本次完整理想方案中哪些动作真正能够同时成立。完整理想方案、部分可执行方案和执行后仍会保留的偏离必须同时展示，避免把执行约束伪装成目标变化。

### 5.5 首次迁移期

新规则启用时，不因为当前结构立即偏离新的常态中心就一次性卖出数万元老仓。首次迁移先经历一个完整季度：最多进行三次月度新增本金修复，不因迁移本身卖老仓；到第一次季度顶层检查时，再用届时温度、真实金额、外侧带宽和半带宽公式决定是否需要部分再平衡。

若首次迁移期内出现短时间极端暴涨暴跌或其他足以触发临时顶层检查的异常窗口，人仍可提前发起检查，但只能使用同一套硬偏离和半带宽公式，不能凭主观判断指定迁移金额。首次迁移安排是一次性的启用过渡，不构成以后每次调整目标后的固定宽限期。

以本轮约 `70.49 万元`账本快照和每月约 `7500 元`新增本金验算：若温度处于极低端，当前约 `71.24/13.22/15.54` 在一笔新增本金投入 B 后约变为 `70.49/14.13/15.38`，全部回到外侧允许范围，无需卖老仓。若温度处于中性区间，连续三个月把约 `2.25 万元`新增本金投入 B 后约为 `69.04/15.91/15.06`；首次季度检查按半带宽修复后约为 `65.99/19.00/15.01`，需从老仓向 B 转移约 `2.25 万元`，而不是启用规则时立即搬动约四至五万元。该快照用于验证迁移量级，不构成未来固定金额参数。

## 6. 调拨结构与现金不足处理

资金调拨只保留以现金池为中心的星型关系：

```text
小市值股票策略当前承载通道 <-> 现金池
多因子可转债策略当前承载通道 <-> 现金池
B 组合当前承载通道 <-> 现金池
C 组合当前承载通道 <-> 现金池
```

现金池在归属上属于 A 组合，同时承担全体系调拨中转通道。买入 B、C 会使 A 中的现金和 A 总金额同步减少，赎回 B、C 到账会使 A 中的现金和 A 总金额同步增加；这正是顶层 A/B/C 之间的资金移动，不需要再虚构一个独立于三个组合之外的第四部分。

不建立“可转债直接调往小市值”“B 直接调往 A”之类的直连关系，也不追踪现金的来源归属。某笔现金是原有余额、证券卖出所得、基金赎回到账还是新增长期投资本金，不改变下一次计划的计算。计划只使用届时已经成为事实的账户、持仓和现金金额。

每次计划独立执行以下计算：

1. 根据温度计算 A、B、C 顶层理想目标和当前偏离。
2. 根据触发类型应用第 5 节规则：月度增量检查只形成真实现金支持的软偏离修复；季度或临时顶层检查只有越过外侧线才形成半带宽部分再平衡。
3. 确定本次已经批准的顶层调入、调出金额。达到相应动作条件的高配对象可以生成减持或赎回计划，实际释放的资金只能回到现金池，不在本次计划中预先指定给某个低配对象。
4. 由部分可执行顶层方案中 A 的净调出金额计算 `A_exec`，再按 A 内部映射计算小市值、可转债和基础现金可执行目标；最后根据有效转债榜单计算可执行可转债目标和最终动态现金目标。A 为净调入时不预先增加 `A_exec`，等资金真实到账后由下一次计划吸收。
5. 现金池按一轮计划的最终净状态校验，而不是先把动态现金目标冻结。设本次已经通过规则和阈值的高配对象计划调入现金池金额为 `I`，现金池计划调往低配对象的金额为 `O`：

   ```text
   计划后现金池金额 = 当前现金池金额 + I - O
   ```

   A 没有等待顶层净调入时，计划后金额应回到最终动态现金目标附近，允许平台颗粒度、交易单位、费用和最小动作造成小幅残差。A 是顶层净调入方时，B、C 的赎回尚未计入 `A_exec`，因此本次只生成赎回来源计划，不在同一计划中预先安排赎回款的 A 内部用途；资金后来真实到账可以使现金暂时高于动态目标，由下一次计划吸收。这不属于计划终态错误。现金池也可以在执行过程中暂时低于目标，并使用当前真实现金桥接不同承载通道的时间差；动态现金目标不是过程中的硬底线。
6. 本次标记为立即可执行的现金池调出不得超过当前真实可转账现金，冻结资金、尚未卖出证券的预计所得、未到账赎回和未来新增本金均不能增加这个即时上限。若当前真实现金足以完成某个低配动作，即使现金当前低于动态目标，也可以先调出；这使用的是已经存在的现金，不是预支未来资金。对应高配对象的计划调出仍独立通过星型关系补回现金池，MVP 不追踪不同调拨动作之间的资金来源归属。

   顶层和 A 内部共用同一个即时现金上限：

   ```text
   顶层立即调出 + A 内部立即调出 <= 当前真实可转账现金
   ```

   顶层已经批准的 B、C 调入先占用其所需现金，剩余真实现金才可用于 A 内部股票或可转债调入；不能分别计算两次可用现金。
7. 若低配动作总额超过当前真实可转账现金，只把当前现金能够支持的部分标记为立即可执行；尚未获得现金支持的部分不伪装成当前购买力，也不建立跨计划待办。高配对象后来实际卖出、赎回或调出并进入现金池后，由下一次计划按最新事实重算。
8. 顶层先决定现金应留在 A 还是用于补 B、C；留在 A 的资金再按 A 内部可执行目标决定是否补小市值或可转债。不能让同一笔当前现金同时填补顶层缺口和 A 内部证券缺口，也不能用 A 内部周度动作绕过顶层触发线。
9. 若同一层的当前真实可转账现金足以覆盖所有有效低配缺口，则分别分配完整缺口；若不足，原则上按各自有效低配缺口占该层全部有效低配缺口的比例分配，不主观预测哪个策略或组合应当优先。
10. 按缺口比例得到的单个分配额无法形成一笔合规动作时，不强行拆成无法执行的小额动作。此时改为按该层目标偏离率由低配最严重到最轻排序，目标偏离率相同时优先绝对缺口更大者；按该顺序依次分配，每个对象最多分配其完整缺口。不足以分配给下一个对象的剩余资金保留在现金池。
11. 高配对象减持、赎回或调出的资金实际回到现金池后，只成为新的现金事实。人下一次触发时使用最新事实完整重算，不接续旧计划的剩余缺口。

这套规则允许现金池以当前真实余额承担流动性桥梁，也允许一次只做当下真实现金能完成的部分。它不要求每条星型调拨同时到账，不需要为了表达“谁卖出之后给谁买入”而建立资金来源跟踪、多阶段调度或执行状态机。

计划终态只是各项计划动作全部成功时的校验结果，不是对实际成交的保证。来源卖出失败或部分到账时，已完成的合规买入不为了恢复数学目标而强制反向卖出；去向买入失败时，已经到账的资金继续留在现金池。无论哪一项动作失败或部分执行，未完成部分都不形成跨计划债务，下一次只按最新真实持仓和现金重算。

## 7. 现金池

现金池同时承担目标仓位、中转账户和执行缓冲：

- 观察理想结构时，现金基础目标是 A 理想目标金额乘以第 3.3 节的现金占 A 比例；生成计划时，改用 `A_exec` 乘以该比例。不能直接以旧的国内总资产为分母，也不能在同一计划中混用两种 A 金额基数。
- 极低、中性、极高估值时，现金分别约占 A 组合的 `3.53%`、`11.76%`、`23.53%`；按对应顶层 A 目标折算，分别约占全体系的 `2.47%`、`7.65%`、`15.29%`。
- 可转债候选不足触发安全阀时，无法配置的金额在 A 内部继续增加现金目标，因此真实目标可能高于上述基础值。
- 极低估值下现金目标仍不降到零；该目标是计划终态目标，不是防守仓位，也不是执行过程中每一时点实际余额的硬保证。
- 极高估值基础目标不是实际余额硬上限。
- 当前真实可转账现金是体系的流动性桥梁；只要调出不超过当前真实余额、去向动作有效且计划终态现金能够由已批准的高配调出恢复到目标附近，就可以先支持低配对象。
- 高配时优先补充达到动作阈值的低配对象。
- 当前现金低于动态目标不自动禁止调出；没有已批准高配来源可以恢复终态现金、或者当前真实余额不足时，才限制本次立即动作。
- 小幅偏离可以接受，并应保留取整、费用和价格变化所需冗余。
- 个人生产力投入需要综合现金情况、资本市场机会和事项重要性主观判断；资本市场极度低估时，优先取得低估资产。
- 生活分红按照总纲规则触发，一般在收盘确认后从现金池支付。

生产力支出和生活分红是外部资金流，记录口径见 [投资记录与绩效口径](投资记录与绩效口径.md)。

新增长期投资本金、生活分红和个人生产力支出只更新现金池及全体系的最新事实，不自动触发资金调拨计划或账户内交易计划。生活分红仍可按总纲在收盘确认后立即支付，但支付动作本身不等于启动一次再平衡。人下一次发起月度增量分配、季度顶层检查、A 内部常态检查或临时追加检查时，体系读取更新后的现金池和全体系事实重新计算；不能因为发生外部资金流就绕过人工触发权自动调仓。

## 8. C：国内长钱组合

C 组合参与顶层再平衡，但不追求精确到元。调拨计划给出方向和目标金额，实际执行按平台最小申赎比例近似；投顾组合内部持有什么、如何再平衡由投顾策略负责，不由 ark-quant 生成交易计划。

已经确认的战术结构：

- 固定目标为全体系总资产的 `15%`。
- 目标比例不直接随市场温度伸缩，避免把长钱变成择时工具。
- C 是相对稳定、允许低频再平衡的国内底仓，不是永久冻结资产。
- 每次顶层检查都根据当时全体系总资产重新计算动态目标金额，不维护固定金额。
- C 的顶层软偏离和硬偏离均服从第 5 节，不再使用旧的 `目标偏离率 5% + 调整金额 1000 元`双阈值。
- 触发 C 低配买入时，按软偏离可用资金或半带宽修复金额申购；若达不到平台硬性最低申购金额，则本次不执行。
- 触发 C 高配卖出时，以当前 C 持仓的 `1%` 为步长，把 `0%` 和各整数卖出比例都作为候选，选择实际卖出金额最接近半带宽调整金额的一档。
- 极度低估时，C 仍保持 `15%`，不参与 A 与 B 之间的五个百分点动态转移；只有自身相对全体系目标确实高配并满足最终顶层卖出规则时，才可能赎回。

C 不承担明显超额收益预期，也不因短期跑输单独申赎。申赎只响应体系级动态目标金额偏离。

## 9. B：海外长钱组合

B 的国别分散和第二收益来源角色属于战略；具体目标占比、投入与再平衡规则属于战术。

此前“每月新增长期投资本金固定 `1/3` 投入海外长钱”的做法是拍脑袋形成的临时规则，已由第 3.1 节的动态顶层目标取代，不再作为战术依据。

B 的动态目标为全体系的 `15%` 至 `20%`，随 A 股温度从极低向中性平滑提高；B 不在 A 股极低估值时被清空，也不在 A 股高估时机械突破 `20%`。月度新增本金按第 5.2 节修复当时的顶层低配，不再机械按 `1/3` 分流。

### 9.1 QDII 可执行状态

QDII 限购、暂停申购或额度不足只影响 B 的增量承载能力，不改变 B 的目标、当前金额和低配事实，也不等于现有投顾组合停止管理。每次计划只根据本次可验证的真实申购能力，把 B 归入以下状态：

| 状态 | 判定 | 体系动作 |
| --- | --- | --- |
| 不可买 | 本次可确认申购额不足 `1000 元`或暂停申购 | 保留 B 低配，不卖资金来源，不生成待办 |
| 部分恢复 | 可以形成至少 `1000 元`实际申购，但不足以完成有效修复 | 使用真实可用现金分步修复，不超过半带宽目标 |
| 正常可买 | 可以承接本次体系算出的完整有效调整 | 恢复正常月度软偏离和季度硬偏离规则 |

不根据明天或下个月可能获得的额度预生成计划，也不把多日可能出现的小额限额相加成尚不可执行的未来购买力。状态由每次计划重新判断，不维护跨计划额度状态机。

截至 2026-07-14 的外部事实是：当前海外长钱因 QDII 基金单日可买金额不足 `100 元`暂停新买入，但既有组合仍继续内部配置和再平衡。这是当前执行事实，不是永久规则；来源见 [海外长钱暂停买入说明](https://youzhiyouxing.cn/lite-posts/3148) 和 [QDII 额度说明](https://youzhiyouxing.cn/materials/2217)。

### 9.2 受限期间与历史低配

B 不可买时：

- 目标和低配缺口照常计算并展示，并标记为“目标有效、执行受限”。
- 月度新增本金先用于其他可执行的低配组合；没有其他合理去向时留在现金池。
- 留在现金池的资金不标记为“欠 B 的钱”，也不因等待未知开放时间长期冻结；后续 A 内部计划照常按实际金额计算。
- 不卖出现有 B，也不因为 B 无法申购就自动卖出 A、C 或降低 B 的目标。

额度恢复时只计算恢复当时的真实缺口：

```text
当前 B 缺口 = 当时 B 动态目标金额 - 当时 B 实际金额
```

不累计过去每月原本可能投入 B 的金额，不补偿假设收益，也不把已经进入其他资产的历史资金继续视为归属于 B 的债务。

### 9.3 恢复买入后的修复

额度恢复属于执行能力变化，不是海外资产低估信号，也不自动授权卖老仓。人可以临时发起一次“B 可用性恢复”的顶层检查，但本次只使用当时真实可用现金：

- B 已处于外侧允许范围内时，恢复月度软偏离，使用新增本金逐步向目标靠近。
- B 低于外侧线时，可以用真实可用现金修复，但最多修到半带宽内侧，不直接补至目标中心。
- 真实现金不足时，不预支股票卖出、基金赎回或未来新增本金。
- 下一次正常季度检查时，B 仍低于外侧线且当时确实可买，才允许按第 5.4 节卖老仓并进行半带宽修复。
- 修复过程中再次限购时立即停止，未完成部分作废；下一次按最新事实重算，不接续旧计划。

因此，额度恢复只解除执行约束，不产生新的追赶公式，也不改变顶层检查频率和动作阈值。

### 9.4 替代载体审查的启动条件

暂时限购本身不足以否定 B 或启动换仓。只有以下任一条件成立时，才启动替代载体审查：

1. 现有投顾永久或长期停止新增服务，投资逻辑、底层结构或服务方式发生实质变化。
2. 管理人信任、治理、投顾服务或持续管理能力发生实质性破坏。
3. B 连续两个季度低于当期硬偏离下限，且现有载体始终无法把 B 修复到半带宽内侧。

启动审查不等于自动购买或赎回现有 B。没有合格载体时，可以继续接受 B 执行受限和阶段性低配，不能为了凑比例降低准入标准。

### 9.5 替代载体硬门槛

替代载体不按短期收益率加权打分，必须同时承接 B 的完整职责：

- 目标仍是获取海外市场平均水平长期收益，而非以主动选股或择时超额为核心。
- 覆盖美国及其他主要成熟市场，不能只是一只单一国家、单一指数或单一行业工具。
- 内部包含与权益配合的防守资产和规则化再平衡，不把防守与择时责任重新交回给人。
- 投资范围、目标结构、调整机制和风险来源足够透明、稳定且可持续复核。
- 管理人或投顾值得长期信任，能够继续承担省心、放心和降低决策负担的职责。
- 费率、流动性、申赎和额度具有可接受的长期可执行性。
- 与 A、C 的国内、小盘和既有风格暴露没有严重重复。

任何核心职责不满足都不能用其他优点抵消。单只海外高权益基金即使暂时不限购，也不是 B 的等价替代；若希望持有，必须另行盘定其角色、风险预算和防守规则，不能借“临时替代”绕过体系审查。

合格的新载体只是 B 的新增承载通道，不新增顶层组合，也不复制 B 的目标：

```text
B 当前金额 = Σ 所有承载通道中归属于 B 的金额
```

截至 2026-06 的当前研究证据中，交银环球精选混合 QDII 约九成为股票、主要配置美股和港股且存在主动风格漂移风险，不具备 B 所需的完整全球分散、防守资产和投顾再平衡职责，因此不能直接作为 B 的等价替代。产品事实变化后可以重新审查，但不能把本结论反推为对该单只基金永久好坏的评价；来源见 [产品说明](https://youzhiyouxing.cn/n/lite-posts/3104) 和 [海外长钱全球配置说明](https://youzhiyouxing.cn/materials/1944)。

## 10. 作战周期

作战周期控制的是“人何时要求体系重新计算”，不改变目标金额、偏离阈值、资金调拨规则或账户内策略答案。当前采用弹性触发机制：

```text
人决定触发一次常态或临时检查
-> 工具使用同一套体系规则重新计算
-> 生成资金调拨计划和交易计划
-> ark-quant 本次职责结束，由人自行审核和执行
```

不同层级采用不同的参考节奏：

- A 组合内部以大约每周、约每 `5` 个交易日检查一次作为参考，不固定星期，也不要求每个自然周必须完成。
- 月度新增本金以修复顶层低配为主要用途；资金到账不自动触发，由人在方便时发起增量分配检查。
- A/B/C 顶层目标原则上每季度检查一次，不跟随 A 内部周度检查来回搬动老仓；只有越过第 5.3 节外侧线才允许卖老仓。

节假日、工作安排或其他现实原因可以使检查提前、顺延或跳过；不为了补足形式上的次数使用过期数据补做计划。

当市场在较短时间内出现明显非理性暴涨暴跌、风格严重分化或其他值得重新核算的变化时，人可以临时追加 A 内部或顶层检查。主观判断只决定“现在是否重新计算”，不能临时改变目标公式、调拨阈值、现金保留目标、调拨规则或账户内策略，也不能凭感觉指定计划金额。

B 的可执行状态从不可买恢复为部分恢复或正常可买时，人也可以临时追加一次顶层检查；该检查只使用真实可用现金，不因额度变化卖老仓，具体服从第 9.3 节。

常态检查和临时追加检查均使用最近已完成交易日的完整收盘数据生成计划，原则上指导下一个交易日开盘执行，不在盘中反复重算。同一计划必须标记触发类型、临时触发原因、数据日和生成时间；MVP 不跟踪计划最终是否执行或如何执行。

检查触发和计划执行目前都由人掌握。工具只负责快速、可重复地计算资金调拨计划和交易计划，不自动监控市场后触发计划，也不连接券商或基金平台自动下单。人工如何处理计划不进入 ark-quant MVP；下一次检查直接根据届时最新的真实账户、持仓和现金事实重新计算，不接续旧计划状态。

具体输入窗口、订单约束、暂停条件和计划交付边界见 [交易执行规则](交易执行规则.md)。
