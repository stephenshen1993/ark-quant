# 仓位与再平衡规则

> 状态：当前真源 v2026-09-28
> 职责：定义全体系目标、检查节奏、净调整需求和共享资金预算。
> 账户内选股、选债和委托取整另见策略与执行规则。

## 2026-09-28 阶段规则（当前生效）

用户已确认本阶段完整维护方案。原A/B/C目标、温度映射、月度新钱专用分配与季度半带修复退出当前目标生成。

| 投资方向 | 目标比例 |
| --- | ---: |
| 小市值股票 | 35% |
| 纳指方向 | 20% |
| 501312 | 10% |
| 主动转债 | 25% |
| 直接现金 | 10% |

1. 比例在本阶段固定，目标金额随最新全体系总资产变化；全局目标不受A股温度变化影响。单独复盘并确认修改后才更新比例。
2. 随既有周度计划统一检查各方向。净调整需求绝对值不足1000元暂不调整；达到1000元，向完整目标附近修复，不作半带修复。现金不设独立触发器。本规则不覆盖原账户内部换股换债及硬风险处置。
3. 新钱只进入现金池。下次统一计划按最新事实重新计算；旧投顾目标为0，确认赎回应收只计一次资产、不计即时购买力，待迁移余额不会要求补回旧权重。
4. 策略当前金额采用证券市值。银行和券商直接现金统一计入现金；投顾和基金内部现金不重复穿透加入。平安是纳指与501312共用的账户，不能复制成两份现金预算。
5. 有效低配需求按缺口比例分享当批可用预算。分配后不足1000元暂留现金，不递归重分配；不能执行的方向保留缺口，不改配其他资产。各账户先抵扣自己的已可用现金，再计算银行需转入金额；券商可买资金不自动等于可跨账户转出资金。
6. 所有即时调入之和不得超过资金池已有未占用现金。10%现金为整轮目标终态，可在资金桥接过程中暂时偏离；只有本轮成立的释放方案用于终态推算，未到账赎回、未成交卖单、未来工资均不直接供买单使用。释放失败时更新事实重算，旧计划失效。
7. 目标差额不是证券委托。原股票、转债策略在预算内生成具体订单；基金按核实后的代码、限价、交易单位和费用生成数量。费用、整手、小额免调与到账差异允许留下未完成缺口。

周度和1000元是执行简化选择，不宣称回测最优或保证增厚收益。所有计划由方舟统一产出，人工核对并在外部执行；没有自动下单或新建定时任务。

## 计算与执行顺序

1. 校验全部账户事实。证券市值、直接现金、投顾剩余持有余额和赎回在途各计一次；未知账户和缺失行情不能按零处理。
2. 同一总资产乘五项比例得到目标金额，分位尾差归现金。待迁移投顾、在途和待归类资产目标为零；未知持仓须先归类，不自动卖出。
3. 按目标减当前市值取得净差额，应用1000元免调与实际可执行条件。该门槛用于方向配置变动，不用于每只证券，也不阻止为合规买单补足不足1000元的银行转账差额。
4. 生成高配释放方案；用已可用现金及这些方案检验整轮现金终态。即时买入只受已有银行现金与各自券商可用现金支持。冻结、赎回在途和别的券商尚未回池资金不成为本账户购买力。
5. 按有效低配缺口分享预算，先抵扣承载账户自己的可用现金，再计算现金池需转入的金额；现金池即时调出合计不得超过余额。同一平安账户两方向共用一份现金。
6. 股票和转债在新的策略预算内产生原策略订单；基金根据核实限价、单位与费用取整。各券商回池金额还须受实际可释放与可取资金约束。
7. 人工完成动作后更新账户事实；下一次独立重算。预算差额不是实际成交，旧计划未完成量不自动续跑。

现金池统一中转。账户内两个基金一卖一买时，可以在计划中分别列出待到账转入与卖出后回池；它们不能互相抵销后掩盖当下资金需求。

## 复盘边界

阶段固定不等于永久固定。发生明确功能缺口或持久执行成本时，复盘后修改同一目标规则；不叠加另一套择时预算。不通过更密检查保证收益增强，也不因一次短期排名推倒配置。
