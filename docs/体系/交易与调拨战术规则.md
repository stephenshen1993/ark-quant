# 交易与调拨战术规则

> 版本：2026-07-13
> 定位：把战略规则翻译成盘后/盘前可执行的战术动作。战略规则见 [个人投资体系规则书](个人投资体系规则书.md)，账户金额口径见 [账户与金额口径](账户与金额口径.md)。

## 1. 战术定位

战术层不重新定义投资信仰，只负责把战略落实成可执行、可检查、可复盘的动作。

战术层回答这些问题：

- 哪一天生成计划。
- 哪些输入可以用于本次计划。
- 各策略/组合目标金额是多少。
- 哪些账户需要释放资金。
- 资金如何经过现金池中转。
- 调拨后股票和转债可以买多少。
- 哪些偏离值得动，哪些偏离应该忽略。
- 执行后如何判断这次动作是否合格。

战术层的核心原则：

```text
先固定输入 -> 再计算目标 -> 先释放资金 -> 再调拨 -> 再买入 -> 最后写回事实
```

## 2. 战术边界

战术层可以调整：

- 再平衡频率。
- 最小调拨阈值。
- 股票和转债订单取整方式。
- 长钱账户申赎近似方式。
- 策略内部过滤、排序和轮动参数。
- 数据源、界面、导出格式和系统实现。

战术层不应调整：

- 投资目标函数：长期收益足够高且过程可坚持。
- 三类概念：资产类别、策略、账户；国别仅作为资产或策略属性。
- 国内再平衡公式。
- 海外长钱不参与国内再平衡。
- 先卖出或释放资金，再调拨，再买入的顺序。
- 不用错误输入生成计划的红线。

如果战术执行不舒服，先判断是实现问题、颗粒度问题、数据问题，还是战略问题。不能因为一次计划不好看就改战略。

## 3. 作战周期

当前默认周期：

```text
每周一次，选择一个盘后或次日盘前有时间的窗口执行。
```

允许跳过本轮执行的情况：

- 本周已经完成一次完整再平衡。
- 市场休市或缺少有效策略榜单。
- 账户、持仓、温度或榜单输入不完整。
- 偏离过小，预计调拨收益不足以覆盖心智成本和交易摩擦。
- 个人时间不足，无法执行后写回真实成交和持仓。

不建议追加盘中操作。单轮计划完成后，当周原则上关闭，不因日内波动补单。

## 4. 计划日期与输入窗口

计划日期由策略数据和温度决定，不由账户快照决定。

定义：

| 概念 | 含义 | 示例 |
| --- | --- | --- |
| 计划日 | 策略榜单和温度所对应的数据日 | `2026-07-10` |
| 适用开盘日 | 本次计划实际准备执行的交易日 | `2026-07-13` |
| 计划输入窗口 | 从计划日到适用开盘日之间，可接受账户和持仓事实快照的窗口 | `2026-07-10` 到 `2026-07-13` |

输入使用规则：

- 温度、股票榜单、转债榜单必须明确计划日。
- 账户快照只保存事实金额、口径日期和更新时间，不保存交易归属日。
- 持仓快照只保存事实持仓、口径日期和更新时间，不保存交易归属日。
- 生成计划时，账户和持仓取计划输入窗口内最新保存的事实快照。
- 同一天多次保存账户或持仓时，取更新时间最新的一条。
- 如果窗口内没有事实快照，暂停生成计划。
- 旧数据只能作为显式兼容回退，不得默默冒充新输入。

一句话：

```text
温度和榜单决定计划日；账户和持仓提供窗口内最新事实。
```

## 5. 资金调拨策略与账户承载

资金调拨/再平衡是一条资金调拨策略：它按各策略/组合的目标金额和偏离控制账户间资金流向，不直接按资产类别或单个账户执行。账户只是承载和执行通道；当前一一映射，所以短期内可以按账户金额近似策略/组合金额。小市值股票与多因子可转债则是各自在广发、华泰账户内的执行策略，负责选标的、轮动和下单。

| 再平衡目标 | 当前承载账户/通道 | 可调拨性 | 执行特点 |
| --- | --- | --- | --- |
| 小市值股票 | 广发账户 | 高 | 可通过卖出、少买、买入调节 |
| 多因子可转债 | 华泰账户 | 高 | 可通过卖出、少买、买入调节 |
| 长钱账户 | 雪球基金托管下的长钱投顾组合 | 中 | 基金投顾申赎，按平台颗粒度近似 |
| 现金池 | 浦发银行 | 高 | 调拨中转、买入弹药、风险缓冲 |
| 海外长钱 | 雪球基金托管下的海外长钱投顾组合 | 不参与国内再平衡 | 单独追踪，原则上只买不卖 |

国内总资产：

```text
国内总资产 = 广发账户总资产
          + 华泰账户总资产
          + 长钱账户总资产
          + 资金账户余额
```

海外长钱进入看板总资产，但不进入国内再平衡公式。

### 5.1 资金调拨策略、账户内策略与账户

资金调拨策略、账户内策略与账户必须解耦：资金调拨策略负责资金调拨与再平衡，并计算各策略/组合的目标金额；它控制账户间的资金流向。账户内策略负责选什么、何时交易；账户只提供托管、现金、持仓与执行能力。当前广发/华泰/雪球两个投顾组合/浦发银行的映射恰好一一对应，只是当前操作最简的安排，不应被固化为数据模型或规则前提。

长期战术模型应分成三层：

```text
战略配置原则 -> 目标金额规则 -> 资金调拨策略 -> 账户内执行策略 -> 账户执行层
```

含义：

- 战略配置层负责回答“现金、长钱、进攻资产、防守型进攻资产之间如何分层”。
- 目标金额规则负责回答“每个策略/组合的目标金额怎么算”。
- 资金调拨策略负责回答“哪些账户释放或接收资金”。
- 账户内执行策略负责回答“小市值或转债账户内买什么、卖什么”。
- 账户执行层负责回答“哪些账户承载资产、如何实际结算和申赎”。

因此，目标算法不应写成一坨针对四个账户的定制公式，而应写成可解释的分层规则。当前账户金额可直接近似策略/组合当前金额，是因为一一映射；未来必须按策略/组合归属汇总账户或子账户金额。

推荐抽象：

| 层级 | 示例 | 职责 |
| --- | --- | --- |
| 战略配置层 | 现金储备、长期配置、主动进攻 | 决定先后顺序和大类预算 |
| 目标金额规则 | 现金池、小市值股票、多因子可转债、长钱组合 | 用规则模板计算目标金额 |
| 资金调拨策略 | 资金调拨/轮动 | 根据偏离控制账户间资金流向 |
| 账户内执行策略 | 小市值股票、多因子可转债 | 在各自账户内生成证券买卖订单 |
| 账户执行层 | 广发、华泰、雪球基金托管、浦发银行 | 保存事实金额、执行调拨、交易和申赎 |

新增第 6 个、第 7 个账户时，先判断它是新增承载通道，还是新增策略；只有新增策略时，才需要新增目标金额规则，而不是修改所有账户目标占比公式。

策略/组合的目标金额规则至少应包含：

```text
strategy_id
account_ids
asset_class
country_exposure
included_in_domestic_rebalance
target_amount_rule_type
target_amount_rule_params
liquidity_profile
transfer_priority
```

未来系统实现时，目标计算流程应为：

```text
1. 读取所有策略/组合定义及账户承载关系
2. 读取各账户事实快照
3. 计算国内总资产和温度
4. 按目标金额规则计算每个策略/组合的目标金额
5. 汇总归属于各策略/组合的账户/子账户当前金额，再与目标金额计算偏离
6. 根据 transfer_priority 和 liquidity_profile 生成账户间调拨计划
7. 基于调拨后账户可用现金生成股票/转债订单
```

## 6. 目标金额计算

设：

```text
T_raw = 全市场温度，范围 0-100
T_norm = T_raw / 100
```

当前公式应理解为一个三层水位算法，而不是四个账户的手写占比。

第一层：现金储备。

```text
现金池目标 = 国内总资产 x 20% x T_norm
```

第二层：非现金资产。

```text
B = 国内总资产 - 现金池目标
长钱账户目标 = B x 20%
主动管理资产 = B x 80%
```

第三层：主动管理资产内部按温度切换。

```text
可转债权重 = 30% + 40% x T_norm
小市值权重 = 70% - 40% x T_norm

多因子可转债目标 = 主动管理资产 x 可转债权重
小市值股票目标 = 主动管理资产 x 小市值权重
```

合并后等价于：

```text
现金池目标 = 国内总资产 x 20% x T_norm
B = 国内总资产 - 现金池目标
长钱账户目标 = B x 20%
多因子可转债目标 = B x 80% x (30% + 0.4% x T_raw)
小市值股票目标 = B x 80% x (70% - 0.4% x T_raw)
```

计算后形成偏离：

```text
偏离金额 = 当前金额 - 目标金额
偏离比例 = 偏离金额 / 国内总资产
```

正偏离表示高配，负偏离表示低配。

这里的“目标”都是策略/组合目标。当前一一承载时，账户金额可直接近似其承载策略/组合的当前金额；出现账户复用或策略跨账户后，应按策略归属汇总后比较。

### 6.1 规则模板

为了避免以后新增策略时重写公式，新策略应选择目标金额规则模板，而不是直接写死账户目标占比。

推荐模板：

| 规则模板 | 用途 | 示例 |
| --- | --- | --- |
| `temperature_reserve` | 随温度变化的现金/防守仓 | 现金池 = 国内总资产 x 20% x T_norm |
| `fixed_after_reserve` | 现金扣除后的固定比例配置 | 长钱 = 非现金资产 x 20% |
| `temperature_split` | 在某个父级预算内随温度线性切换 | 可转债 = 主动管理资产 x (30% + 40% x T_norm) |
| `residual_split` | 承接父级预算剩余部分 | 小市值 = 主动管理资产 - 可转债 |
| `excluded_tracking` | 单独展示，不参与国内再平衡 | 海外长钱 |

当前规则用模板表达为：

```text
cash_pool:
  rule = temperature_reserve
  base = domestic_total
  cap = 20%

changqian:
  rule = fixed_after_reserve
  base = domestic_total - cash_pool
  weight = 20%

active_sleeve:
  base = domestic_total - cash_pool - changqian

bond:
  rule = temperature_split
  base = active_sleeve
  low_temperature_weight = 30%
  high_temperature_weight = 70%

stock:
  rule = residual_split
  base = active_sleeve
  residual_after = bond
```

这样未来新增第 6、第 7 个账户时，只需要回答：

- 它是新的承载账户，还是新的策略。
- 它属于现金储备、长期配置、主动管理资产、防守型资产、还是单独追踪。
- 它的目标规则属于哪种模板。
- 它是否参与国内再平衡。
- 它的调拨优先级和流动性是什么。

不应重新写一套互相嵌套的账户占比公式。

## 7. 最小动作阈值

公式给的是目标锚点，不代表每一元偏离都要执行。

默认战术阈值：

| 动作 | 默认阈值 | 说明 |
| --- | ---: | --- |
| 股票/转债账户间调拨 | `max(1000 元, 国内总资产 x 0.2%)` | 小于阈值时优先忽略，避免噪音操作 |
| 长钱账户申购/赎回 | `max(3000 元, 国内总资产 x 0.5%)` | 长钱有申赎摩擦和颗粒度，阈值应更高 |
| 现金池偏离 | `max(1000 元, 国内总资产 x 0.2%)` | 现金池允许承担小额误差 |
| 单笔股票买入 | 至少满足 100 股和最小成交金额 | 不为凑目标买过小碎单 |
| 单笔转债买入 | 至少满足 10 张和最小成交金额 | 不为凑目标买过小碎单 |

这些阈值是战术默认值，不是战略信仰。年度复盘可以根据资产规模、交易成本和执行体验调整。

## 8. 调拨顺序

资金调拨必须服从顺序：

```text
先卖出或释放资金 -> 进入现金池或账户现金 -> 再转入低配账户 -> 再生成买入订单
```

禁止的顺序：

- 还没释放资金就假设现金可用。
- 浏览器端任意传入一个 `cash` 生成订单。
- 股票和转债账户各自按满仓逻辑下单。
- 用海外长钱补国内低配。
- 把长钱账户当作可以精确到元的券商现金账户。

调拨判断流程：

1. 计算四个国内再平衡目标的目标金额。
2. 汇总每个策略/组合在其承载账户/子账户中的当前金额，计算偏离。
3. 找出高配目标和低配目标。
4. 先用现金池补低配。
5. 如果现金池不足，优先从高配的股票或转债释放资金。
6. 如果长钱账户明显高配，按平台可执行比例赎回，资金回到现金池。
7. 资金进入低配账户后，再生成股票或转债买入订单。
8. 执行后写回真实成交、真实现金和真实持仓。

## 9. 现金池战术

现金池同时是目标仓位、中转账户和安全缓冲。

现金池高配时：

- 优先补低配的小市值股票或多因子可转债。
- 如长钱账户低配且偏离超过阈值，可以考虑申购长钱。
- 不因为现金高配就立刻全买，应先检查温度、榜单、持仓和可用现金。

现金池低配时：

- 优先通过高配的股票或转债卖出/少买回补。
- 如长钱账户明显高配，可以按可执行比例赎回。
- 不使用海外长钱回补国内现金池。

现金池小幅偏离时：

- 可以接受，不为小额误差频繁调拨。
- 优先保留一点冗余，避免买入订单因费用或价格波动导致现金不足。

## 10. 长钱账户战术

长钱账户是国内基金投顾配置，不是现金，也不是券商账户。

执行原则：

- 参与国内再平衡。
- 不追求精确到元。
- 调拨计划给目标方向和目标金额。
- 实际执行按平台允许的最小申赎比例近似。
- 小额偏离默认不动。

如果长钱账户高配：

- 偏离小于阈值：不动。
- 偏离超过阈值：给出建议赎回金额和约等于的赎回比例。
- 执行时选择最接近目标的整数百分比或平台允许比例。

如果长钱账户低配：

- 现金池充足且偏离超过阈值：可以申购。
- 现金池不足时，不为了补长钱而优先卖出核心进攻资产，除非偏离很大。

长钱账户不因短期跑输调整战术。只有价值观漂移、利益结构漂移、产品定位漂移、信任关系破裂、监管或基础设施风险，才进入替换讨论。

## 11. 股票订单战术

股票订单服务于两个目标：

- 把广发账户金额拉向小市值股票目标。
- 在账户内部维持小市值策略的候选排序和持仓轮动。

生成股票订单前必须满足：

- 股票榜单有效。
- 股票持仓为计划输入窗口内最新事实持仓。
- 广发账户总资产和可用现金为窗口内最新事实快照。
- 已考虑资金调拨后可用现金。
- 当前现金不足时，先给出卖出或调拨步骤，不直接生成不可执行买入。

股票订单规则：

- 买入按 100 股整数倍。
- 卖出不绕过策略卖出规则。
- 单只股票不因主观故事额外加仓。
- 涨停、停牌、退市、ST 等不可正常交易标的不得作为买入对象。
- 因取整产生的小额现金残留可以保留在账户内，不强行凑满。

股票订单的现金来源只能是：

- 广发账户原有可用现金。
- 资金账户调入广发账户后的可用现金。
- 股票账户内部卖出释放的现金。

不能由前端传入任意现金数覆盖服务端计算。

## 12. 转债订单战术

转债订单服务于两个目标：

- 把华泰账户金额拉向多因子可转债目标。
- 在账户内部维持多因子转债策略的候选排序、分散和风险过滤。

生成转债订单前必须满足：

- 转债榜单有效。
- 转债持仓为计划输入窗口内最新事实持仓。
- 华泰账户总资产和可用现金为窗口内最新事实快照。
- 已考虑资金调拨后可用现金。
- 强赎、价格、剩余规模、成交额、正股风险等关键字段可检查。

转债订单规则：

- 买入按 10 张整数倍。
- 优先规避强赎风险和流动性不足标的。
- 不为了凑目标买入风险字段缺失的转债。
- 高价、高溢价、临近强赎、成交额不足的标的需要被过滤或降权。
- 因取整产生的小额现金残留可以保留在账户内，不强行凑满。

转债订单的现金来源只能是：

- 华泰账户原有可用现金。
- 资金账户调入华泰账户后的可用现金。
- 转债账户内部卖出释放的现金。

不能由前端传入任意现金数覆盖服务端计算。

## 13. 同一天多次保存

同一天多次保存账户或持仓时，交易层按以下优先级取数：

1. 计划输入窗口内。
2. 口径日期最接近适用开盘日。
3. 写入时间最新。
4. 数据完整度更高。

账户层不需要知道本次计划归属哪一天。账户层只负责保存事实，交易层负责判断事实是否适用于本次计划。

## 14. 暂停生成计划的条件

以下情况宁可没有计划，也不要生成错误计划：

- 温度缺失或来源不可追溯。
- 股票榜单或转债榜单缺失。
- 策略榜单日期和计划日不一致。
- 账户快照不在计划输入窗口内。
- 持仓快照不在计划输入窗口内。
- 榜单关键字段缺失，无法检查风险。
- 调拨后现金仍不足，但系统试图生成买入。
- 前端传入现金与服务端事实账户不一致。
- 海外长钱被纳入国内再平衡。
- 生活备用金被纳入投资资金池。

## 15. 执行后写回

执行后必须把真实结果写回，而不是保留计划值。

写回内容：

- 实际成交价格。
- 实际成交数量。
- 未成交订单和原因。
- 券商账户最新可用现金。
- 股票/转债真实持仓。
- 长钱账户实际申购或赎回比例。
- 资金账户实际余额。

如果计划与实际执行不一致，应记录原因：

- 价格变化。
- 涨跌停或停牌。
- 现金不足。
- 取整误差。
- 人工放弃执行。
- 平台申赎颗粒度限制。

计划值不能覆盖事实值。

## 16. 战术复盘清单

每次执行后检查：

- 是否使用了正确计划日。
- 账户和持仓是否来自计划输入窗口。
- 是否先释放资金，再调拨，再买入。
- 股票/转债订单是否基于调拨后现金。
- 是否存在浏览器端传入任意现金覆盖事实账户。
- 是否把海外长钱排除在国内再平衡外。
- 是否因为小额偏离过度操作长钱账户。
- 股票订单是否遵守 100 股取整和策略过滤。
- 转债订单是否遵守 10 张取整、强赎和流动性过滤。
- 执行后是否写回真实成交、真实现金和真实持仓。

年度复盘时检查：

- 当前再平衡频率是否过高或过低。
- 最小动作阈值是否匹配资产规模。
- 目标金额规则是否仍清晰，新增账户/策略是否能用规则模板表达，而不是重写定制公式。
- 股票策略是否仍有效表达小盘风格。
- 转债策略是否仍有效表达机制优势和防守型进攻。
- 长钱账户是否仍符合信任和托管定位。
- 现金池是否仍提供足够生存权和再配置权。

## 17. 当前待验证问题

以下问题尚不需要立即写死，但应在未来执行中观察：

- 周度再平衡是否是最佳频率，是否需要改成偏离触发。
- `1000 元 / 0.2%` 的小额调拨阈值是否合适。
- `3000 元 / 0.5%` 的长钱申赎阈值是否合适。
- 可转债强赎、价格、溢价率、成交额阈值是否需要独立文档化。
- 小市值策略未来是否需要从单一市值排序升级为小盘多因子。
- 现金池是否需要保留额外安全垫，避免订单取整和手续费导致现金不足。

这些问题进入复盘清单，不作为日常临时改规则的理由。
