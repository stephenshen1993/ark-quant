# 账户与金额口径

> 用途：统一 Web 看板、体系再平衡、策略订单和人工录入时使用的账户概念。只要页面文案、API 字段或报告字段涉及资产、现金、持仓、市值，应先对齐本文。

## 核心原则

- 项目默认币种为人民币，金额单位为元。
- 用户界面展示金额时优先使用 `¥`，不在每个数值后重复写“元”。
- 指标名称需要消除歧义时，使用“总资产”“持仓资产”“可用现金”等业务词，不把单位混进字段名。
- 金额类数值默认保留 2 位小数。
- 大额概览可以使用“万”做紧凑展示，但详情、表格、输入和订单金额仍以元为准。
- 策略内部的“市值”只描述证券持仓价值；账户层面优先使用“资产”。

## 账户分层

账户只是执行和落地维度，不等同于资产类别或策略。当前体系的三类核心概念是资产类别、策略、账户；国别只是资产或策略的风险暴露属性。

| 账户/执行通道 | 当前承载策略或组合 | 资产类别 | 国别属性 | 是否参与国内再平衡 | 金额口径 |
| --- | --- | --- | --- | --- | --- |
| 广发账户 | 小市值股票 | 股票 | 国内 | 是 | 股票持仓资产 + 账户现金（可用 + 冻结） |
| 华泰账户 | 多因子可转债 | 可转债 | 国内 | 是 | 转债持仓资产 + 账户现金（可用 + 冻结） |
| 雪球基金托管（长钱投顾组合） | 投顾-长钱账户 | 基金 | 国内 | 是 | 账户总资产 |
| 浦发银行 | 现金池 | 现金 | 国内 | 是 | 账户余额 |
| 雪球基金托管（海外长钱投顾组合） | 投顾-海外长钱 | 基金 | 海外 | 否，单独追踪 | 账户总资产 |

家庭生活备用金不进入本项目投资资金池。

账户不是策略；它只负责资金托管、持仓记录和交易/申赎执行。当前映射恰好一一对应，方便操作，但不构成系统约束：未来可以让一个账户承载多个策略/组合，也可以让一个策略跨多个账户执行。新增账户时，先判断它只是新增承载通道，还是新增了策略；只有后者才需要新增目标金额规则。

## 指标定义

| 指标 | 定义 | 页面用语 |
| --- | --- | --- |
| 总资产 | 一个账户的全部投资资产。股票/转债账户中等于持仓资产 + 账户现金（可用 + 冻结）。 | 总资产 |
| 持仓资产 | 当前证券持仓按最新可得价格估算的价值。 | 持仓资产 |
| 可用现金 | 券商账户内可用于买入、转出或参与调拨的现金。 | 可用现金 |
| 冻结现金 | 已计入账户现金和总资产、但暂时不能买入或转出的现金。 | 冻结现金 |
| 余额 | 现金账户的金额。现金账户没有证券持仓时，用“余额”比“总资产”更自然。 | 余额 |
| 账户占比 | 单账户总资产 / 看板总资产。 | 占比 |
| 持仓占比 | 单个证券持仓市值 / 当前策略账户持仓资产。 | 占比 |
| 市值 | 单个证券或一组证券持仓按价格估算的价值。 | 市值 |

## 总资产公式

看板总资产：

```text
总资产 = 广发账户总资产
      + 华泰账户总资产
      + 长钱账户总资产
      + 资金账户余额
      + 海外长钱总资产
```

国内再平衡总资产：

```text
国内总资产 = 广发账户总资产
          + 华泰账户总资产
          + 长钱账户总资产
          + 资金账户余额
```

海外长钱只进入看板总资产，不进入国内再平衡公式。

国内再平衡由资金调拨策略执行，不直接按资产类别或单个账户执行。它为各策略/组合计算目标金额；当前每个目标只有一个承载账户，因此可以暂以账户金额近似该目标的当前金额：

```text
国内再平衡目标金额 = 广发账户小市值股票策略当前金额
                   + 华泰账户多因子可转债策略当前金额
                   + 长钱投顾组合当前金额
                   + 浦发现金池当前金额
```

可扩展口径为：

```text
策略/组合当前金额 = 归属于该策略/组合的所有承载账户/子账户金额之和
国内总资产 = Σ(参与国内再平衡的策略/组合当前金额)
```

当前一一承载时，策略/组合当前金额恰好等于承载账户总资产或余额；以后账户复用或策略跨账户时，必须按策略归属汇总，不能直接把整个账户金额当作单一策略金额。

## 股票与转债账户

股票账户：

```text
持仓资产 = Σ(股票股数 × 最新价格)
总资产 = 持仓资产 + 股票账户现金
```

可转债账户：

```text
持仓资产 = Σ(转债张数 × 最新价格)
总资产 = 持仓资产 + 转债账户现金
```

股票持仓单位为股，买卖取整通常按 100 股；可转债持仓单位为张，买卖取整通常按 10 张。

其中：

```text
账户现金 = 可用现金 + 冻结现金
总资产 = 持仓资产 + 账户现金
```

冻结现金属于账户资产，但不能用于账户内下单或资金调拨；策略订单只能使用可用现金。

## 输入与保存

- 股票/转债账户的持仓资产由持仓数量和报价估算，不建议手工输入。
- 股票/转债账户录入可用现金和冻结现金；系统自动得到账户现金（可用 + 冻结），因为这两项来自券商账户实时状态。
- 长钱、资金账户、海外长钱目前由人工输入总额或余额。
- 每个账户都有独立快照。修改某个账户时，只写入该账户自己的 `account_value_snapshots` 记录。
- 日期和温度属于计划上下文，独立写入 `account_contexts`，不是任何账户的资产快照。
- 看板总资产是当前各账户最新快照的派生结果，不单独存储。
- 快照日期表示账户状态的口径日期，不一定等同于策略榜单的数据基准日。
- 策略计划日期口径为：基于 T 日收盘数据，生成 T+1 日开盘可执行计划。

## 数据模型

当前账户体系按事实分层：

| 表 | 含义 |
| --- | --- |
| `account_contexts` | 计划上下文：口径日期、全市场温度 |
| `account_value_snapshots` | 单账户资产快照：账户、口径日期、总资产、账户现金、冻结现金、写入时间 |
| `stock_positions` / `cb_positions` | 策略持仓快照：代码、名称、数量、持仓日期 |
| `account_snapshots` | 旧宽表，仅作为历史迁移来源，不作为新写入目标 |

账户总览使用 `/api/account/summary` 聚合当前上下文和各账户最新快照。兼容接口 `/api/account/latest` 仍可读取同一聚合结果，但新代码优先使用 `/summary`。`/api/account/model` 单独提供资产类别、策略、账户的稳定定义与当前承载关系；它不返回账户余额，也不替代快照接口。

## 命名约定

推荐：

- 总资产
- 持仓资产
- 可用现金
- 余额
- 市值
- 占比
- 金额

避免：

- 账户总市值：账户包含现金，不应只叫市值。
- 账户资产（持仓+现金）：过长，详情页直接用“总资产”即可。
- 金额（元）和数值后缀“元”同时出现：二选一，当前 UI 优先用 `¥`。
