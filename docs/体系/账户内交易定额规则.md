# 账户内交易定额规则

> 状态：当前真源 v2026-08；共同规则
> 职责：定义股票与可转债账户把策略可执行预算转成计划后目标持仓和净订单时，必须共同考虑的因素、约束和输出证据。
> 真源范围：账户内交易定额的共同问题与待验证规则；策略筛选和资金调拨仍以各自正式规则为准。
> 不负责：选择具体求解器或实现结构；定义榜单生成、资产配置权重、具体风险过滤参数、盘中重算、自动下单或具体页面。
> 最后核对：2026-10-26

## 2026-10-26 整体配置优先（延续费用预留口径）

账户间资金调拨由账户目标资金占比驱动，作为账户内定额的前置输入。广发、华泰保留原有300元费用预留，完整计划不再逐笔扣算费用（不代表实际免费）；预留不进入证券等权预算。账户内同时优化证券目标权重与资金利用率：可投资余现按零目标权重进入第一层最大整体偏离，证券平方偏差居第二层。1,000元是余现检查门槛，不是强制清零、回池或放宽风险约束的上限；超过时必须检查并说明无法继续配置的原因，不因此反向改变账户间调拨。账户可承载不足时最多保留实际可承载的费用预留，不额外追加小额补款。

## 1. 问题定义

账户内交易定额不是“分别给股票和转债凑手数”，而是在一个固定计划日和一个证券账户内，选择计划后离散持仓与净订单的共同组合构造问题。

输入是：已冻结的策略目标集合、当前持仓、计划日价格、执行日可用资金、必要卖出和策略定额约束。输出是：一份只指导下一交易日的完整人工执行计划，包括每标的一笔净订单、资金方程、计划后估算权重、执行顺序与无法继续配置资金的原因。

资金调拨是本问题的前置事实。定额器只能消费账户原有可用现金、执行日可用调入和同账户必要卖出回款；它不能把未来回流当作预算，也不能为了订单结果反向修改资金调拨计划。

## 2. 共同因素

| 类别 | 必须考虑的因素 | 在定额中的地位 |
| --- | --- | --- |
| 事实时点 | 计划日收盘价、账户与持仓快照、榜单和风险字段的日期 | 输入有效性；不满足则暂停。 |
| 策略目标 | 固定 Top 20、目标集合退出、风险失效与必要卖出 | 决定目标集合和必要卖出，不由资金利用临时改写。 |
| 资金 | 原有可用现金、同日调入、同账户必要卖出回款、冻结、未来到账 | 决定执行日可用预算。 |
| 离散执行 | 100 股或 10 张单位、普通订单门槛、买入资格、实际价格护栏 | 决定哪些目标持仓与订单可行。 |
| 风险 | Top 20 理论等权两倍的共同单标的风险防线，即 10% | 硬约束；分母为扣除候选费用前、已经冻结的策略可执行预算，最小交易单位超过该线即为容量冲突。 |
| 组合质量 | 最大整体偏离、目标持仓平方偏差、全体绝对偏离、可投资余现、显性费用和执行复杂度 | 在全部可行目标手数组合之间按正式字典序比较。 |
| 执行不确定性 | 次日价格、停牌、资格变化、实际现金不足 | 不伪造预测精度；通过冻结顺序、缩减和跳过规则处理。 |

## 3. 预算与卖出边界

### 3.1 策略可执行预算

计划日估算下，账户内可用于证券订单的现金边界为：

```text
原有可用现金
+ 执行日可用调入
+ 同账户必要卖出估算回款
- 已知冻结
- 候选订单的必要费用预留
```

未来到账、尚未实际完成的跨账户回流和其他账户的卖出不得进入本式。费用不是展示尾注，而是候选订单可行性的组成部分：每次比较候选目标手数时，都必须使用该候选订单集对应的费用预留。费用口径仍以 [交易执行规则](交易执行规则.md) 为准。

### 3.2 卖出权限由策略适配层冻结

策略规则先确定目标集合与卖出权限。股票和可转债使用同一套账户内目标态口径：出现在 Top 20 但当前未持有的标的建仓，当前持有但掉出 Top 20 的标的清仓，当前已持有且仍在 Top 20 的标的允许按完整目标态加仓或减仓微调，但减仓后必须保留正持仓。账户内定额不得为了用尽现金、改善表面等权或完成资金调拨而清空仍在 Top 20 的标的，也不得换入榜单外标的。

## 4. 计划后持仓的共同要求

1. 两个账户均以其合格的固定 Top 20 为等权方向，理论单标的权重为 `1 / 20`；任一账户合格候选不足 20 时，暂停该账户的普通交易计划并报告容量冲突，不以少于 20 个标的、安全阀或重新均分静默退化。硬风险卖出提醒仍可按 [交易执行规则](交易执行规则.md) 独立输出。
2. 净订单增减量必须满足交易单位、可用预算、买入资格和 10% 单标的风险防线；已有零股余数在风险减仓后可以保留，但实际减仓量仍须满足交易单位。最小交易单位本身超过 10% 即报告容量冲突。
3. 先把必要卖出与目标手数合并为每标的一笔净订单，再按卖出、买入两个阶段组织人工执行。
4. 买入优先级必须可冻结并输出。执行日现金或资格不足时，只能按该顺序缩减或跳过原计划买单，不能盘中换入榜单外标的或重新规划。
5. 任何计划后现金都必须归因于继续配置会恶化正式整体比较结果、不足下一手、必要费用、冻结、不可交易或执行日变化；“算法未继续分配”不是合法原因。候选不足 20 或最小交易单位不可承载时，不产生普通交易计划，而是报告容量冲突。

## 5. 组合质量与取舍

令 `V` 为扣除候选费用前、已经冻结的策略可执行预算。目标标的 `i` 的计划后比较权重为 `w_i = value_i / V`，余现虚拟仓位的比较权重为 `w_cash = residual / V`；必要费用另行披露，不作为目标仓位，也不因不同候选费用而移动 5% 等权锚点。`V` 同时用于等权质量指标和 10% 灾难性集中上限，冻结、不可交易与费用仍必须分别进入可执行性检查和输出证据。

满足硬约束后，候选计划至少需要报告以下指标：

1. **目标持仓平方跟踪误差**：`Σ_i (w_i - 5%)²`，只衡量 Top 20 证券持仓相对名义等权的分散程度；
2. **最大整体偏离**：计划后单只估算权重相对理论等权，以及无归因可投资余现相对零权重中的最大差距；
3. **全体整体偏离**：`Σ_i |w_i - 5%| + w_cash`；
4. **无归因可投资余现**：扣除费用、冻结和不可交易金额后仍可投资却未配置的资金；
5. **显性摩擦成本**：按正式费用口径估算；
6. **执行复杂度**：非零订单数及其执行阶段。

无归因可投资余现以零权重参与整体偏离，不构成账户内现金目标。这样，使用可投资现金与接近 Top 20 等权是同一组合质量问题：大额闲置现金不能因为只比较 20 只证券而伪装成更等权。必要费用、冻结和不可交易导致的现金不是无归因可投资余现，必须分别说明；候选不足 20 或交易单位不可承载则是容量冲突，不以余现方式降级。

显性费用进入预算硬约束；难以在开盘前可靠预测的滑点和实际价格变化不应伪装成精确扣减，应作为执行日护栏与风险提示。

资金利用率与证券持仓占比共同组成账户内配置质量，不使用“精确等权绝对优先”排除任何微小平方偏差增加。必要费用预留、冻结与不可交易资金不作为闲置现金惩罚。1,000元不取代整手与风险约束；不是必须通过额外调拨满足的现金目标。

定额器必须按以下字典序选择唯一候选，所有比较先按厘或更高精度计算、展示时再四舍五入：

1. 最小化最大整体偏离 `max(max_i |w_i - 5%|, w_cash)`；
2. 仍并列时，最小化目标持仓平方偏差 `Σ_i (w_i - 5%)²`；
3. 仍并列时，最小化全体整体偏离 `Σ_i |w_i - 5%| + w_cash`；
4. 仍并列时，最小化可投资余现；
5. 仍并列时，最小化显性摩擦成本；
6. 仍并列时，最小化普通非零订单数；
7. 最后以已冻结的策略排名顺序和证券代码作为稳定的技术性平局规则。

现金以零目标权重参与第一层，表达证券整体投入不足；证券平方偏差居第二层，避免仅使用绝对偏差时出现集中配置的平坦方向。该数学偏差不等同于基于收益协方差的金融跟踪误差。若现金可以买入但继续买入会恶化第一层，归因为 `overall_deviation_priority`；在第一层不变时恶化第二层，归因为 `equal_weight_priority`；费用及不足下一合规状态分别披露。归因中的下一状态检查用于解释直接追加的限制，不替代全局最优性证明；模型状态、MIP gap和正式目标顺序同时输出。

必要退出、目标集合、10%风险防线和资金真实性始终是硬约束。不得只为降低余现清空仍在Top20的持仓或买入榜单外标的；允许在既有权限内全局比较普通加减仓组合，而非只检查逐只追加一手。订单数及复杂度不能压过前述配置质量。

## 6. 计划输出与验收

每个账户计划必须提供 [交易计划验收契约](交易计划验收契约.md) 所列资金方程、目标集合、计划后持仓与权重、余现原因、执行顺序和执行日护栏。任何算法变更都必须同时通过股票与转债的共同验收场景；共享求解核心不得被任一策略适配器绕过。实现差距记录在 [交易计划定额验收差距](../工程/交易计划定额验收差距.md)。
