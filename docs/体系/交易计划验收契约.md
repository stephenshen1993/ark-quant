# 交易计划验收契约

> 状态：当前验收基线 v2026-08；账户内交易定额的共同验收基线
> 职责：定义股票和可转债账户交易计划在算法选择前必须通过的可复算场景、输出证据与允许降级。
> 真源范围：账户内交易定额的验收边界；与 [交易执行规则](交易执行规则.md) 一起约束资金、订单和失败处理。
> 不负责：定义策略榜单、筛选参数、页面或自动下单；具体求解实现须满足共同规则的同一比较顺序。
> 最后核对：2026-08-15

## 1. 共同问题

股票和可转债账户都要在固定计划日的事实下，依据本策略可执行预算、当前持仓、固定目标集合和计划日价格，形成计划后目标持仓及每标的一笔净订单。资金调拨是前置条件：只把执行日真实可用的调入计入账户预算；同账户计划卖出回款可在既定执行顺序下支持该账户买入；未来到账资金不属于本次预算。

计划只输出一份完整的人工执行安排。算法内部可以比较目标手数组合，但这些组合不是多份用户计划，也不允许盘中重新计算或更换标的。

## 2. 共同验收场景

| 场景 | 输入特征 | 合格结果 |
| --- | --- | --- |
| 预算恰好可等权 | Top 20 合格、资金足以形成等权整数手数 | 计划后持仓接近等权；仅保留等权优先、费用和无法形成下一手的自然余现。 |
| 取整后仍有大额可投资余现 | Top 20 合格、离散手数使等权与用尽现金不能同时达到 | 不新增普通卖单；继续比较所有满足共同约束的买入定额。若额外买入扩大第一层平方等权误差，可以保留余额，但必须输出 `equal_weight_priority`；不得留下无解释余额。 |
| 20 个最小单位无法覆盖 | 资金不足以让每个合格目标各持有一手 | 暂停普通交易计划并报告容量冲突；不得静默缩为少于 20 个目标。 |
| 合格候选不足 20 个 | 策略筛选后候选数不足 | 暂停该账户普通交易计划并报告容量冲突；不得缩为少于 20 个目标或重新均分。 |
| 必要卖出释放资金 | 硬退出、目标集合退出或风险失效导致卖出 | 必要卖出先确定；同账户卖出回款进入本次买入预算；不因期初现金未体现回款而少买。 |
| 资金到账时点不同 | 同时存在当日调入与未来调入或回流 | 只使用当日真实可用调入；未来金额保留为下一次计划的新事实，不形成本次待办。 |
| 执行日价格或资格变化 | 开盘后价格上涨、停牌或标的失去买入资格 | 不重算、不替换榜单外标的；按冻结买入顺序缩减或跳过，下一次计划按新事实重算。 |
| 目标之间存在取舍 | 等权、可投资余现和摩擦成本无法同时最优 | 输出唯一计划，并可解释计划后偏离、未投资余额及预计摩擦；不得用隐含实现顺序掩盖取舍。 |

## 3. 必须随计划提供的证据

每个账户交易计划至少应能复算：

1. 期初可用现金、当日调入、同账户计划卖出回款、必要费用、计划买入金额与计划后自然余现的现金方程；
2. 固定目标集合、合格候选数、候选不足或最小交易单位不可承载时的容量冲突，以及每笔必要卖出的规则原因；
3. 每个目标标的的当前持仓、计划后持仓、计划后估算权重、理论等权与交易单位；
4. 所有未继续配置资金的原因：等权优先、不足下一手、必要费用、冻结、不可交易或执行日价格/资格变化；
5. 执行顺序和执行日护栏，特别是资金未实际到位或买入资格失效时的缩减、跳过边界。

## 4. 共同判定方式

验收使用 [账户内交易定额规则](账户内交易定额规则.md) 的正式字典序：先比较目标持仓平方跟踪误差，再比较最大整体偏离、全体整体偏离、无归因可投资余现、显性摩擦成本和普通订单数。求解器可以是受限搜索、整数规划或能证明产出同一排序结果的其他实现；不能用循环顺序、资产类别分支或未披露的阈值改变结果。
