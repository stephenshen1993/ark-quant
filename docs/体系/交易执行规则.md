# 交易执行规则

> 状态：盘点中；保留当前已明确的执行红线与临时做法
> 职责：把目标金额和策略榜单翻译为可执行、可检查、可复盘的交易计划。
> 真源范围：计划日期、输入窗口、资金可用性、订单约束、暂停条件和事实写回。
> 不负责：战略目标、仓位公式、账户内策略筛选参数、Web 页面实现。
> 最后复盘：2026-07-18

## 1. 执行总原则

```text
固定计划口径
-> 校验输入
-> 计算目标
-> 先释放资金
-> 再调拨
-> 再生成买入订单
-> 人工检查
-> 写回真实结果
```

宁可没有计划，也不要用缺失、混期或不可追溯的数据生成错误计划。

## 2. 计划日期与输入窗口

| 概念 | 含义 |
| --- | --- |
| 计划日 | 温度、股票榜单和转债榜单对应的数据日 |
| 适用开盘日 | 计划准备实际执行的交易日 |
| 计划输入窗口 | 从计划日到适用开盘日之间可接受事实快照的窗口 |

规则：

- 温度、股票榜单和转债榜单必须明确计划日。
- 账户和持仓只保存事实状态、口径日期和更新时间，不保存人为交易归属日。
- 计划使用输入窗口内最新、完整且可追溯的事实快照。
- 同一天多次保存时，优先使用口径日期更接近适用开盘日、更新时间更新且完整度更高的记录。
- 旧数据只能作为显式兼容回退，不能默默冒充新输入。

## 3. 必需输入

- 全市场温度及来源。
- 各承载账户或通道的总资产、可用现金和更新时间。
- 股票与转债真实持仓。
- 同一计划日的股票与转债策略榜单。
- 策略版本、参数版本和必要风险字段。

金额、持仓、资金流和绩效语义见 [投资记录与绩效口径](投资记录与绩效口径.md)。

## 4. 资金可用性

股票订单只能使用：

- 股票承载账户原有可用现金。
- 资金账户实际调入后的可用现金。
- 股票账户内部卖出实际释放的现金。

转债订单只能使用：

- 转债承载账户原有可用现金。
- 资金账户实际调入后的可用现金。
- 转债账户内部卖出实际释放的现金。

冻结现金属于资产，但不能用于下单或调拨。不能由浏览器或命令行任意传入一个现金数覆盖事实账户。

## 5. 股票订单

生成前必须确认股票榜单、持仓、账户总资产和可用现金均有效，并已经考虑调拨后的实际可用现金。

当前执行约束：

- 买入按 100 股整数倍。
- 卖出必须服从 [小市值股票策略规则](../策略/小市值股票策略规则.md)。
- 涨停、停牌、退市、ST 等不可正常交易标的不得作为买入对象。
- 取整产生的小额现金可以保留，不强行凑满。

## 6. 转债订单

生成前必须确认转债榜单、持仓、账户总资产、可用现金和关键风险字段有效，并已经考虑调拨后的实际可用现金。

当前执行约束：

- 买入按 10 张整数倍。
- 强赎、价格、剩余规模、成交额、正股风险等检查服从 [多因子可转债策略规则](../策略/多因子可转债策略规则.md)。
- 不为了凑目标买入风险字段缺失的转债。
- 取整产生的小额现金可以保留，不强行凑满。

## 7. 暂停生成计划

出现以下任一情况时暂停：

- 温度缺失或来源不可追溯。
- 股票或转债榜单缺失、日期不一致或运行不完整。
- 账户或持仓快照不在计划输入窗口内。
- 榜单缺少必要风险字段。
- 调拨后现金仍不足，但系统试图生成买入。
- 外部传入现金与事实账户不一致。
- 海外长钱被纳入国内调拨。
- 家庭生活备用金被纳入投资资金池。

## 8. 执行前人工检查

- 计划日和适用开盘日是否正确。
- 账户、持仓、温度和榜单是否来自允许窗口。
- 是否先释放资金，再调拨，再买入。
- 订单是否基于调拨后现金。
- 股票与转债订单是否满足单位、过滤和风险约束。
- 长钱申赎是否符合平台颗粒度。
- 是否存在实现方便替代投资规则的情况。

## 9. 执行后写回

计划值不能覆盖事实值。执行后记录：

- 实际成交价格和数量。
- 未成交、部分成交及原因。
- 券商最新可用现金和冻结现金。
- 股票与转债真实持仓。
- 长钱实际申购或赎回比例。
- 资金账户实际余额。

计划与实际不一致时，记录价格变化、涨跌停、停牌、现金不足、取整误差、平台限制或人工放弃等原因。

## 10. 当前待决问题

- 跨银行、券商和基金申赎的到账时序如何拆成多日计划。
- 部分成交和未完成调拨如何进入下一轮。
- 股票与转债订单的资金分配、残余现金和优先级。
- 当前周度执行窗口是否需要改为偏离触发或混合机制。
