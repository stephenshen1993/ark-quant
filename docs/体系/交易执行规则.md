# 交易执行规则

> 状态：当前真源 v2026-08；跨策略执行手册
> 职责：把目标金额和策略榜单翻译为可执行、可检查的资金调拨计划和账户内交易计划。
> 真源范围：计划日期、输入窗口、资金可用性、订单有效性、费用预留、现金不足、部分成交、失败交易、资金回流、暂停条件和计划交付边界。
> 不负责：战略目标、仓位公式、账户 UI 行为、账户内策略筛选参数、策略排名生成逻辑、API、数据库、页面实现或自动下单。
> 最后核对：2026-08-05

## 1. 执行总原则

```text
固定计划口径
-> 校验输入
-> 计算目标
-> 按动作阈值和当前真实可用资金计算本次动作
-> 分别生成资金调拨计划和账户内交易计划
-> 人工检查
-> 输出计划
```

宁可没有计划，也不要用缺失、混期或不可追溯的数据生成错误计划。

### 1.1 执行层边界

本文件定义跨策略执行纪律：同一个计划日内，资金调拨、股票订单和可转债订单如何共享事实、现金、费用、失败处理和人工检查。它不定义账户页面怎么交互，也不定义股票或转债榜单如何产生。

账户 UI 只能呈现或录入事实，不能因为页面控件方便就改变本文件的现金、费用、订单和暂停规则。策略特定排名、筛选、硬风险字段和退出语义只在执行规则依赖它们时被引用；具体规则以对应策略文档为准。

当前引用关系为：

| 执行事项 | 本文件职责 | 专属规则来源 |
| --- | --- | --- |
| 体系级资金调拨 | 使用已经确认的目标、偏离、现金池和触发结果生成本次可执行动作 | [仓位与再平衡规则](仓位与再平衡规则.md) |
| 小市值股票订单 | 使用可执行策略预算、费用、100 股单位、订单下限和执行顺序生成订单 | [小市值股票策略规则](../策略/小市值股票策略规则.md) 负责榜单、退出和策略风险 |
| 多因子可转债订单 | 使用可执行策略预算、费用、10 张单位、价格硬上限和执行顺序生成订单 | [多因子可转债策略规则](../策略/多因子可转债策略规则.md) 负责榜单、过滤和风险字段 |
| 账户 UI 或 API | 只作为事实录入和计划展示载体 | 工程实现说明，不是投资规则真源 |

### 1.2 人在回路的执行治理

当前安全形态为人在回路，而不是自动交易：

```text
人决定何时触发计算
-> 工具按体系规则生成资金调拨计划和交易计划
-> 人工复核计划与真实账户
-> ark-quant 的本次职责结束
-> 人在工具之外决定是否以及如何执行
```

触发权和最终执行权属于人，但计划计算权仍属于已经确认的体系规则。ark-quant 保留生成计划所需的输入和原始输出即可；MVP 不追踪计划是否执行、怎样执行、部分成交或人工调整，也不要求把执行结果写回系统。人工实际动作不会反向改变本次体系计划，下一次计划直接使用届时最新的真实账户和持仓事实重新计算。

当前不接入 QMT 等自动交易机制，不向券商或基金平台自动提交订单。未来是否引入任何自动触发、自动下单或自动申赎能力，必须重新完成安全边界、权限、异常处理和人工撤回机制的独立评审，不能作为普通工程升级默认开启。

### 1.3 一个计划入口，分步人工执行

工具无论以按钮、命令或脚本形式触发，都只能生成或刷新一份完整计划，统一给出资金调拨与账户内交易草案；这只是一次只读计算，不是一键执行。资金调拨计划只依赖账户事实、温度和经核验的申购事实；股票或转债交易计划只在同一计划日再合并已经成立的调拨结果、对应榜单、该账户持仓和真实可用现金。

人工执行顺序为：先完成当下已经成立的资金调拨；再在各自账户内按真实可用现金执行股票或转债订单；任何卖出、赎回、申购或转账的未到账部分都不进入同次可用现金。每个关键人工动作后，如需继续操作，重新读取最新事实并生成新计划。MVP 不保存“下一步”、不自动续接旧计划，也不提供一键提交多个账户或平台动作的能力。

## 2. 计划日期与输入窗口

| 概念 | 含义 |
| --- | --- |
| 计划日 | 温度、股票榜单和转债榜单对应的数据日 |
| 适用开盘日 | 计划准备实际执行的交易日 |
| 计划输入窗口 | 从计划日到适用开盘日之间可接受事实快照的窗口 |
| 触发类型 | 常态检查或临时追加检查 |

规则：

- 温度、股票榜单和转债榜单必须明确计划日。
- 常态和临时检查只影响何时启动计算，使用完全相同的目标、阈值、策略和执行约束。
- 正式计划使用最近已完成交易日的完整收盘数据，原则上只指导下一个交易日开盘开始执行。
- 若人在适用开盘日未能使用该计划，计划不能自动顺延为后续交易日的有效指令；下次准备执行前应按新的最近收盘数据重新生成。ark-quant MVP 不判断旧计划已经执行多少，也不维护跨日执行状态。
- 账户和持仓只保存事实状态、口径日期和录入时间，不保存人为交易归属日。计划输入窗口以口径日期为准；录入时间只用于区分同一口径日期下的先后版本，不能把旧口径事实伪装成新事实。
- 计划使用输入窗口内最新、完整且可追溯的事实快照。
- 同一天多次保存时，优先使用口径日期更接近适用开盘日、更新时间更新且完整度更高的记录。
- 旧数据只能作为显式兼容回退，不能默默冒充新输入。
- 账户、持仓或本次计划条件一旦保存新事实，基于旧事实生成的当前订单立即失效；同日榜单仍可复用，但必须重新计算资金调拨和订单。MVP 不把派生订单当作不可变的成交记录。
- 首选温度来源短期未更新时，本次估值驱动检查等待来源恢复，不使用旧温度生成正式资金调拨计划或普通交易计划；来源治理和换源规则见 [仓位与再平衡规则](仓位与再平衡规则.md) 的估值输入章节。

## 3. 必需输入

- 全市场温度及来源。
- 触发类型：A 内部常态检查、月度增量分配、季度顶层检查或临时追加检查；临时追加还必须记录触发原因。
- 各承载账户或通道的总资产、可用现金和更新时间。
- 计划涉及 B 申购时，本次可验证的 QDII 可执行状态、实际可申购上限、来源和核对时间。
- 股票与转债真实持仓。
- 同一计划日的股票与转债策略榜单。
- 策略版本、参数版本和必要风险字段。

金额、持仓、资金流和绩效语义见 [投资记录与绩效口径](投资记录与绩效口径.md)。

## 4. 资金可用性

账户间调拨先按 [仓位与再平衡规则](仓位与再平衡规则.md) 计算每个策略或组合的最终净调拨需求。不同去向的小额需求不能相加凑门槛，同一策略或组合在同一检查周期不能同时生成调入和调出。

顶层资金调拨计划确定后，先计算 A 组合本次可执行预算：

```text
A_exec
= A 组合当前实际金额
- 本次部分可执行顶层方案中 A 的净调出金额
```

没有触发顶层净调出时，A 内部必须以 A 当前实际金额为总预算，不能使用较低的 A 理想目标提前生成卖单。A 为净调入时，B、C 计划赎回只有真实到账、已经进入下一次 A 当前金额后才能增加 `A_exec`；尚未到账的计划流入不得计入。B、C 在同一顶层方案中一个调出、一个调入且 A 仍为净调出时，`A_exec` 只扣除 A 的净调出，实际立即购买力仍由现金池统一上限单独控制。

在 `A_exec` 边界内，股票和可转债策略再计算各自本次可执行预算：

```text
本次可执行策略预算
= 当前策略资产金额
+ 本次由当前真实现金支持的调入金额
- 本次调出金额
```

当前策略资产金额包含已归属该策略的证券市值和现金。账户内目标持仓和净订单必须以本次可执行策略预算为边界，不得直接使用尚未获得资金支持的理论目标金额生成买单。

达到相应调拨条件后，还必须检查来源能否真实释放资金、去向能否形成合规订单。月度顶层软偏离只能使用真实新增本金和可用现金，不能卖老仓；季度或临时顶层检查只有越过外侧线才允许按半带宽结果生成老仓减持。调拨计划不能代替账户内策略生成证券买卖，也不能仅因目标金额变化就假设证券已经卖出或资金已经到账。

B 的目标和低配事实不因 QDII 限购改变，但申购动作必须同时满足：

- 本次可确认申购金额达到 `1000 元`，并且计划申购额不超过当时真实上限。
- 不把多日限额、未来可能恢复的额度或历史未投入金额累计成本次购买力。
- B 可用性恢复检查只使用真实可用现金，不因额度变化生成 A、C 老仓卖出。
- 修复过程中额度再次受限时，旧计划未完成部分不续接；下一次按最新状态和金额重算。
- 单只替代基金或新通道只有通过 [仓位与再平衡规则](仓位与再平衡规则.md) 的 B 替代载体审查后，才能计入 B 或生成申购动作。

股票订单只能使用：

- 股票承载账户原有可用现金。
- 资金账户实际调入后的可用现金。
- 股票账户内部卖出实际释放的现金。

转债订单只能使用：

- 转债承载账户原有可用现金。
- 资金账户实际调入后的可用现金。
- 转债账户内部卖出实际释放的现金。

冻结现金属于资产，但不能用于下单或调拨。不能由浏览器或命令行任意传入一个现金数覆盖事实账户。

同一策略、同一承载通道内的计划卖出所得，可以按计划日收盘价估算并纳入同一份账户内买入计划。这是将策略轮动合并为一组净订单，不是预支跨账户未到账资金。计划按以下顺序展示：

```text
必要退出和其他净卖单
-> 同一承载通道内的净买单
```

这个顺序是对人工执行的计划约束，不使 ark-quant 承担成交跟踪或步骤状态管理。若人实际未完成计划卖出，不能超过届时真实可用现金强行执行买单。

订单金额和卖出所得继续使用计划日收盘价估算，不为下一交易日开盘误差额外拍脑袋预留固定百分比现金。必要费用按以下统一粗略口径从可用资金中扣除：

```text
股票计划费用预留 = 5 元 × 非零股票订单数 + 计划卖出金额 × 0.06%
可转债计划费用预留 = max(10 元, 计划总成交额 × 0.01%)
```

粗略预留只负责防止计划透支，不追求逐券商、逐市场复刻实际费用；法定税费结构变化时应更新口径。交易单位和订单下限形成的自然余现也可以吸收部分价格误差，二者都不是账户内现金目标。实际成交价、未完全成交和人工如何调整属于 MVP 之外的执行事实；若开盘时真实现金不足，按计划生成时的买入优先级依次执行，只能缩减或跳过原计划买单，不能透支、借款、突破届时真实可用现金或增加计划外标的。下一次计划以最新真实持仓和现金重算。

计划生成后、人工执行前若出现停牌、无法成交、ST、新强赎风险或其他已经能够确认的不可买状态，跳过对应买单，不临时增加榜单外替代对象；其他原计划买单仍可按既定顺序在真实可用现金范围内执行。计划日之后普通价格变化是否触发新的策略过滤，只服从对应策略已经明确的执行语义，不能由执行层临时增加条件。

股票和可转债策略均不设账户内现金目标。只要剩余现金还能给目标标的形成一笔合规买单，就继续分配；只有交易单位、普通订单下限、必要费用、冻结、不可交易或计划与实际执行价格差异所产生的自然残余现金可以保留。

资金调拨使用 [仓位与再平衡规则](仓位与再平衡规则.md) 的星型结构。计划中只能出现“某策略或组合的当前承载通道与现金池之间”的调拨，不出现策略间直接调拨，也不标记某笔现金的原始来源或未来用途。

对高配对象，只有满足对应层级动作条件，本次计划才可以给出减持、赎回或调出金额；人在工具之外只能使用已经真实可用的资金完成转账。对低配对象，现金池可以使用当前真实可转账现金承担流动性桥梁，即使执行过程中暂时低于基于 `A_exec` 计算的动态现金目标；立即调出总额不得超过当前真实可转账现金。A 不是顶层净调入方时，计划终态现金还必须在计入本轮已批准的高配调入后回到动态目标附近；A 是净调入方时，不在同一计划中预先安排尚未到账赎回款的 A 内部用途，到账后的暂时现金高配留给下一次计划处理。尚未卖出、赎回或到账的金额不能增加本次立即可用现金。账户内交易计划仍可使用该承载通道原有可用现金和同一策略内部卖出释放的资金，不把账户内资金利用与账户间调拨混为一层。

顶层调拨和 A 内部调拨必须共享同一笔当前真实可转账现金。计划先扣除已经批准且可以执行的 B、C 调入，再用剩余即时现金支持 A 内部低配策略；两层分别生成计划时仍必须通过一次汇总校验，不能让同一笔现金同时出现在两层的立即可执行金额中。

若现金无法补齐同一层的全部有效低配缺口，按缺口比例分配；按比例拆分后无法形成合规最小动作时，才用目标偏离率作为执行优先级。调入股票或转债承载通道的资金应能按对应账户内策略形成至少一笔合规订单；调入 B、C 的资金应能形成合规申购。现金池作为目标去向时不要求生成证券订单。

实际卖出、赎回或调出金额后来进入现金池时，它们只成为新的现金事实。MVP 不保留这些资金、不绑定旧计划中的买入用途，也不维护“等待到账后继续”的未完成状态。下一次检查按当时的最新事实重新计算。

次交易日或更晚回流的资金，只有在真实到账、解除冻结并由人保存为新的账户事实后，才进入下一次计划的可用现金。回流前不得作为同次买入预算；回流后也不自动继承旧计划的去向、优先级或未完成缺口。

部分成交或执行失败按事实处理：

- 来源卖出、赎回或转账失败时，不得用原计划预计所得继续完成尚未获得现金支持的买入；已经使用原有真实现金完成的合规动作不强制撤销。
- 来源只部分到账时，只把实际到账金额计入新的可用现金，不沿用原计划的剩余额度。
- 去向申购、转账或买入失败时，已经释放或到账的资金留在其实际所在账户，不为了恢复计划比例临时改买其他对象。
- 任一动作未执行、部分执行或成交金额变化后，旧计划中的未完成部分不成为债务或自动待办；下一次由人触发时按最新真实余额、持仓和可执行状态重新生成。

因此，MVP 只需要展示完整理想金额、部分可执行金额、当前可立即执行金额，以及因资金尚未到账而未进入本次动作的差额；该差额不是待办。MVP 不承担成交回报跟踪、失败回滚或跨计划续跑。

## 5. 股票订单

生成前必须确认股票榜单、持仓、账户总资产和可用现金均有效，并已经考虑调拨后的实际可用现金。

当前执行约束：

- 买入按 100 股整数倍。
- 卖出必须服从 [小市值股票策略规则](../策略/小市值股票策略规则.md)。
- 涨停、停牌、退市、ST 等不可正常交易标的不得作为买入对象。
- 目标持仓为策略榜单 Top 20 等权；单只目标金额为本次可执行小市值股票策略预算的 `1/20`。
- 单只股票计划持仓金额按计划日收盘价估算，硬上限为本次可执行小市值股票策略预算的 `10%`。`10%`只拦截灾难性集中，不取代 `5%`等权目标。
- 普通净订单下限为 `max(1000 元, 单只目标金额 × 10%)`；普通净订单未达到下限时可以暂不执行。
- `1000 元`是当前普通股票订单的最低经济尺度，`单只目标金额 × 10%`用于防止资金规模扩大后固定金额退化为噪声微调；两者均为形成期执行参数，不是战略常数。
- 排名退出、硬性风险退出、清空尾仓和无法拆分的必要卖出不受普通净订单下限约束。
- 取整、必要费用和普通订单下限产生的小额现金可以保留；不能把资金调拨偏离阈值直接套到账户内订单，也不能以等待未来调拨为由长期保留大额现金。

股票目标手数使用“目标态贪心 + 余现修补”，不从当前持仓出发逐只强行凑满：

1. 先把 Top 20 每只股票的理论目标金额换算为 100 股整数倍，全部向下取整，形成第一轮完整目标持仓。
2. 在不超过本次可执行策略预算、必要费用和单只 `10%`硬上限的前提下，从第一轮剩余现金中每次增加一个 100 股交易单位。优先增加相对单只目标金额低配最严重的股票；低配程度相同时，策略排名更高者优先。
3. 每增加一个交易单位后重新计算全部 Top 20 的低配程度。同一股票若增加后仍然最欠配，可以继续获得下一个交易单位；不能不经重算就连续把一只股票填满。
4. 得到完整目标手数后，再用“目标手数 - 当前手数”计算每只股票的一笔净订单。资金预算变化、策略轮动和当前持仓在这里一次合并，不能先按旧预算轮动、再为调拨重复买卖。
5. 必要退出先保留，普通净订单再应用普通订单下限；低于下限的普通订单本次暂不执行。
6. 订单过滤后如仍有可投资现金，只进行买入方向的余现修补，不为使用余现额外制造普通卖单。尚无合格买单的股票，第一次修补必须使该股票的最终净买单达到普通订单下限；已经有合格净买单的股票，可以继续增加一个 100 股交易单位。
7. 每次余现修补后继续按相对低配程度重排，直到剩余现金不足以形成下一笔合规买单。由此造成的轻微不等权和自然余现可以保留。

净买单按计划生成时相对单只理论目标金额的低配程度从高到低排列，低配程度相同时策略排名更高者优先。执行时真实现金不足，当前买单可以向下缩减到 100 股整数倍；缩减后低于普通订单下限，或连 100 股都无法买入时，跳过当前订单并继续检查后续原计划买单。只有剩余全部原计划股票买单都无法形成合规订单时，才停止买入；不能临时增加榜单外标的。

生成目标手数前必须检查 Top 20 的可执行性：

- 若本次可执行策略预算连 Top 20 每只股票各买入 100 股都无法覆盖，则 Top 20 目标在当前资金规模和价格下不可执行，暂停生成股票交易计划并明确告警，不能静默退化为少于 20 只。
- 若总预算足以覆盖 Top 20 的最低交易单位，某只股票 100 股金额高于单只理论目标、但不超过本次可执行策略预算的 `10%`，计划仍保留 Top 20 目标，同时明确提示该标的会因交易颗粒度产生显著不等权；不能擅自换股或隐藏偏离。
- 若某只目标股票最低 100 股按计划日收盘价估算已经超过本次可执行策略预算的 `10%`，说明当前资金规模无法承载该 Top 20 目标，暂停普通股票交易计划并报告容量冲突；不自动换成第 21 名或临时改变目标集合。

已有持仓在计划日超过 `10%`时，集中度减持优先于普通高配修复，目标仍是回到 `5%`等权附近；该卖单不受普通订单下限约束。若因停牌、涨跌停等原因无法卖出，只报告真实集中风险并在下一次按事实重算，不卖出其他股票抵消，也不假设上限已经恢复。

## 6. 转债订单

生成前必须确认转债榜单、持仓、账户总资产、可用现金和关键风险字段有效，并已经考虑调拨后的实际可用现金。

当前执行约束：

- 买入按 10 张整数倍。
- 强赎、价格、剩余规模、成交额、正股风险等检查服从 [多因子可转债策略规则](../策略/多因子可转债策略规则.md)。
- `130 元`同时是计划日候选过滤线和新增买入硬上限：只有计划日收盘价与实际可成交价格都低于 `130 元`才允许买入；实际价格等于或高于 `130 元`时跳过该买单，不重排榜单、不新增替代转债，继续检查其他原计划买单。
- 已有持仓盘中达到或超过 `130 元`不触发临时卖出，下一次完整策略检查再按已完成交易日收盘数据处理。
- 不为了凑目标买入风险字段缺失的转债。
- 基础目标持仓为策略榜单 Top 20 等权；单只目标金额固定为可转债基础目标金额的 `1/20`。合格候选不足 20 只时，使用可投资性安全阀，不将未配置金额重新均分。
- 净卖单优先级为：硬风险或基础过滤失效、有效候选排名跌出 Top 20、单债超过基础目标金额的 `8%`、Top 20 内高于 `5%` 等权目标的普通减持。排名跌出 Top 20 即卖出，不另设排名缓冲区间。
- 不另设普通订单金额下限；只要剩余可投资现金足以完成一笔合规的 10 张订单，就继续按策略排名和低配程度使用资金。
- 10 张是可转债的自然执行单位，金额通常已接近当前统一考虑的千元级经济尺度；不再叠加精确的 `1000 元`门槛，避免对同一笔订单重复过滤。
- 只有不足以完成下一笔合规 10 张订单、必要费用、成交失败、冻结或结算状态产生的现金可以保留，不以摩擦成本为由主动留下大额现金。

可转债沿用同一套目标态贪心框架，但不增加股票普通订单下限：

1. 按每只固定理论目标金额把合格目标转债全部向下取整到 10 张整数倍。
2. 只在可转债可执行目标金额内分配剩余现金，每次给相对理论目标金额最欠配且当前买得起的目标转债增加 10 张；低配程度相同时，策略排名更高者优先，每次增加后重新排序。
3. 合格候选不足 20 只时，安全阀留下的未配置金额不属于账户内取整余现，不能参加第二轮分配，也不能重新均分给现有候选。
4. 得到完整目标手数后，再与当前持仓合并为每只转债的一笔净订单；必要卖出按既定优先级展示在前，净买单在后。

净买单同样按相对固定理论目标金额的低配程度从高到低排列，低配程度相同时策略排名更高者优先。执行时真实现金不足，当前买单可以向下缩减到 10 张整数倍；连 10 张都无法买入时，跳过当前订单并继续检查后续原计划买单。只有剩余全部原计划转债买单都无法形成 10 张订单时，才停止买入；不能临时增加榜单外转债。

若可转债可执行目标金额连每只合格目标转债各买入 10 张都无法覆盖，则当前资金规模无法承载该目标集合，暂停生成转债交易计划并明确告警。这个检查只判断交易单位可执行性，不得据此放宽风险过滤或动用安全阀未配置资金。

目标态贪心是当前 MVP 的正式取整方法：它比单纯向下取整更能使用可投资资金，又避免从当前持仓出发为用完现金而制造大量额外买卖。整数优化可以继续作为研究和验算参照，但不进入 MVP 正式规则；除非真实计划记录持续显示贪心结果存在重大偏差，否则不为追求数学最优引入新的目标权重、求解器和参数。

## 7. 暂停生成完整计划

出现以下任一情况时暂停：

- 温度缺失、未对应最近完成交易日或来源不可追溯。
- 股票或转债榜单缺失、日期不一致或运行不完整。
- 账户或持仓快照不在计划输入窗口内。
- 榜单缺少必要风险字段。
- 本次可执行策略预算无法覆盖股票 Top 20 或全部合格目标转债的最低交易单位，或者任一目标股票最低 100 股已经超过股票策略预算的 `10%`硬上限。
- 顶层目标、当前占比、外侧带宽或半带宽修复结果没有各自加总为 `100%`，或修复结果仍落在半带宽之外。
- `A_exec` 小于零、超过 A 当前金额，或 A 内部可执行目标没有加总为 `A_exec`。
- 本次标记为立即可执行的现金池调出超过当前真实可转账现金；或者 A 不是顶层净调入方时，计入本轮已批准高配调入后的计划终态现金仍明显低于动态目标且没有可解释的颗粒度残差。
- 计划生成 B 申购，但 QDII 可执行状态、真实申购上限、来源或核对时间缺失，或申购金额超过真实上限。
- B 可用性恢复检查生成了任何老仓卖出，或计划试图补偿历史未投入金额、假设收益和未来额度。
- 计划把尚未卖出、赎回或到账的资金当作本次可用现金。
- 外部传入现金与事实账户不一致。
- B 组合被错误纳入 A 组合内部调拨，月度软偏离计划卖出任何老仓，或顶层组合未越过外侧线却生成老仓卖出计划。
- 家庭生活备用金被纳入投资资金池。

温度不可用时暂停的是估值驱动的完整资金调拨计划和普通交易计划。若股票或转债的最新策略数据本身完整、日期一致且可追溯，可以独立输出强赎、基础资格失效等硬风险的卖出提醒；它不是完整交易计划，不生成普通排名轮动或任何买单，卖出所得暂留原承载账户现金，等待下一次温度有效时重新计算。

## 8. 执行前人工检查

- 计划日和适用开盘日是否正确。
- 账户、持仓、温度和榜单是否来自允许窗口。
- 资金调拨是否只使用“策略或组合的当前承载通道 <-> 现金池”的星型关系。
- 触发类型是否正确；月度软偏离是否只使用新增本金和真实可用现金，季度硬偏离是否确实越过外侧线并按半带宽修复。
- `A_exec` 是否只扣除部分可执行顶层方案中 A 的净调出，是否把 B、C 的星型调拨动作重复扣减，或者在 A 为净调入方时错误计入尚未到账的赎回。
- 本次标记为立即可执行的现金池调出是否超过当前真实可转账现金；A 不是顶层净调入方时，计划终态现金是否在计入已批准高配调入后回到按 `A_exec` 计算的动态目标附近；A 为净调入方时，是否错误预先安排了未到账赎回款的用途。
- 股票与转债订单是否满足单位、过滤和风险约束。
- 粗略费用是否已占用现金；股票订单数、股票计划卖出金额和可转债计划总成交额是否与费用口径一致。
- Top 20 或合格目标转债的最低交易单位是否可执行，显著不等权是否已经明确提示。
- 股票计划持仓是否都不超过计划日口径下的 `10%`硬上限；已有持仓越线时是否已经优先减回 `5%`目标附近，或者明确报告无法卖出的真实原因。
- 余现修补是否只增加买单，没有为用完现金额外制造普通卖单。
- B、C 申赎是否符合平台颗粒度和已经确认的顶层规则。
- B 申购是否满足本次真实 QDII 上限；是否错误累计多日限额、历史低配、错过收益或未来可能额度。
- 新增 B 承载通道是否已经通过完整职责审查，所有通道是否只汇总为一个 B 目标。
- 不能把投顾组合内部交易误写成自行管理的基金订单，也不能把旧的国内长钱阈值或 A 内部千元阈值当成顶层卖出线。
- 是否存在实现方便替代投资规则的情况。
- 是否把尚未卖出、赎回或到账的资金错当成本次可用现金，或为其建立了跨计划待办。

## 9. MVP 交付边界

ark-quant 当前交付物止于：

```text
本次计划输入
资金调拨计划
股票交易计划
可转债交易计划
本次未补足的有效低配缺口及原因
暂停原因和人工检查项
```

资金调拨计划对每个相关策略或组合对象至少列出：对象名称、当前承载通道、当前金额、动态目标金额、完整净调整缺口、阈值判断、本次调拨金额和未补足原因。这些字段用来区分“理想中心”与“本次真实能做的动作”，不组织成资金来源链或跨计划待办。

股票和可转债交易计划还应分别列出：本次可执行策略预算、估算价格基准日、现有可用现金、本次调入与调出、账户内计划卖出所得、粗略费用预留及计算基数、理论目标金额、目标手数、当前手数、计划后估算权重、按执行顺序排列的净卖单与净买单、无法继续分配的自然残余现金及原因，以及交易单位可执行性或显著不等权告警。股票计划还必须列出单只 `10%`硬上限检查和容量冲突；可转债买单还必须明确标注实际买入价低于 `130 元`的硬上限。

MVP 不负责记录实际成交、未成交、部分成交、费用、滑点、实际申赎、跨日进度或计划放弃原因，也不替代有知有行投资账本。下一次计划以届时的真实账户、持仓和现金快照为新事实，独立重新计算；旧计划只是一份历史计划输出，不自动成为下一次计划的待办任务。

## 10. 当前待决问题

- 目标态贪心、股票普通订单下限和余现修补在真实计划中的残余现金、目标偏差、订单数量、换手和短期反向交易，需要继续通过可追溯记录复盘；没有记录证据前不临时改参数。
