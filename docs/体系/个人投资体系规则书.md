# 个人投资体系规则书

> 版本：2026-07-13
> 定位：平台无关的个人投资体系规则书。
> 说明：本文沉淀的是投资体系，不绑定 ark-quant、Ghostfolio、果仁网、回测框架或任何具体软件。系统可以换，体系需要长期可迁移、可验证、可复盘。

## 1. 一句话定义

当前投资体系是一套服务于长期复利的个人投资体系：它把投资视为无限游戏，首要目标是不出局，其次是在可承受风险内提高长期复利速度。

体系以风险溢价为底层逻辑，主动拥抱小盘风格，用小市值股票承担主要权益风险溢价和小盘风险溢价；用多因子可转债承担防守型进攻角色；用投顾长钱账户承接国内基金配置；用海外长钱承担国别分散；用现金池保留低估再配置弹药。

它的目的不是预测短期涨跌，而是在可承受风险内，用清晰规则长期执行：

- 什么时候提高或降低风险暴露。
- 哪些资产参与国内再平衡。
- 资金应该从哪里流向哪里。
- 策略候选如何转化成可执行交易计划。
- 什么时候不操作。

## 2. 最重要的边界

真正属于个人、需要长期迭代的是投资体系；投资系统只是当前实现。

可以更换：

- 数据源，例如 AkShare、Tushare、网页抓取、CSV、商业数据。
- 回测框架，例如 backtrader、vectorbt、果仁网、其他平台。
- 账户与组合管理底座，例如自建 Web、Ghostfolio、表格、笔记系统。
- 执行界面，例如本地页面、命令行、券商导出表、自动化脚本。

不应轻易更换：

- 资产类别、策略、账户三类概念及国内再平衡目标定义。
- 仓位公式。
- 再平衡纪律。
- 策略筛选口径。
- 执行红线。
- 复盘与改规则的流程。

平台迁移的核心要求是：新平台必须能表达这些规则，而不是反过来让规则迁就平台。

## 3. 投资哲学

体系建立在几个基本判断上：

- 人生和投资都是无限游戏。短期一关两关打得漂亮不重要，重要的是不出局、走得久、走得远。
- 普通人最触手可及的财富解药是复利，但复利需要足够长的时间、足够强的内心，以及足够稳定的纪律。
- 长期收益主要来自承担有补偿的风险，而不是持续预测市场。
- 股票长期存在权益风险溢价，小盘风格长期存在额外风险溢价。即使小盘溢价阶段性摊薄，底层仍有股票风险溢价作为长期收益来源。
- 全市场温度不是短期预测工具，而是市场整体加权估值水位仪。模糊的正确胜过精确的错误。
- 可转债是 A 股市场少数仍具机制优势的不对称资产之一，股债双性使其成为防守型进攻资产。
- 单一资产或单一策略都可能长期失效或阶段性大幅回撤，因此需要多层分散。
- 再平衡不是为了精确择时，而是把不同资产、策略、标的之间的相对偏离转化成机械动作。
- 现金不是闲置资金，而是低位再配置和系统生存的弹药。
- 投资服务生活，不允许为了系统收益破坏家庭现金流和生活安全边界。
- 体系目标不是无约束收益最大化，而是在不破坏生活、不被波动击穿、不因情绪犯大错的前提下，尽量提高长期复利速度。

### 3.1 外部理论锚

本体系的形成早于有知有行《中国大类资产投资年报 / SBBI China Yearbook》。年报不是体系的来源，而是外部验证材料和长期校准参照。

体系本身先基于以下判断形成：

- 股票长期存在权益风险溢价。
- 小盘风格长期存在额外风险补偿。
- 可转债具备股债双性和机制优势。
- 资产配置有助于提高长期可坚持性。
- 现金池提供生存权、调拨权和低估再配置权。
- 海外长钱提供国别分散。

《中国大类资产投资年报》中关于中美大类资产长期收益、股票风险溢价、小盘风险溢价和各类资产风险补偿结构的呈现，侧面印证了本体系在战略层面的合理性。

因此，SBBI China 在本体系中的定位是：

- 作为长期世界地图，而不是短期交易信号。
- 作为战略复盘参照，而不是仓位公式的每日输入。
- 用于校准风险溢价是否仍然存在，而不是因为单年数据变化机械改规则。
- 用于增强长期执行信心，而不是替代个人风险承受能力判断。

体系不因某一年报而成立，也不因某一年报更新而自动改变。只有当长期数据、制度环境和个人约束共同指向同一个方向时，才进入年度复盘讨论。

## 4. 三类核心概念

讨论投资对象时，必须区分资产类别、策略和账户三类概念；国别是资产或策略的风险暴露属性，不单列为一层。

| 概念 | 问题 | 当前口径 |
| --- | --- | --- |
| 资产类别 | 买的是什么 | 股票、可转债、基金、现金 |
| 策略 | 如何在账户间或账户内做决策 | 资金调拨策略；账户内的小市值股票、多因子可转债 |
| 账户 | 放在哪里、如何执行 | 广发账户、华泰账户、长钱账户、海外长钱、资金账户 |

### 4.1 资产类别

| 资产类别 | 当前承载 | 主要收益来源 |
| --- | --- | --- |
| 股票 | 小市值股票策略 | 权益风险溢价、小盘风险溢价、市值因子暴露 |
| 可转债 | 多因子可转债策略 | 股债双性、转股期权、债底保护、市场结构和机制优势 |
| 基金 | 国内长钱投顾、海外长钱投顾 | 长期资产配置、管理人能力、国别分散 |
| 现金 | 资金账户现金池 | 再平衡选择权、低估买入弹药、系统生存空间 |

### 4.2 国别属性

| 国别 | 包含 | 是否参与国内再平衡 |
| --- | --- | --- |
| 国内 | 股票、可转债、国内基金、现金 | 是 |
| 海外 | 海外基金 | 否，单独追踪，承担国别分散 |

### 4.3 策略分层与当前账户承载

| 策略层次 | 策略/组合 | 当前执行或承载位置 | 角色 |
| --- | --- | --- | --- |
| 资金调拨策略 | 资金调拨/再平衡轮动 | 广发、华泰、雪球投顾组合、浦发之间 | 按组合目标控制账户间资金流向 |
| 账户内 | 小市值股票 | 广发账户 | 账户内选股、轮动和下单 |
| 账户内 | 多因子可转债 | 华泰账户 | 账户内选债、轮动和下单 |
| 托管组合 | 长钱投顾组合 | 雪球基金托管 | 国内基金长期配置 |
| 托管组合 | 海外长钱投顾组合 | 雪球基金托管 | 海外分散，单独追踪 |
| 资金承载 | 现金池 | 浦发银行 | 再平衡中转与缓冲 |

### 4.4 国内再平衡目标

资金调拨/再平衡是一条资金调拨策略：它直接以各策略/组合的目标金额及偏离控制账户间资金流向；账户仅负责承载和执行。

| 国内再平衡目标 | 当前承载账户 | 参与国内再平衡 | 主要规则 |
| --- | --- | --- | --- |
| 小市值股票 | 广发账户 | 是 | 策略筛选、分散持有、定期轮动 |
| 多因子可转债 | 华泰账户 | 是 | 多因子筛选、分散持有、规避强赎和流动性风险 |
| 长钱账户 | 雪球基金托管下的长钱投顾组合 | 是 | 投顾基金配置，申赎按可执行颗粒度近似目标 |
| 现金池 | 浦发银行 | 是 | 根据市场温度动态变化，作为调拨中转 |
| 海外长钱 | 雪球基金托管下的海外长钱投顾组合 | 否 | 单独追踪，原则上不卖出参与国内再平衡 |

家庭生活备用金不属于投资资产，不进入本体系。

当前具体承载关系是：广发承载小市值、华泰承载多因子转债、雪球基金托管下的两个投顾组合承载国内/海外长钱、浦发承载现金池；资金调拨策略协调这些账户之间的资金。这只是当前运行安排，不是体系约束。新增账户不自动意味着新增策略；只有新增真正不同的策略或资产角色时，才需要新增目标金额规则或修改仓位公式。

## 5. 核心输入

每次生成交易计划，只需要少量动态输入。平台可以不同，但输入语义必须一致。

| 输入 | 含义 | 约束 |
| --- | --- | --- |
| 全市场温度 | 国内市场估值/情绪温度，取值 0-100 | 来源要可追溯，失败时不估温替代 |
| 账户快照 | 各账户当前金额、可用现金、更新时间；金额须可归属到策略/组合 | 必须保留真实更新时间 |
| 股票持仓 | 股票代码、名称、股数、口径日期 | 必须是真实持仓，不用估算替代数量 |
| 转债持仓 | 转债代码、名称、张数、口径日期 | 必须是真实持仓，不用估算替代数量 |
| 股票策略榜单 | 某一数据基准日的股票候选及排序 | 必须能追溯到数据日期和策略参数 |
| 转债策略榜单 | 某一数据基准日的转债候选及排序 | 必须能追溯到数据日期和策略参数 |

交易计划生成时，温度、股票榜单、转债榜单必须明确计划口径日；账户快照和持仓快照只保存事实状态、口径日期和更新时间，不在账户层保存交易归属日。服务端生成计划时，应取计划日到适用开盘日之间的最新事实快照作为输入。不能用上周榜单配本周账户生成计划。

## 6. 仓位公式

设：

```text
T_raw = 全市场温度，范围 0-100
T_norm = T_raw / 100
国内总资产 = 广发账户总资产 + 华泰账户总资产 + 长钱账户总资产 + 资金账户余额
```

现金目标：

```text
现金 = 国内总资产 x 20% x T_norm
```

国内非现金资产：

```text
B = 国内总资产 - 现金

长钱账户 = B x 20%
多因子可转债 = B x 80% x (30% + 0.4% x T_raw)
小市值股票 = B x 80% x (70% - 0.4% x T_raw)
```

解释：

- 温度越低，现金越少，小市值股票占比越高。
- 温度越高，现金越多，可转债占比越高。
- 长钱账户是国内基金投顾配置，在非现金资产中保持相对固定比例。
- 海外长钱单独跟踪，不进入国内仓位公式。
- 公式给出目标锚点，执行允许颗粒度误差。例如长钱账户底层为基金投顾，卖出可能只能按整数百分比执行，实际操作取最接近目标的可执行比例即可。

## 7. 策略模块

### 7.1 小市值股票策略

定位：大当家，主要进攻核心。

体系主动选择拥抱小盘风格。小市值策略是当前表达小盘风格和市值因子暴露的战术方式，而不是不可替代的唯一形式。长期信仰是小盘风险溢价和权益风险溢价，当前实现是小市值股票轮动。

当前策略口径：

- 股票范围：A 股主板与中小板，排除创业板、科创板、北交所、B 股。
- 风险过滤：排除 ST、退市、停牌、涨停、跌停等不可正常交易标的。
- 财务与交易过滤：成交额、PE、ROE 等必须满足最低要求。
- 排序规则：以总市值从小到大为核心排序。
- 持仓方式：分散持有，约 20 只。
- 轮动原则：根据排名和卖出阈值替换不再符合规则的持仓。

体系层面只要求它输出：

```text
日期、策略版本、参数版本、候选代码、候选名称、排序、评分或关键指标
```

具体由哪个平台计算并不重要，但输出必须可复现、可回测、可追溯。

如果小市值策略阶段性跑输，先复查当前策略表达是否需要升级，例如小盘质量、小盘价值、小盘低波、小盘动量或小盘多因子，而不是直接否定小盘风格。

### 7.2 多因子可转债策略

定位：二当家，防守型进攻资产。

可转债兼具股性和债性，是 A 股市场中少数仍具机制优势的不对称资产。它的进攻性通常弱于小市值股票，但在熊市和权益市场回撤中更有防守托底价值。体系持有可转债不是为了凑配置，而是为了获得股债双性、债底、转股期权、强赎/下修等机制所带来的可筛选收益。

当前策略口径：

- 数据口径：使用已完成交易日收盘数据。
- 基础过滤：价格、剩余规模、成交额、强赎风险、ST 正股、到期时间。
- 因子方向：双低、正股动量、低波动、小市值等。
- 持仓方式：分散持有，约 20 只。
- 交易约束：以张为单位，通常按 10 张整数倍执行。

体系层面只要求它输出：

```text
日期、策略版本、参数版本、候选代码、候选名称、排序、评分、关键风险字段
```

只要输出满足这个接口，策略可以在自建代码、回测框架或第三方平台上运行。

### 7.3 投顾-长钱账户

定位：国内基金投顾配置。

长钱账户既是资产配置的一部分，也是愿意交托给投顾的长期资产。它不是备用现金，也不是简单防守仓，而是体系中的长期基金配置模块。

主要作用：

- 降低全部资产都由自己亲手操作带来的认知负担。
- 提供与小市值股票、多因子可转债不同的配置节奏。
- 在国内再平衡中承担相对稳定的基金目标配置。

执行原则：

- 长钱账户参与国内再平衡，但不追求精确到元。
- 底层基金申赎有执行颗粒度，例如按 1% 或平台允许的最小比例操作。
- 调拨计划给出目标方向，实际执行选择最接近目标的可执行百分比。

### 7.4 投顾-海外长钱

定位：海外基金投顾配置和国别分散。

海外长钱单独追踪，不参与国内再平衡。它的主要作用是降低单一国家、单一市场环境对家庭长期资产的影响。

海外长钱原则上不作为国内调拨资金来源。除非家庭资产结构或长期规则发生重大变化，否则不因国内市场短期涨跌卖出海外长钱。

### 7.5 现金池

定位：再平衡弹药和资金中转。

现金池不是收益拖累，而是体系在低估市场继续下注的选择权。它同时承担：

- 高温阶段降低纯风险资产暴露。
- 低温阶段为小市值股票和可转债提供买入弹药。
- 承接卖出、银证转出、基金赎回等资金流。
- 降低因现金不足导致的误买和被动卖出风险。

## 8. 决策流水线

一份有效交易计划应由以下步骤生成：

> 战术细则见 [交易与调拨战术规则](交易与调拨战术规则.md)。

```text
1. 固定计划口径日 T
2. 获取并保存 T 日全市场温度
3. 获取并保存计划输入窗口内最新账户快照
4. 获取并保存计划输入窗口内最新股票持仓与转债持仓
5. 生成或读取 T 日股票策略榜单
6. 生成或读取 T 日转债策略榜单
7. 按仓位公式计算各策略/组合的国内再平衡目标金额
8. 生成资金调拨计划
9. 基于调拨后可用现金生成股票和转债订单
10. 执行前人工检查
11. 执行后写回真实成交、持仓和现金
```

如果任一输入缺失、日期不一致、数据源失败或榜单不完整，应暂停生成计划。宁可没有计划，也不要生成错误计划。

## 9. 资金调拨原则

资金调拨服务于各策略/组合的再平衡目标，不服务于单个账户满仓偏好。

优先顺序：

1. 先判断四个国内再平衡目标相对目标金额的高配/低配。
2. 超配的股票或转债账户先通过卖出或少买释放资金。
3. 现金池作为中转枢纽，承接卖出、银证转出、基金赎回。
4. 低配的股票或转债账户再转入资金并执行买入。
5. 长钱账户按可执行颗粒度近似目标，偏离很小时可以不动，避免基金申赎摩擦。
6. 海外长钱不作为国内调拨资金来源。

交易顺序原则：

```text
先卖出或释放资金 -> 再调拨 -> 再买入
```

这样可以降低现金不足和误买风险。

## 10. 执行红线

以下规则优先级高于单次收益机会：

- 不使用杠杆、配资、融资融券或借贷加仓。
- 不把家庭生活备用金纳入投资资金池。
- 不绕过策略规则重仓单一标的。
- 不因社群热点或短期故事临时纳入体系外资产。
- 不在未取得有效温度和有效榜单时生成交易计划。
- 不混用不同日期的账户、温度、榜单、持仓。
- 不为短期亏损临时修改参数。
- 不把阶段性高收益外推为长期预期。
- 不把系统显示结果视为事实，券商真实成交和真实持仓优先。
- 不因为小盘、可转债或温度纪律阶段性不舒服，就在非复盘窗口临时改规则。

重大规则改动前必须回答：

```text
这个改动在过去哪个阶段会让我亏损？
这个改动解决的是长期问题，还是只是在回应最近一次不舒服？
```

回答不清楚，不改。

## 11. 数据与系统原则

数据和系统是工具，不是体系本身。

数据层原则：

- 外部数据源可以外包，数据口径必须落地成可追溯快照。
- 策略计算优先读取本地快照，不直接依赖实时网页状态。
- 数据源失败时不手工猜测，不用旧数据伪装成新数据。
- 回测数据、实盘数据、展示数据应有清晰边界。

系统层原则：

- 账户更新时间是事实，不能为了交易计划改写。
- 交易计划应绑定具体输入版本，而不是绑定“最新数据”。
- 订单应绑定具体计划版本，而不是由页面实时重算。
- 平台可以更换，但必须保留导出能力和迁移路径。

## 12. 回测定位

回测不是投资体系的全部，也不必由方舟计划自研。

回测应回答：

- 这个策略长期收益、回撤、波动和换手是否可接受。
- 当前参数是否仍有基本合理性。
- 再平衡是否改善了组合体验。
- 策略失效时可能以什么形态出现。

回测不应承诺：

- 未来收益率。
- 某年一定跑赢。
- 极端环境下没有回撤。

体系需要的是可迁移的策略信号接口，而不是绑定某一个回测引擎。

## 13. 复盘机制

### 13.1 每次交易后

记录：

- 实际成交。
- 未成交原因。
- 账户现金变化。
- 持仓数量变化。
- 与计划不一致之处。

### 13.2 周度或本轮执行后

检查：

- 是否严格使用同一天输入。
- 是否有数据源异常。
- 是否有手工绕过规则。
- 是否存在小额调拨过度操作。

### 13.3 年度复盘

年度复盘是主要参数修改窗口。

复盘内容：

- 小市值策略相对基准是否健康。
- 可转债策略是否仍有分散和防御性进攻作用。
- 长钱和现金是否有效降低系统脆弱性。
- 海外资产是否仍承担国别分散功能。
- SBBI China 等外部理论锚是否仍支持当前风险溢价世界观。
- 仓位公式是否仍匹配家庭风险承受能力。
- 是否出现体系外主观交易。
- 是否需要新增、降权、暂停某个策略。

原则：不因短期亏损改参数，只因长期证据和个人约束变化改规则。

### 13.4 失效处理

体系区分战略信仰和战术表达。

战略信仰包括：

- 长期复利优先于短期胜负。
- 股票风险溢价长期存在。
- 小盘风格长期存在有补偿的风险溢价。
- 可转债仍具机制性不对称价值。
- 资产配置、现金和国别分散提高体系生存能力。
- SBBI China 等外部材料用于校准长期世界地图，不用于触发短期交易。

战术表达包括：

- 当前小市值股票筛选规则。
- 当前多因子可转债筛选规则。
- 当前温度来源和仓位公式参数。
- 当前投顾和账户平台。

处理原则：

- 小市值策略连续跑输时，先复查当前表达方式是否需要升级，不直接否定小盘风格。
- 可转债策略阶段性跑输时，先检查转债估值、溢价率、强赎环境、流动性和筛选因子，不直接取消转债策略。
- 温度纪律错过牛市时，视为估值纪律的机会成本，不单独作为修改温度规则的充分理由。
- 长钱投顾阶段性跑输时，优先检查是否偏离其承诺风格和配置目标，而不是只看短期收益排名。
- 重大规则变化只在年度复盘或家庭风险约束发生实质变化时讨论。

### 13.5 体系免疫系统

本体系允许进化，但不允许情绪化漂移。它需要在未来痛苦时区分三件事：

- 短期波动带来的不舒服。
- 长期证据或制度环境变化带来的战略问题。
- 当前表达方式、账户、平台或工具不再合适带来的实现问题。

#### 13.5.1 失败定义

体系失败不是短期亏损、阶段性跑输、某个账户回撤，也不是某一年收益不好。

体系失败是：这套体系不再能帮助我长期、稳定、可坚持地暴露于有补偿风险，或者它开始伤害我的生活、纪律和内心稳定。

失败信号包括：

- 生活失败：投资影响家庭现金流、生活备用金、安全感或重大生活安排。
- 执行失败：反复无法按规则执行，频繁主观改计划。
- 纪律失败：因为贪婪、恐惧、社群热点、短期排名而破坏体系。
- 证据失败：长期数据和制度环境显示某个战略假设明显变化，但拒绝复盘。
- 结构失败：单一资产、单一策略、单一平台或单一国家风险大到击穿体系。

亏损本身不是失败。亏损导致体系无法继续执行，才是失败。

#### 13.5.2 战略升级条件

战略升级只能回应长期结构变化，不能回应短期情绪疼痛。

只有当长期证据、制度环境、策略表现和个人约束中至少两项同时发生变化，才进入战略升级讨论。

允许讨论战略升级的情况包括：

- 小市值长期拥挤、退市制度变化、流动性恶化，导致当前小盘表达方式需要升级。
- 可转债制度、强赎/下修机制、市场结构发生变化，导致不对称收益明显削弱。
- 家庭资产规模、现金流、职业风险、住房、育儿或养老目标发生实质变化。
- 全市场温度来源失真、不可持续，或不再能代表市场整体估值水位。

不允许因为以下原因升级战略：

- 最近亏了。
- 最近跑输别人。
- 看了某个短期观点。
- 牛市后半段现金拖累收益。
- 小盘、可转债或温度纪律阶段性让人不舒服。

#### 13.5.3 模块替换原则

底层信仰优先于当前实现。具体策略、因子、账户、投顾、数据源、系统和执行工具都只是表达方式，可以替换；但替换前必须说明：替换的是模块，不是因为短期痛苦而否定底层信仰。

模块替换规则：

- 小市值股票：可替换当前筛选规则，不轻易放弃小盘风格；优先升级为小盘质量、小盘价值、小盘低波、小盘多因子等表达。
- 多因子可转债：可替换因子、过滤条件和轮动规则；不因短期收益弱就取消转债策略；只有机制优势明显消失，才讨论战略降权。
- 长钱账户：不因短期跑输替换；只有价值观漂移、利益结构漂移、产品定位漂移、信任关系破裂、监管或基础设施风险，才考虑替换。
- 海外长钱：不因国内市场高低切换；只在家庭战略、国别风险判断或长期资产安排变化时调整。
- 现金池：不因牛市拖累收益取消；只有家庭现金流、风险承受力或估值纪律发生长期变化，才调整现金规则。

## 14. 平台选择标准

任何未来底座、平台或开源项目，都按以下标准评估：

| 标准 | 问题 |
| --- | --- |
| 资产表达 | 能否表达股票、可转债、基金、现金这些资产类别 |
| 概念映射 | 能否区分资产类别、策略和账户；国别是否作为资产/策略属性表达 |
| 多账户 | 能否表达多个券商/基金/现金账户 |
| 策略接口 | 能否导入或计算股票、转债候选榜单 |
| 调拨计划 | 能否支持账户间资金流向和执行顺序 |
| 日期绑定 | 能否绑定同一天账户、温度、榜单、持仓 |
| 可追溯 | 能否保存历史计划和输入快照 |
| 可迁移 | 能否导出数据，避免被平台锁死 |
| 心智成本 | 是否比当前系统更省心，而不是更复杂 |

如果一个平台只能提供漂亮界面，却不能表达日期绑定、调拨和策略信号，它只能作为展示层，不能作为体系核心。

## 15. 当前体系接口

为了保持迁移能力，长期应把体系抽象成以下接口：

```text
MarketTemperatureProvider
  -> date, temperature, label, source, updated_at

AccountSnapshotProvider
  -> date, account_id, strategy, asset_class, country, total_value, available_cash, updated_at

PositionProvider
  -> date, strategy, code, name, quantity

StrategySignalProvider
  -> date, strategy, version, rank, code, name, score, fields

AllocationPolicy
  -> date, domestic_total, temperature, target_values

TransferPlanner
  -> date, current_values, target_values, transfer_steps

TradePlanner
  -> date, plan_id, strategy_signals, positions, cash_after_transfer, orders
```

只要这些接口存在，底层可以是自建代码、GitHub 项目、表格、商业平台或混合方案。

## 16. 最终原则

当前投资体系的长期资产不是代码，而是规则。

系统应该做到：

- 帮助执行规则。
- 暴露输入缺失。
- 阻止错误混用。
- 保留可复盘证据。
- 降低心智负担。

系统不应该：

- 替代投资判断体系。
- 因实现方便扭曲规则。
- 让个人被平台锁死。
- 在数据不完整时假装确定。

一句话：投资体系跟人走，投资系统随行就市。
