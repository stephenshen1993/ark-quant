# 账户页清理 — 2026-07-03

## 问题

1. 账户列表（5行）和下方的持仓表/简单账户卡片是同一份数据的两种展示，冗余
2. 点击 stock/cb 行触发 loadQuotes，但无详情页可导航，`›` 箭头误导
3. 行情需手动点击加载，但用户工作流是打开页即需要对着现价编辑持仓
4. 残留旧详情页死代码：`view`, `selectedAccount`, `back`, `currentAccount`, `savePositions`, `snapSaved`, `autoSaved`, `quotesLoading`

## 设计

### 布局：纯表单流

```
┌─ 总资产 ¥xxx ─── [占比条 + 图例] ─── 更新于 xxxx-xx-xx ─┐
│                                                          │
│  ┌─ 广发账户 · 股票 ──── 现金 ¥[____] ─────── [保存] ─┐ │
│  │  代码   名称   股数   现价   市值   占比        ✕   │ │
│  │  [+ 添加行]                                       │ │
│  └───────────────────────────────────────────────────┘ │
│                                                          │
│  ┌─ 华泰账户 · 转债 ──── 现金 ¥[____] ─────── [保存] ─┐ │
│  │  (同上)                                             │ │
│  └───────────────────────────────────────────────────┘ │
│                                                          │
│  ┌─ 长钱账户 ────┐ ┌─ 资金账户 ────┐ ┌─ 海外长钱 ────┐  │
│  │ ¥[________]   │ │ ¥[________]   │ │ ¥[________]   │  │
│  └───────────────┘ └───────────────┘ └───────────────┘  │
```

### 关键变更

1. **删除账户列表区块**（lines 73-110）：不再需要，数据已平铺在下方
2. **行情自动加载**：`load()` 中直接调 `loadQuotes('stock')` 和 `loadQuotes('cb')`，不再等点击
3. **删除死代码**：`view`, `selectedAccount`, `snapSaved`, `autoSaved`, `quotesLoading`, `back()`, `currentAccount()`, `savePositions()`
4. **简化 `openDetail`**：不再需要，直接删掉。行情已在 load() 中加载
5. **删除 `loaded` 状态**：既然 load() 就加载行情，loaded 恒为 true，不需要这个标记

### 不做

- 不改保存逻辑（stock/cb 手动保存按钮，简单账户 @change 自动保存）
- 不改 DB schema
- 不改后端 API
