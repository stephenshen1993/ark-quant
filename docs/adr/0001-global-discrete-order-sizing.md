# 全局离散订单定额

状态：已接受。两个账户的普通交易计划均固定为合格 Top 20；候选不足 20，或任一目标的最低交易单位超过账户策略预算的 10%，即为容量冲突并暂停普通计划。理论等权为 5%，共同单标的风险防线为其两倍，即 10%。对股票和可转债的交易计划，目标集合、可交易性、当日真实可用资金、交易单位和已启用的统一单标的风险防线是唯一硬约束；等权偏离、资金利用率和预计摩擦成本在满足硬约束的可行组合之间共同权衡。无归因可投资余现作为理论权重为零的虚拟仓位参与整体等权偏离，因此“等权”不再忽略大额闲置现金。选择全局离散定额而非逐手贪心，是因为高价标的一手可能跨越理论目标，局部“最欠配”并不等于组合层面的较优结果。

## 考虑过的方案

- 保持局部余现修补：可解释，但会在离散交易单位下留下大额现金，或因逐手选择而产生不必要的偏离与换手。
- 把等权或资金利用率之一设为绝对优先：规则简单，但会把另一项的合理取舍伪装成算法错误。

## 后果

正式算法在内部比较满足硬约束的目标手数组合，依次比较：包含无归因可投资余现的最大整体偏离、全体整体偏离、余现金额、预计摩擦成本与普通订单数；整体偏离的精确定义见 [账户内交易定额规则](../体系/账户内交易定额规则.md)。必要卖出由策略规则预先确定；余现修补只允许新增合规买入，不得为用完现金或改善表面等权制造普通卖单。复核输出必须报告整体偏离、余现归因和预计摩擦。候选组合不构成多份用户计划：日常生成始终只输出由公开、可版本化的订单定额偏好规则自动选定的一份完整计划，不要求用户在多个候选方案中每日选择。
