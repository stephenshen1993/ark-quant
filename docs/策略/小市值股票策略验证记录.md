# 小市值股票策略验证记录

> 状态：当前策略基线的非规范性证据档案
> 职责：记录策略配置来源、历史回测、智能调优、实盘表现与证据边界。
> 真源范围：验证事实及其口径，不定义或修改策略规则。
> 不负责：账户间资金调拨、目标金额、工程实现或未来收益承诺。
> 最后核对：2026-07-19

## 1. 结论

当前小市值股票策略不是临时拍定的参数组合。它已经经过果仁长期历史回测、果仁智能调优以及广发账户持续实盘检验，足以确认为当前账户内策略基线。验证证据支持“保持规则、长期执行”，不支持把回测收益当作承诺，也不支持根据近期表现继续寻找更激进参数。

规则真源见 [小市值股票策略规则](小市值股票策略规则.md)。本文件只记录为什么当前版本可以被信任，以及哪些问题仍不能由现有证据回答。

## 4. 长周期回测与智能调优

用户说明：在果仁会员有效期间，曾使用接近 20 年数据回测，并尝试使用智能调优；更高排名多数需要明显提高交易频率，不适合当前人工执行条件。当前保存的 [智能调优结果](小市值研究/证据/果仁智能调优结果.xlsx)包含 200 条试验记录，但文件本身没有保存回测起止日期和目标函数公式。

序号 1 与当前策略参数一致，目标函数结果归一化为 `1`：

| 指标        |    当前策略记录值 |
| --------- | ---------: |
| 年化收益      |   `36.95%` |
| 夏普比率      |    `0.978` |
| 最大回撤      |   `72.81%` |
| 收益波动率     |   `33.68%` |
| 信息比率      |    `1.415` |
| 近期收益      |   `18.86%` |
| 年换手率      | `1483.26%` |
| 平均持有天数    |    `16.97` |
| 平均持仓股票数   |    `19.99` |
| 调仓指令可执行比例 |   `99.06%` |
| 交易赢率      |   `57.58%` |
| 换股次数      |     `5245` |

对全部记录的对抗审查结果为：

- 200 次试验中，51 个目标函数得分高于当前方案。
- 其中 46 个采用 1 个交易日调仓；另外 2、3、4、6、11 个交易日调仓各有 1 个。
- 51 个更高分方案全部把当日成交额下限降为 `0`；其中 50 个把 EP 下限设为 `0`。
- 当前方案在该批所有 5 个交易日调仓试验中排名第一，但该批试验没有对 5 日附近进行充分局部穷举，不能据此声称数学意义上的全局最优。

这批结果显示，优化器找到的主要纸面提升来自更频繁轮动和取消流动性下限，而不是一组稳定、精确的质量阈值。更高分方案可能引入更深的小微盘暴露、滑点、成交困难、资金容量和人工操作压力；因此当前版本应理解为收益、流动性和人工可执行性之间经过验证的选择，而不是简单放弃无成本收益。

长期记录中的 `72.81%`最大回撤也表明该策略可能经历极深回撤。高历史收益不能代替全体系的股票、可转债、基金、现金及国别分散，更不能成为提高股票战略占比或使用杠杆的理由。

广发账户证明当前策略在现实条件下具有可执行性和获利记录，但不是果仁理论净值的精确复制。资金加权收益还会受到入金、出金和执行时点影响，不能与固定初始本金回测收益直接做等号比较；ark-quant 的 MVP 也不因此承担投资账本迁移或逐笔跟踪误差计算。

## 6. 证据边界

现有材料仍不能独立回答：

- 果仁长期回测的准确起止日期、目标函数公式和完整调优搜索空间。
- 果仁对历史退市股票、财务数据披露时点、`主板等`、涨跌停标记和备选买入的精确定义。
- 理论回测中的滑点、冲击成本、最低佣金与当前真实成交的逐笔差异。
- 广发账户每次计划、实际成交和未执行订单造成的精确跟踪误差。

这些边界要求对结论保持克制，但不足以推翻现有策略。没有新的完整、同口径、可复现证据时，保留当前策略规则比根据单次体验或近期曲线重新调参更可靠。
