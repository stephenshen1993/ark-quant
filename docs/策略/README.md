## 可转债研究材料

[可转债研究](可转债研究/README.md) 保存因子总账、阶段结论、对抗审查、前瞻影子清单和 CSV/JSON 证据附件。它们用于追溯研究过程，只有被写入当前策略规则后才成为执行规则。

## 小市值研究材料

[小市值研究](小市值研究/README.md) 保存小市值策略的回测、配置和取证附件。它们用于支撑验证记录，不直接替代当前策略规则。

资金调拨策略属于体系级战术，见 [仓位与再平衡规则](../体系/仓位与再平衡规则.md)。账户只是当前承载通道，不是策略。
