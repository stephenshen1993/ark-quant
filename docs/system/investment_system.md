# 投资体系说明书

> 版本：2026 年 6 月  
> 定位：个人长期投资体系说明、执行规则与复盘基准。  
> 说明：本文用于阐述个人投资系统，不构成投资建议。

## 一、体系定位

这是一套以风险溢价为理论基础、以小市值策略为进攻核心、以可转债和长钱账户为辅助配置、以现金池为再平衡弹药的个人长期投资体系。

它不是单一策略，也不是简单的股债现金配置，而是一个多层轮动、多维再平衡的个人资产操作系统。体系的目标不是预测市场短期涨跌，而是在长期可承受风险内，持续暴露于有补偿的风险资产，并利用资产、策略和标的之间的涨跌幅度差异进行再平衡。

系统设计的根本出发点是：

- 用规则替代判断。
- 用系统对抗情绪。
- 用多层分散提高生存能力。
- 用再平衡把波动转化为可操作空间。
- 让投资服务于生活，而不是占据生活。

## 二、核心机制：多层轮动与多维再平衡

体系的核心不是“死拿小盘股”，而是围绕小市值、可转债、长钱、海外资产和现金构建多层轮动结构。

| 层级 | 对象 | 机制 | 作用 |
| --- | --- | --- | --- |
| 标的内部 | 小市值股票、可转债 | 各自持仓约 20 只，按策略规则轮动 | 分散单一标的风险，持续暴露于有效因子 |
| 策略之间 | 小市值、可转债、长钱、现金 | 按市场温度与目标仓位动态再平衡 | 在不同风险资产之间腾挪资金 |
| 资产地域 | 国内资产、海外长钱 | 海外长期定投，原则上不再平衡卖出 | 降低单一国家市场风险 |
| 时间维度 | 周度、年度 | 全组合周度再平衡，年度审视 | 匹配不同资产特性，避免无效操作 |

这个体系的再平衡空间来自“不同步”，但这里的不同步并不要求某些资产上涨、某些资产下跌。更准确地说，只要各资产、策略、标的之间的涨跌幅度不同步，就存在相对高配与低配，也就存在轮动和再平衡空间。

即便多个资产同时下跌，只要跌幅不同，跌幅较小的资产、基金账户和现金账户就会在组合中被动变成相对高配，再平衡时可以回流到跌幅更大的资产，从而在低位获得更多份额。2024 年 4 月股票账户短期回撤超过 60% 时，转债账户、基金账户和现金账户相对抗跌，体系通过再平衡回流股票账户，获得了底部区域的筹码，这正是该机制的实盘体现。

因此，现金池并不是闲置资金，而是再平衡弹药。所谓“伪无限子弹”，不是现金真的无限，而是体系内不同资产的相对强弱不断变化，使得上涨或相对抗跌的一端可以持续为下跌更深的一端提供再配置空间。

## 三、收益来源

这套体系的收益来源可以拆成三层。

### 3.1 长期风险溢价

体系承认长期收益来自承担有补偿的风险，而不是来自持续预测市场。

根据 SBBI China 2005-2024 年数据：

| 资产类别 | 年化收益率 |
| --- | ---: |
| 小盘股 | 10.04% |
| A 股整体 | 9.63% |
| 大盘股 | 9.18% |

小盘股的长期超额收益来自两层补偿：

- 股票风险溢价：承担股权资产波动和企业经营风险。
- 小盘股溢价：承担小盘公司经营稳定性弱、流动性差、交易成本高等额外风险。

注：SBBI China 2025 年报已将统计区间更新至 2005-2025 年，A 股整体、大盘股、小盘股的年化收益分别更新为 10.40%、9.71%、10.87%。本文保留 2005-2024 年版本，是为了记录体系形成时使用的原始依据。

### 3.2 策略 Alpha

小市值股票策略是体系的进攻核心。策略参数在果仁网维护，以下为截至 2026-06-15 的完整回测结果（回测区间 2017/01/03–2026/06/15，单边交易成本千分之二，收益基准沪深300）：

| 指标 | 本策略 | 沪深300 |
| --- | ---: | ---: |
| 总收益 | 632.33% | 46.36% |
| 年化收益 | 23.47% | 4.12% |
| 夏普比率 | 0.68 | 0.01 |
| 最大回撤 | 44.55% | 45.60% |
| 收益波动率 | 28.58% | 18.44% |
| Alpha | 19.38% | — |

回测超额年化约 18.59%，但历史回测不代表未来收益，实盘执行存在拥挤度上升、容量限制、交易成本与回测偏差等衰减因素，不应直接外推。它不是单只股票押注，而是在小市值股票池中按规则筛选、分散持有、定期轮动。

可转债多因子轮动策略是进攻辅助。它利用可转债市场中价格、溢价率、强赎、流动性、债性与股性等因素进行规则化筛选和轮动。

两类策略都采用“策略内部摊大饼”的方式：不依赖单一标的成败，而是通过多标的组合承接因子暴露。

### 3.3 再平衡收益

体系试图获取的第三层收益，是策略间和资产间的再平衡收益。

当小市值、可转债、长钱、海外资产和现金之间出现相对涨跌差异时，系统会根据目标比例进行再平衡：卖出或少买相对高配资产，买入或多买相对低配资产。长期看，这相当于把不同步波动转化为低买高卖的机械动作。

体系追求的不是单纯超越大盘，而是在可承受回撤内，争取获得优于“死拿小盘股”的资金曲线体验和风险调整后收益。

## 四、资产架构

| 资产 | 角色 | 策略来源 | 内部分散 |
| --- | --- | --- | --- |
| 小市值股票 | 进攻核心 | 果仁网 15 年回测验证的小市值策略 | 持仓约 20 只 |
| 可转债 | 进攻辅助 / 防御性进攻 | 多因子轮动策略 | 持仓约 20 只 |
| 长钱账户 | 国内安全垫 | 有知有行投顾组合（可公网检索"有知有行长钱账户"） | 投顾内已分散 |
| 海外长钱 | 国别分散 | 有知有行投顾组合（可公网检索"有知有行海外长钱"） | 投顾内已分散 |
| 现金 | 再平衡弹药 / 择时工具 | 市场温度公式决定 | 不适用 |

按功能划分：

- 小市值股票负责主要进攻。
- 可转债负责辅助进攻，并在部分市场环境中承担相对防御功能。
- 长钱账户提供国内配置的稳定器。
- 海外长钱提供国别分散，不追求超额收益。
- 现金账户提供流动性、防御和低位再平衡弹药。

## 五、核心公式

### 5.1 现金仓位

设 `T_raw` = 全市场温度，取值范围为 0-100；`T_norm` = `T_raw / 100`，取值范围为 0-1。

> 数据来源：有知有行温度计（https://youzhiyouxing.cn/data），每日更新，使用时以当日最新读数为准。

```text
现金 = 国内总资产 x 20% x T_norm
```

含义：

- 温度接近 0 时，现金接近 0，体系接近满仓进攻。
- 温度接近 100 时，现金接近国内总资产的 20%，体系进入高位防御。
- 现金比例线性变化，不设置主观阈值。

### 5.2 国内非现金资产分配

设 `B = 国内总资产 - 现金`。

| 资产 | 计算公式 |
| --- | --- |
| 长钱 | B x 20% |
| 可转债 | B x 80% x (30% + 0.4% x T_raw) |
| 小市值 | B x 80% x (70% - 0.4% x T_raw) |

设计逻辑：

- 长钱账户作为安全垫，比例相对固定。
- 可转债与小市值共享剩余进攻额度。
- 低温时小市值占优，强化进攻。
- 高温时可转债占优，增强防御。

### 5.3 规则示例

以国内总资产 100 为基准：

| 温度 | 现金 | 长钱 | 可转债 | 小市值 |
| ---: | ---: | ---: | ---: | ---: |
| 0 | 0 | 20 | 24 | 56 |
| 50 | 10 | 18 | 36 | 36 |
| 100 | 20 | 16 | 44.8 | 19.2 |

## 六、执行机制

> **当前执行方式为周度再平衡**：每周选一个有空的交易日，完成全组合检查和调仓，当周调完即结束，不追加操作。周几不固定，以有时间为准。  
> 月度再平衡（降低摩擦成本）是待验证的优化方向，尚未切换执行。

### 6.1 周度整体再平衡

每周选一个交易日执行整体检查：

1. 查询全市场温度（https://youzhiyouxing.cn/data）。
2. 按公式计算现金、长钱、可转债、小市值目标金额。
3. 调整各账户仓位至目标。
4. 可转债总仓位调整与内部标的轮动在同一周期内一并完成。

### 6.2 可转债内部轮动

可转债内部轮动随周度整体再平衡同步执行：

1. 确认可转债目标总仓位。
2. 卖出信号变弱、风险上升或不再符合规则的标的。
3. 买入信号较强、符合规则的新标的。
4. 保持可转债总持仓金额与当周目标一致。

可转债轮动严格在 09:25 前或 15:10 后运行，使用前一交易日收盘数据，不做盘中操作。

### 6.3 小市值股票轮动

小市值股票策略按既定策略频率执行内部轮动，保持约 20 只分散持仓。该部分是体系的主要收益发动机，但不以单一股票为胜负手。

### 6.4 海外资产与增量资金

- 每月固定日期买入固定金额海外长钱。
- 海外长钱原则上长期持有，不卖出、不参与国内再平衡。
- 剩余增量资金进入国内现金池，在下一次月度再平衡时自动分配。

### 6.5 执行红线

以下规则不因市场涨跌、情绪高低、他人建议而动摇。违反任意一条须在年度复盘中记录原因。

**仓位与杠杆**
- 不加杠杆：不使用融资融券、配资或任何形式的借贷加仓工具。
- 不混用生活现金：家庭6个月以上生活备用金严格隔离，不纳入投资资金池。

**策略纪律**
- 不绕过策略规则重仓单一标的：所有买卖来自策略信号，不因"逻辑好"额外建仓。
- 不追涨停板：不在涨停状态下买入，策略信号以前一交易日收盘数据为准。
- 不盘中操作可转债：转债调仓严格在 09:25 前或 15:10 后执行。
- 不在未查温度的情况下调整仓位：调仓前必须完成温度查询，不凭感觉估温。
- 当周调仓结束后不追加操作：单次再平衡完成即关闭，不因日内波动补刀。

**参数与预期**
- 不因短期亏损修改参数：策略参数调整仅在年度复盘时进行，中途不动。
- 不外推阶段性高收益：任何账户的短期超额不作为长期预期依据，长期年化锚定SBBI基础收益区间。
- 不跟风纳入体系外资产：不因市场热点或社群推荐临时加入非体系资产（单一行业ETF、个股、热门赛道等）。

**体系变更**
- 重大规则改动须能回答"这个改动在过去哪个阶段会让我亏损"，不能回答则不改。

### 6.6 年度体系审视

每年进行一次体系级审视，这是唯一允许修改策略参数的窗口：

- 检查小市值、可转债、长钱、海外资产的策略健康度。
- 检查目标仓位公式是否仍符合个人风险承受能力。
- 检查过去一年是否有违反规则的主观交易。
- 只在有充分理由时调整参数，不为短期波动修改规则。

## 七、系统有效性验证

### 7.1 实盘阶段表现

用户自 2019 年入市，2022 年 3 月因结婚买房清仓。婚后重新入市后，截至 2026-06-14，有知有行投资汇总显示：

| 指标 | 数值 |
| --- | ---: |
| 统计天数 | 1096 天 |
| 资金加权收益率 | +63.57% |
| 年化收益率 | +18.34% |

当前账户年化收益分布：

| 账户 | 定位 | 年化收益率 |
| --- | --- | ---: |
| 广发账户 | 股票仓位 | +36.66% |
| 华泰账户 | 可转债仓位 | +20.74% |
| 海外长钱 | 海外基金 | +9.80% |
| 长钱账户 | 国内基金 | +8.14% |
| 资金账户 | 现金仓位 | +1.63% |

该收益分布符合体系设计：进攻账户贡献主要收益，长钱、海外长钱和现金承担稳定、分散和流动性功能。

### 7.2 极端回撤检验

2024 年 4 月，小市值股票账户短期回撤超过 60%。体系并未在低位停止运行，而是通过转债账户、基金账户和现金账户的相对抗跌部分回流股票账户，在底部区域获得更多份额。

这说明体系的关键不是避免所有回撤，而是在回撤中保持结构、纪律和再平衡能力。

## 八、风险边界

| 风险类型 | 说明 | 应对方式 |
| --- | --- | --- |
| 小盘风格集中 | 小市值长期可能跑输大盘，策略收益不会每年兑现 | 主动接受，作为体系核心风险溢价来源 |
| 策略失效 | 小市值和可转债策略可能受拥挤、容量、交易成本、制度变化影响 | 年度审视，建立账户级健康度监控 |
| 可转债复合风险 | 可转债不是纯防御资产，可能受到权益、信用、溢价率、强赎共同冲击 | 周度轮动，持续监控强赎和流动性 |
| 同步下跌风险 | 多数资产可能同时下跌；若跌幅高度同步，再平衡空间会下降 | 保留现金池和长钱账户，接受极端阶段系统承压 |
| 收益预期上移 | 阶段性高收益可能导致长期预期过高 | 长期预期以风险溢价为锚，不外推短期年化 |
| 生活现金流冲击 | 买房、结婚、家庭支出可能影响投资连续性 | 投资服务生活，家庭安全现金与长期投资资金分层 |

## 九、体系总结

这套体系的本质，是用规则持续捕捉风险溢价，用多层轮动利用波动差，用现金池和再平衡维持系统生命力。

它的核心公式不是某一个收益预测，而是一套执行原则：

- 长期收益来自承担有补偿的风险。
- 小市值股票是进攻核心，但不单独承担全部体系成败。
- 可转债、长钱、海外资产和现金共同提供腾挪空间。
- 下跌并不必然破坏体系，只要跌幅不同步，就仍有再平衡机会。
- 真正危险的是策略失效、相关性高度同步、现金流被生活事件打断，以及投资者本人无法继续执行。

最终目标不是追求每年最高收益，而是在长期可承受风险内，争取获得优于单一持有小盘股的资金曲线体验和风险调整后收益。

## 十、后续演进方向

下一阶段重点不是继续增加策略，而是把体系管理工程化：

1. 建立账户级健康度仪表盘：跟踪收益、回撤、基准对比、收益贡献。
2. 建立策略失效预案：明确观察、降权、暂停的触发条件。
3. 建立家庭资金分层：生活安全现金、中短期目标资金、长期投资资金分开。
4. 建立年度复盘模板：记录资产比例、最大回撤、策略表现、参数审视和执行纪律。
5. 验证再平衡效果：比较当前体系与单纯持有小盘股在收益、回撤、夏普、卡玛上的差异。
