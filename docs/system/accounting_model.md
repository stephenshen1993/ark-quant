# 账户与金额口径

> 用途：统一 Web 看板、体系再平衡、策略订单和人工录入时使用的账户概念。只要页面文案、API 字段或报告字段涉及资产、现金、持仓、市值，应先对齐本文。

## 核心原则

- 项目默认币种为人民币，金额单位为元。
- 用户界面展示金额时优先使用 `¥`，不在每个数值后重复写“元”。
- 指标名称需要消除歧义时，使用“总资产”“持仓资产”“可用现金”等业务词，不把单位混进字段名。
- 金额类数值默认保留 2 位小数。
- 大额概览可以使用“万”做紧凑展示，但详情、表格、输入和订单金额仍以元为准。
- 策略内部的“市值”只描述证券持仓价值；账户层面优先使用“资产”。

## 账户分层

| 账户 | 含义 | 是否参与国内再平衡 | 金额口径 |
| --- | --- | --- | --- |
| 广发账户 | A 股小市值策略账户 | 是 | 股票持仓资产 + 可用现金 |
| 华泰账户 | 可转债轮动策略账户 | 是 | 转债持仓资产 + 可用现金 |
| 长钱账户 | 国内基金或其他长期安全垫 | 是 | 账户总资产 |
| 资金账户 | 现金池、银证转出后可调拨资金 | 是 | 账户余额 |
| 海外长钱 | 海外基金或长期海外资产 | 否，单独追踪 | 账户总资产 |

家庭生活备用金不进入本项目投资资金池。

## 指标定义

| 指标 | 定义 | 页面用语 |
| --- | --- | --- |
| 总资产 | 一个账户的全部投资资产。股票/转债账户中等于持仓资产 + 可用现金。 | 总资产 |
| 持仓资产 | 当前证券持仓按最新可得价格估算的价值。 | 持仓资产 |
| 可用现金 | 券商账户内可用于买入、转出或参与调拨的现金。 | 可用现金 |
| 余额 | 现金账户的金额。现金账户没有证券持仓时，用“余额”比“总资产”更自然。 | 余额 |
| 账户占比 | 单账户总资产 / 看板总资产。 | 占比 |
| 持仓占比 | 单个证券持仓市值 / 当前策略账户持仓资产。 | 占比 |
| 市值 | 单个证券或一组证券持仓按价格估算的价值。 | 市值 |

## 总资产公式

看板总资产：

```text
总资产 = 广发账户总资产
      + 华泰账户总资产
      + 长钱账户总资产
      + 资金账户余额
      + 海外长钱总资产
```

国内再平衡总资产：

```text
国内总资产 = 广发账户总资产
          + 华泰账户总资产
          + 长钱账户总资产
          + 资金账户余额
```

海外长钱只进入看板总资产，不进入国内再平衡公式。

## 股票与转债账户

股票账户：

```text
持仓资产 = Σ(股票股数 × 最新价格)
总资产 = 持仓资产 + 股票账户可用现金
```

可转债账户：

```text
持仓资产 = Σ(转债张数 × 最新价格)
总资产 = 持仓资产 + 转债账户可用现金
```

股票持仓单位为股，买卖取整通常按 100 股；可转债持仓单位为张，买卖取整通常按 10 张。

## 输入与保存

- 股票/转债账户的持仓资产由持仓数量和报价估算，不建议手工输入。
- 股票/转债账户的可用现金需要人工输入，因为它来自券商账户实时状态。
- 长钱、资金账户、海外长钱目前由人工输入总额或余额。
- 每个账户都有独立快照。修改某个账户时，只写入该账户自己的 `account_value_snapshots` 记录。
- 日期和温度属于计划上下文，独立写入 `account_contexts`，不是任何账户的资产快照。
- 看板总资产是当前各账户最新快照的派生结果，不单独存储。
- 快照日期表示账户状态的口径日期，不一定等同于策略榜单的数据基准日。
- 策略计划日期口径为：基于 T 日收盘数据，生成 T+1 日开盘可执行计划。

## 数据模型

当前账户体系按事实分层：

| 表 | 含义 |
| --- | --- |
| `account_contexts` | 计划上下文：口径日期、全市场温度 |
| `account_value_snapshots` | 单账户资产快照：账户、口径日期、总资产、可用现金、写入时间 |
| `stock_positions` / `cb_positions` | 策略持仓快照：代码、名称、数量、持仓日期 |
| `account_snapshots` | 旧宽表，仅作为历史迁移来源，不作为新写入目标 |

账户总览使用 `/api/account/summary` 聚合当前上下文和各账户最新快照。兼容接口 `/api/account/latest` 仍可读取同一聚合结果，但新代码优先使用 `/summary`。

## 命名约定

推荐：

- 总资产
- 持仓资产
- 可用现金
- 余额
- 市值
- 占比
- 金额

避免：

- 账户总市值：账户包含现金，不应只叫市值。
- 账户资产（持仓+现金）：过长，详情页直接用“总资产”即可。
- 金额（元）和数值后缀“元”同时出现：二选一，当前 UI 优先用 `¥`。
