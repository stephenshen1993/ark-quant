# 交易计划离散优化算法调研

> 状态：只读研究结论，不自动形成策略规则或工程实现决定
> 研究对象：`ark-quant` 小市值股票 Top 20 等权账户内交易计划
> 核对日期：2026-08-15
> 资料边界：只使用原始论文、求解器/建模框架官方文档、官方示例或官方源代码

## 1. 结论先行

这不是一个需要继续改良贪心规则的问题，而是一个规模很小、约束明确的离散组合再平衡问题。成熟做法是把整手、订单门槛、费用、现金和目标偏离同时建模，交给能够给出最优界的离散优化求解器。

对当前 Top 20 规则，推荐方案是：

1. **采用“单标的可行状态枚举 + 字典序 MILP”作为正式模型。** 每只股票先枚举 10% 上限内所有可能的计划后整手数，并预计算该状态对应的净订单、普通订单门槛是否合法、候选相关费用、订单数和计划后市值；主模型只需为每只股票选择一个状态。
2. **按投资目标逐层求解，而不是把目标混成拍脑袋权重。** 先在全部可行组合中最小化 Top 20 目标持仓的平方等权误差，再依次最小化最大整体偏离、全体整体偏离、无归因余现、显性费用和订单数，前一层最优值固定后再求下一层。资金利用率与交易成本不得反过来牺牲等权目标。
3. **默认开源落地可用 `scipy.optimize.milp`/HiGHS；需要更强诊断、原生分层目标或未来扩展时用 Gurobi。** OR-Tools CP-SAT 是优秀的全整数备选，但不是当前模型唯一或天然更优的答案。
4. **MIQP/MISOCP 暂不作为第一版。** 它们适合未来引入带交叉项的协方差 tracking error、风险模型或非线性市场冲击；当前名义等权的可分离平方误差可在单标的状态枚举后预计算成 one-hot 状态成本，仍由 MILP 精确表达。
5. **动态规划只适合作为小规模校验器或研究基准。** 它能在离散金额网格上求全局最优，但复杂度依赖预算刻度，费用、订单逻辑和多层目标会使自研状态管理迅速膨胀。

这一方向并非闭门造车。固定/比例交易成本、最低交易金额、买卖互斥、整手和换手约束都已有成熟的混合整数建模范式。Gurobi 的官方再平衡示例直接把固定费用、比例费用和最低交易规模纳入预算与二进制交易变量；MOSEK 的官方 Portfolio Cookbook 给出了同类混合整数及锥模型。[Gurobi 官方再平衡示例](https://gurobi-finance.readthedocs.io/en/latest/modeling_notebooks/rebalancing.html)、[MOSEK 交易成本章节](https://docs.mosek.com/portfolio-cookbook/transaction.html)

## 2. ark-quant 问题的数学形态

设固定目标集合为 `i = 1...20`：

- `p_i`：计划价；
- `L = 100`：A 股整手；
- `h_i`：当前股数；
- `x_i`：计划后手数，整数；
- `v_i = p_i L x_i`：计划后市值；
- `B`：计划可执行总预算；
- `F(x)`：候选订单集合对应的必要费用；
- `c = B - F(x) - Σv_i`：计划后无归因可投资余现；
- `V = Σv_i + c = B - F(x)`：现行规则中的计划后可比较价值；
- 理论单标的权重为 `1/20 = 5%`。

主要硬约束可以写成：

```text
x_i ∈ Z, x_i >= 1
v_i <= 10% * B
c >= 0
净买卖订单必须是 100 股整数倍
普通非零订单金额 >= 动态最低金额
必要卖出按策略规则豁免普通订单门槛
费用必须由当前候选订单集计算并进入现金方程
固定 Top 20，不允许用第 21 名替代
```

现行模型先要求终态无法继续形成下一笔合规买入，再使用字典序而非单一加权和：

```text
1. min max(max_i |v_i / V - 5%|, c / V)
2. min Σ_i (v_i / V - 5%)²
3. min Σ_i |v_i / V - 5%| + c / V
4. min c
5. min F(x)
6. min 非零普通订单数
7. 按冻结排名和证券代码稳定破同分
```

这里有一个容易被忽略的建模细节：`V = B - F(x)` 随候选费用变化，因此前两项目标一般是**混合整数线性分式目标**，不是把百分比乘一个常数后就天然得到的普通 MILP。通用做法可以使用参数化 MILP（Dinkelbach 法或对偏离阈值做可行性二分），不能悄悄把分母固定。Dinkelbach 原始论文将分式优化转成一系列参数化子问题；在本问题中，每个子问题仍是 MILP。[Dinkelbach 1967 原始论文](https://pubsonline.informs.org/doi/10.1287/mnsc.13.7.492)

股票正式实现还可以进一步精确化简：必要卖出先冻结后，卖出费用成为常数；买入费用只取决于买入订单数 `K`。枚举 `K=0..20` 后，每个子问题的正式费用和 `V` 都是常数，分式字典序可转成普通整数 MILP，再用精确分数跨 `K` 比较。这比继续运行 Dinkelbach 外层更容易审计，也避免把单个参数化子问题的 `mip_gap=0` 误报为整个分式问题已全局最优。

| --- | --- | --- | --- | --- | --- |

| MIQP | MILP 全部约束，加上平方偏离、协方差 tracking error、二次换手惩罚 | 适合 `Σ(w-w*)²` 或 `(w-w*)'Σ(w-w*)` | 二次项凸且求解器完成分支定界时，可证明全局最优至 gap | Top 20 很小，通常可解；但模型和依赖比当前需要更重 | Gurobi、SCIP、MOSEK；CVXPY 需另装支持 MIQP 的求解器 |

| CP-SAT | 整数、布尔、绝对值、最大值、条件约束、最低订单和精确分币费用都很自然 | 线性整数目标；字典序用多次求解并固定前层最优值 | `OPTIMAL` 才代表已证明最优；`FEASIBLE` 只代表找到可行解 | 很合适，尤其适合大量逻辑约束 | `ortools.sat.python.cp_model`，要求所有约束整数化 |
| DP / 多项选择背包 | 预枚举每只股票可选手数后，可表达预算、上限、门槛和逐状态费用 | 可在状态中维护偏离、现金、费用的 Pareto 前沿 | 对选定金额刻度和完整状态空间可全局最优 | 20 只可做，但复杂度对“预算最小单位”是伪多项式 | 通常需自研；通用 knapsack API 不直接覆盖本问题全部约束 |

SciPy 官方文档明确把 `scipy.optimize.milp` 定义为 HiGHS 的 MILP 包装，并返回 MIP 对偶界和 gap；文档同时用背包例子说明连续松弛后直接取整可能超预算或得到次优解。[SciPy `milp` 官方文档](https://docs.scipy.org/doc/scipy/reference/generated/scipy.optimize.milp.html)

## 4. 各类成熟方法的适用边界

### 4.1 MILP：当前问题的首选

直接变量模型可以为每只股票设置计划后手数、买入手数、卖出手数和买卖方向二进制变量。最低普通订单金额通过“有订单则金额不低于门槛”的指示约束表达；买卖互斥、10% 上限、现金不透支和订单数也都是线性约束。

更适合 ark-quant 的做法是先做**单标的状态枚举**：

1. 对每只股票枚举 `1...floor(10% * B / (100 * p_i))` 手；
2. 根据当前持仓计算每个计划后手数对应的净买卖量；
3. 删除违反普通订单门槛且不属于必要卖出的状态；
4. 按正式券商费用口径预计算该状态的费用；
5. 为每只股票建立 `z_i,k ∈ {0,1}`，并约束 `Σ_k z_i,k = 1`；
6. 用所选状态的市值、费用和订单数构造全局现金与偏离目标。

这相当于多项选择背包的列/配置式 MILP。它有三个直接好处：不需要为最低佣金的 `max(最低佣金, 费率 × 成交额)` 手写脆弱的 Big-M；普通订单门槛在状态生成时已经精确判定；费用与候选状态一一对应，不会出现为了改善权重而虚增或低估费用的松弛变量。

固定费用、比例费用、最低交易规模以及买卖互斥使用二进制变量，是求解器官方资料中的标准模型，不是 ark-quant 特有技巧。[Gurobi 官方再平衡示例](https://gurobi-finance.readthedocs.io/en/latest/modeling_notebooks/rebalancing.html)、[MOSEK 固定费用与 buy-in threshold](https://docs.mosek.com/portfolio-cookbook/transaction.html)

字典序应使用“求解、固定前层最优值、再求下一层”的多次求解方式。Gurobi也原生支持 hierarchical objectives，但其官方文档说明多目标模型中的目标必须是线性的；当前分式目标仍应先参数化或固定分母口径后再使用原生多目标功能。[Gurobi 多目标官方文档](https://docs.gurobi.com/projects/optimizer/en/current/reference/misc/misc/multiobjective.html)

### 4.2 MIQP：适合带交叉项的 tracking error，不是当前规则的必要条件

如果目标变成：

```text
min (w - w*)' Q (w - w*) + λ * turnover + transaction_cost
```

且 `Q` 为半正定矩阵，就得到凸 MIQP。`Q = I` 时是各标的平方偏离；`Q = Σ` 时是相对目标组合的收益 tracking error。整数手数和订单二进制变量仍保留。

Gurobi 官方文档明确把“凸二次目标 + 离散变量”归为 MIQP，并由 MIP 求解器处理；CVXPY 官方示例也给出了半正定二次目标和整数变量的 MIQP 形式。[Gurobi 二次目标官方文档](https://docs.gurobi.com/projects/optimizer/en/current/concepts/modeling/objectives.html)、[CVXPY MIQP 官方示例](https://www.cvxpy.org/version/1.1/examples/basic/mixed_integer_quadratic_program.html)

平方偏离允许多个小偏离与一个较大偏离互相补偿，不能取代最差单标的控制，因此正式规则仍先最小化 `L∞`。但在 `L∞` 并列后，平方项能打破 `L1` 中“现金减少与单只超配增加恰好抵消”的平坦方向。当前每只股票恰选一个已枚举状态，`(w_i-w_i*)²` 对每个状态都是可预计算常数，乘以 one-hot 状态变量后仍是线性目标；只有引入协方差交叉项、连续交易量二次项等变量乘积时，才需要 MIQP。

### 4.3 MISOCP：为风险模型和非线性冲击预留

二次风险约束可转成二阶锥，整数整手和订单变量加入后形成 MISOCP。MOSEK 官方 Portfolio Cookbook 展示了：

- 固定及比例交易成本；
- buy-in threshold；
- cardinality/交易数量约束；
- 协方差风险的锥约束；
- 用 power cone 表达约 `|trade|^(3/2)` 的市场冲击。

来源：[MOSEK Portfolio Cookbook：Transaction costs](https://docs.mosek.com/portfolio-cookbook/transaction.html)、[MOSEK Modeling Cookbook：Power cone portfolio model](https://docs.mosek.com/modeling-cookbook/powo.html)

这类模型适合资金规模和成交量足以让市场冲击成为主要成本，或需要正式协方差/鲁棒风险约束时使用。当前 Top 20、约 5% 名义等权和整手分配并不需要锥模型；过早引入会增加商业求解器依赖、模型验证和数值调试成本。

### 4.4 CP-SAT：精确整数逻辑的强备选

CP-SAT 只在整数上工作，因此价格、费用和比例必须缩放成分、万分位或其他明确整数刻度。官方 API 原生提供整数/布尔变量、条件约束、绝对值和最大值等建模能力；返回 `OPTIMAL` 时证明最优，`FEASIBLE` 则尚未证明。[OR-Tools CP-SAT 官方说明](https://developers.google.com/optimization/cp/cp_solver)、[CP-SAT Python API](https://or-tools.github.io/docs/pdoc/ortools/sat/python/cp_model)

它可以完整表达 ark-quant 的约束，尤其适合：

- 金额按分精确整数化；
- 普通订单门槛与必要卖出豁免等布尔逻辑较多；
- 希望避免浮点 MIP 容差影响边界判断；
- 接受通过多次 solve 实现字典序。

限制是二次 tracking error 不能直接作为 CP-SAT 的二次目标；需改用 `L∞/L1`、分段线性近似或预枚举状态。对当前规则这不是问题，但若未来转向协方差 MIQP，需更换后端或模型。

### 4.5 动态规划/多项选择背包：可做精确对照，不宜做主实现

状态枚举后，每只股票必须从多个计划后手数中选一个，形式上接近 multiple-choice knapsack。Pisinger 的原始论文给出了把多项选择背包与动态规划结合的精确算法；minimum-lot 组合选择本身已被证明具有组合复杂性，早期组合优化文献因此采用混合整数和启发式方法。[Pisinger 1995 原始论文](https://www.sciencedirect.com/science/article/pii/037722179500015I)、[Mansini & Speranza 1999 原始论文](https://doi.org/10.1016/S0377-2217(98)00252-5)

对本问题，DP 的预算维若按“分”离散，约 27 万元就是约 2700 万个现金刻度；再加入最大偏离、总偏离、费用和订单数的 Pareto 状态，内存与去重逻辑会快速变复杂。按“元”或更粗刻度可降低规模，但会失去费用与现金的精确性。它更适合：

- 为随机小实例生成穷举/DP 真值，验证 MILP 或 CP-SAT；
- 在非常固定、可分离的费用模型下做专项性能比较；
- 不作为承载长期策略规则变化的默认生产算法。

OR-Tools 自带 knapsack/packing 算法，但官方 multiple-knapsack 示例解决的是多个容量容器分配，并不直接包含本问题的一标的一状态、订单门槛、费用和字典序目标。[OR-Tools Packing 官方文档](https://developers.google.com/optimization/pack)

### 4.6 Tracking error + turnover/transaction cost：采用其建模思想，不照搬目标

Markowitz 的均值-方差框架是二次风险组合优化的经典起点；后续成熟再平衡框架通常把目标收益、风险、交易成本和持仓成本放在同一个优化问题中。[Markowitz 1952 原始论文](https://doi.org/10.1111/j.1540-6261.1952.tb01525.x)、[Boyd 等 2017 原始论文及代码](https://stanford.edu/~boyd/papers/cvx_portfolio.html)

Lobo、Fazel、Boyd 对线性和固定交易成本的研究指出：线性成本与凸风险可高效全局求解，而固定费用和折扣断点引入组合结构，需要混合整数、松弛或启发式处理。[Lobo、Fazel、Boyd 2007 原始论文](https://stanford.edu/~boyd/papers/portfolio.html)

对 ark-quant，成熟框架中值得直接吸收的是：

- 用计划后持仓减当前持仓定义交易量；
- 费用进入自融资预算，不只是结果页展示；
- 用绝对交易量表达 turnover；
- 用交易二进制变量表达固定费用、最低交易金额和订单数；
- 把现金作为显式变量；
- 报告可行解、最优界、MIP gap 和停止原因。

不宜直接照搬的是“预期收益 - 风险 - 成本”的单一加权目标。当前 Top 20 已由策略层固定，定额层没有可靠的横截面预期收益输入；随意设置 `λ` 会暗中改写“等权优先、费用后置”的正式规则。已有 index-tracking 研究也使用多阶段 MILP，先满足跟踪目标，再最小化交易成本，说明分层求解是成熟路线。[Canakgoz & Beasley 2009 原始论文](https://doi.org/10.1016/j.ejor.2008.03.015)

## 5. 推荐的正式模型

### 5.1 模型结构

推荐名称：**Top 20 离散目标态字典序 MILP**。

```text
输入冻结
  -> 枚举每只股票的可行计划后整手状态
  -> 精确计算每个状态的净订单、门槛资格、费用和订单数
  -> 每只股票恰选一个状态
  -> 满足预算、现金非负、10% 上限和必要卖出约束
  -> 分层求解六级目标
  -> 输出最优界、gap、现金归因和唯一稳定解
```

状态 `k` 的数据全部是常数：

```text
shares[i,k]
market_value[i,k]
trade_shares[i,k]
trade_notional[i,k]
fee[i,k]
ordinary_order_count[i,k]
is_allowed[i,k]
```

决策变量只需 `z[i,k]`。因此普通订单最低金额、最低佣金、卖出印花税等非光滑费用可以在枚举阶段按正式费用函数精确计算，不必在主模型中近似。

### 5.2 订单数分解后的精确字典序

推荐按以下方式保留现行百分比口径：

1. 必要卖出先冻结，普通持仓只枚举保持或增持状态；金额、费用和现金统一缩放到厘。
2. 枚举买入订单数 `K`。每个 `K` 对应唯一正式费用和固定分母 `V_K`。
3. 在每个 `K` 内先最小化 `Σ_i (N v_i - V_K)²`。平方项在单标的状态枚举后是常数，并通过减去逐标的最小常数、再除以全体公约数，缩放成可由浮点 MILP 接口精确表示的整数目标。
4. 固定平方等权误差后，再依次最小化整数分子 `max(max_i |N v_i - V_K|, N c)`、总绝对偏离分子和余现。
5. 用精确有理数跨 `K` 按同一顺序比较平方等权误差、最大偏离和总绝对偏离，再比较余现、费用和订单数。即使余现足以形成另一笔买单，只要该买入会恶化第一层等权误差，仍保留等权最优组合。
6. 最后按冻结排名和代码逐标的锁定平局，并保存状态、gap、节点数和求解次数。

若未来费用结构不再能由必要卖出与买入订单数完全确定，应重新使用经独立验证的参数化分式方法，或切换支持更强逻辑和多目标诊断的求解器；不能继续沿用本分解并声称分母已固定。

### 5.3 求解器建议

**第一落地选择：`scipy.optimize.milp` / HiGHS。**

- 优点：开源、Python 接口轻、足够支持状态枚举后的纯 MILP；官方接口提供最优状态、MIP 对偶界和 gap。
- 代价：缺少 Gurobi 那样完整的原生 indicator、多目标和诊断能力；字典序、分式参数循环与失败诊断需要应用层组织。
- 适用：先建立可复现的正确性基线，并用真实 Top 20 计划验证。

**增强/生产求解器：Gurobi。**

- 优点：官方已有 round lots、minimum buy-in、turnover、固定/比例成本和再平衡示例；支持 MIP/MIQP、hierarchical linear objectives、MIP gap、IIS 和丰富诊断。
- 代价：商业许可证依赖；多目标仍只支持线性目标，分式口径仍需参数化。
- 适用：需要更稳定的最优性证明、诊断，或未来模型扩展时。

**开源全整数备选：OR-Tools CP-SAT。**

- 优点：分币整数与逻辑约束自然，`OPTIMAL`/`FEASIBLE` 语义清楚。
- 代价：必须严格设计金额和比例缩放；不直接支持二次 tracking error。
- 适用：希望全程整数化，或 HiGHS 在逻辑型状态模型上表现不理想时。

**MIQP/MISOCP 研究后端：PySCIPOpt、Gurobi 或 MOSEK。** CVXPY 是建模层而不是求解器；其官方文档明确说明混合整数问题需要另装合适的开源或商业求解器。[CVXPY mixed-integer 官方说明](https://www.cvxpy.org/tutorial/constraints/index.html)、[PySCIPOpt 官方文档](https://pyscipopt.readthedocs.io/en/stable/index.html)

## 6. 全局最优保证应如何表述

“用了 MILP/MIQP/CP-SAT”不自动等于“得到了全局最优”。正式输出应区分：

- `OPTIMAL`：在建模精度和求解容差内已证明最优；
- `FEASIBLE / TIME_LIMIT`：只有可行 incumbent，并有未闭合的最优界；
- `INFEASIBLE`：模型证明无可行组合，应映射为容量冲突或输入/规则冲突；
- `NUMERICAL / UNKNOWN`：不得把当前解伪装成最优计划。

对 MILP/MIQP，应记录 primal objective、best bound 和 MIP gap。对 CP-SAT，官方状态定义明确区分 `OPTIMAL` 与 `FEASIBLE`。[Gurobi MIP gap 官方说明](https://docs.gurobi.com/projects/optimizer/en/current/reference/parameters.html)、[OR-Tools CP-SAT 状态说明](https://developers.google.com/optimization/cp/cp_solver)

这里的“全局最优”只表示：在给定目标集合、计划价、持仓、费用函数、可交易状态和策略约束下，对所写数学模型最优。它不表示次日真实成交价最优，也不消除报价变化、停牌、涨跌停、滑点和人工执行误差。

## 7. 验收建议

正式实施及后续算法变更至少应保留以下三层验证：

1. **小实例真值**：用穷举或 DP 对 2 至 5 只、少量手数的随机实例生成真值，逐项核对字典序最优性。
2. **真实计划回放**：对当前暴露出余现和权重差异的 Top 20 计划，比较平方跟踪误差、最大偏离、总绝对偏离、余现、费用、订单数和求解状态；特别保留次级费用或余现目标导致等权目标退化的回归样本。
3. **求解器交叉验证**：同一状态枚举模型分别交给 HiGHS 与 CP-SAT/Gurobi，要求最优目标层级与最终唯一解一致；若不一致，先检查金额缩放、费用口径和容差。

推荐的成功标准是：只要存在满足普通订单门槛、费用和 10% 上限且平方等权误差更小的组合，正式求解器就不得停在次优解；剩余现金必须能由“等权优先、不足下一可行状态、费用、冻结或不可交易”明确归因；若求解未证明最优，计划输出必须展示 gap，而不是声称“已最优”。

## 8. 最终推荐

ark-quant 当前应站在成熟运筹优化方法之上，把现有逐手贪心/局部换手替换为：

> **必要卖出冻结 + 单标的可行状态枚举 + 平方等权误差优先的字典序 MILP + 最优界审计。**

正式实现使用 `scipy.optimize.milp`/HiGHS 建立开源正确性基线；名义等权平方误差通过状态成本线性化，模型边界保持求解器无关，以便需要时切换 Gurobi。保留 CP-SAT 作为全整数交叉验证后端。除非未来正式引入协方差 tracking error、风险约束或市场冲击，不升级到 MIQP/MISOCP；不把自研 DP 或新的局部贪心作为主求解器。

这一方案首先优化约 5% 等权，同时满足 100 股整手、固定 Top 20、单标的 10% 上限、现金不透支和普通订单最低金额；在等权最优集合内再提高资金利用率并降低候选相关费用，还能对“为什么还剩这笔现金”给出可审计的最优性或最优界证据。
