# 近十年极端波动与现金池压力测试

> 状态：战术决策研究记录
> 职责：检验中性现金池能否在股票大幅下跌时承担第一阶段调仓资金。
> 真源范围：2015-12-20 至 2026-07-17 的指数日收盘价计算与候选组合压力测试。
> 不负责：替代正式仓位规则、预测未来跌幅或证明历史一定重演。
> 最后核对：2026-07-18

## 1. 研究问题

中性估值下，专用现金池占国内总资产 `5%` 是否足以应对极端波动带来的再平衡需求？

## 2. 数据与代理

- 使用公开指数日收盘价计算共同窗口收益和峰谷回撤，价格指数用于压力测试，不用于长期绩效基准。
- 小市值股票策略以中证1000作为最低限度风险代理。中证1000选取中证800以外规模偏小且流动性好的1000只证券；实际20只小市值组合可能更集中、波动更大。
- 长钱投顾组合暂以沪深300作为偏大盘风险代理，不能代表投顾组合的真实持仓和净值。
- 可转债以中证转债作为市场代理，不能代表当前多因子策略的精确回撤。
- 原始日线通过 AkShare 的腾讯公开指数行情接口取得；指数定义和近年收益使用中证指数公司资料交叉核对。

## 3. 典型共同窗口跌幅

| 极端窗口 | 沪深300 | 中证500 | 中证1000 | 中证转债 |
| --- | ---: | ---: | ---: | ---: |
| 2016 年熔断后延续 | -23.51% | -30.80% | -33.10% | -11.42% |
| 2018 年小盘熊市 | -26.82% | -37.66% | -42.28% | -6.12% |
| 2020 年疫情冲击 | -14.39% | -15.24% | -15.46% | -5.27% |
| 2024 年初小盘流动性冲击 | -6.72% | -17.85% | -27.08% | -5.10% |
| 2025-04-07 单日冲击 | -7.05% | -9.55% | -11.39% | -4.05% |

样本期内按日收盘价计算的完整峰谷最大回撤约为：沪深300 `-45.60%`、中证500 `-48.85%`、中证1000 `-61.61%`、中证转债 `-17.94%`。

这些结果说明，真正需要资金调拨的典型场景不是所有资产同步下跌，而是小盘相对大盘和可转债下跌更多；此时可转债、长钱和现金会相对高配，构成股票补仓来源。

## 4. 5%现金候选压力测试

起始候选结构：

```text
小市值股票 50%
多因子可转债 30%
长钱 15%
现金池 5%
```

假设冲击后仍只恢复上述中性目标，不额外提高低估股票目标，则股票需要补入的金额占冲击前国内总资产：

| 场景 | 股票补入需求 |
| --- | ---: |
| 2016 年熔断后延续 | 4.80% |
| 2018 年小盘熊市 | 7.64% |
| 2020 年疫情冲击 | 1.99% |
| 2024 年初小盘流动性冲击 | 5.50% |
| 2025-04-07 单日冲击 | 1.71% |

`5%`现金在2018年和2024年初情景下不能独立完成第一阶段股票补仓。若极低估值规则还要求提高股票目标，缺口会进一步扩大。

## 5. 决策结论

中性估值锚点改为：

```text
小市值股票 45%
多因子可转债 30%
长钱 15%
现金池 10%
```

`10%`现金能够覆盖上述历史共同窗口中恢复中性股票目标的第一阶段需求，并为实际小市值策略可能高于中证1000的波动留出余量。它仍不负责独自完成极低估值下的全部目标切换，剩余资金必须由相对高配资产分阶段释放。

默认执行顺序：

```text
现金池立即执行
-> 卖出相对高配的可转债或股票，跨账户资金可用后继续
-> 达到偏离阈值的长钱赎回到账后完成剩余部分
```

## 6. 局限

- 使用指数而非真实20只小市值持仓、可转债策略榜单和投顾组合净值。
- 使用共同窗口收盘价，没有模拟盘中跌停、无法成交、滑点、费用和跨账户结算时间。
- 压力测试保持中性目标不变，没有加入尚未盘定的极端估值目标。
- 历史极端只用于检验资金链，不用于预测下一次危机的时间、幅度或相关性。
