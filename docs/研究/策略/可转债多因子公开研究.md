# 公网可转债多因子策略调研

> 状态：研究材料
> 职责：整理公开可转债多因子机制、参数与回测局限。
> 真源范围：调研所覆盖的公开证据。
> 不负责：自动构成当前策略参数或工程待办。
> 最后核对：2026-07-18

调研日期：2026-06-02

## 1. 调研目标

本文关注中国 A 股公募可转债的多因子多头策略。目标不是收集策略名称，而是提取可以进入本项目研究与回测流程的机制：

- 可投资池如何过滤；
- 因子为什么可能有效；
- 因子如何合成；
- 组合如何分层、调仓和控制风险；
- 哪些参数已经公开，哪些参数仍需自行回测；
- 哪些公开回测存在样本、成本或可复现性限制。

本文不是投资建议。公网回测不能替代本地数据快照、交易成本建模、样本外验证和人工复核。

## 2. 结论先行

公开资料支持一个比较清晰的演化路径：

1. 经典双低适合作为可解释基线，但不适合继续作为唯一核心。双低系数通常定义为：

   ```text
   双低系数 = 转债价格 + 转股溢价率 * 100
   ```

   低价提供相对债底保护，低转股溢价率让正股上涨更容易传导到转债价格。

2. 相比简单叠加更多正股因子，更值得优先补齐的是转债特有因子和转债-正股联动因子。公开研究反复出现的高价值信息包括：转股溢价率、纯债溢价率、YTM、平价底价溢价率、隐含波动率、转债价格动量、转债相对正股涨跌偏离、转债量价和换手。

3. 可转债应按股性和债性分层。统一打分会把经济含义不同的券混在一起。可使用平价底价溢价率或平价分位，把样本分为偏债、平衡、偏股三组，再分别选券或控制组内配额。

4. 单纯固定权重择券并不足以承担完整风控。公开研究显示，择时、信用风险过滤、强赎过滤、流动性约束和行业集中度控制是独立的重要模块。

5. 当前项目 `CB-MF-Rotation v1` 的方向基本合理，但仍偏“正股增强双低”。下一轮研究应优先加入转债自身状态，而不是直接继续增加正股指标。

## 3. 公开机制地图

### 3.1 经典双低轮动：基础基线

**机制**

- 对存续可转债计算价格和转股溢价率；
- 按双低系数升序排序；
- 选择排名最靠前的一组，等权持有；
- 定期或越过阈值时轮动。

**收益来源**

- 低价格：尽量保留债底缓冲；
- 低转股溢价率：尽量保留正股上涨传导能力；
- 轮动：不断替换已经上涨、溢价扩张或失去性价比的标的。

**局限**

- 低价不等于无信用风险；
- 2022 年后转股溢价率中枢抬升，低溢价标的减少，双低超额收益斜率下降；
- 单因子组合容易暴露于小微发行人、流动性和行业集中风险。

**公开依据**

- 国泰君安期货研究报告公开给出了双低系数公式和动态轮动逻辑。
- 国金证券 2025 年报告明确讨论了经典双低在估值中枢上移后的困境。

### 3.2 海通三因子框架：可直接搭建的月频原型

**公开规则**

- 样本：2018 年初至 2022-01-28；
- 过滤：剔除余额小于 2 亿元的转债；
- 调仓：每 20 个交易日调仓；
- 因子：正股 `PB`、转股溢价率、正股收益率；
- 合成：从各类因子中各选一个有效因子合成；
- 持仓：每期最优 20 只，等权；
- 成本：双边千一；未考虑流动性和滑点。

**机制**

- `PB`：捕捉正股估值或风格暴露；
- 低转股溢价率：捕捉转债相对平价的性价比；
- 正股收益率：要求正股具备上涨弹性，以消化转债估值。

该策略不是“只买低溢价”。公开材料明确指出，溢价率因子需要价格接近债底、没有重大信用事件、正股有向上弹性等条件，和正股收益率合成后更合理。

**公开回测**

- 年化收益率：`11.33%`
- 年化波动率：`10.33%`
- 最大回撤：`25.85%`
- 相对中证转债指数年化超额：`3.60%`

**证据评价**

可复现性较高，适合作为本项目第一个历史回测对照组。缺点是样本结束较早，且没有处理流动性、滑点和近年的信用风险冲击。

### 3.3 开源九因子框架：把联动因子放到核心位置

**公开规则**

- 因子来源分为三类：正股、转债-正股联动、转债自身量价；
- 使用 3 大类共 9 个因子；
- 合成前进行去极值、标准化和方向调整；
- 9 个因子等权合成；
- 每期选择合成因子值最大的 20 只转债，等权持有；
- 公开摘要中的回测区间：2018-01 至 2021-06。

**机制**

1. 正股因子通过影响正股价格，间接影响转债定价。
2. 转债-正股联动因子描述转债与正股之间的预期差。典型指标是转股溢价率，也可以构造转债与正股涨跌、波动或量价反应速度的偏离。
3. 转债自身量价因子捕捉参与者结构、交易热度和短期行为。

公开摘要认为，转债-正股联动因子的显著性和稳定性更突出。这一点对本项目尤其重要：当前 MVP 有正股动量，但尚未显式建模“转债相对正股是否反应过度或不足”。

**公开回测**

- 合成因子 IC 均值：`9.35%`
- `IC_IR`：`1.89`
- Top20 组合年化收益：`34.6%`
- 年化波动率：`20.8%`
- 相对中证转债指数年化超额：`26.1%`

**证据评价**

机制很有价值，但仅凭公开摘要无法完整复原 9 个因子的全部公式和调仓频率。适合作为因子实验室的方向，不适合直接复制收益数字。

### 3.4 国金双低五因子增强：经典双低的近期升级版

**公开规则**

在低价格、低转股溢价率之外，增加：

- 双低因子历史分位数；
- 隐含波动率；
- 转债价格动量。

形成五因子增强策略。

**机制**

- 历史分位数：同样的绝对双低值在不同市场估值中枢下意义不同，历史分位数用于做时间维度标准化；
- 隐含波动率：反映内嵌期权价格，帮助识别市场是否为转债期权支付了过高溢价；
- 转债价格动量：捕捉转债自身交易趋势，而不是只依赖正股趋势。

**公开回测**

- 2018 年以来年化收益：约 `24%`
- 相比经典双低提升：约 `10%`
- 超额最大回撤：小于 `9%`

**证据评价**

这是对当前项目最有直接启发的公开框架。但公开摘要没有披露五因子的标准化、权重、调仓频率和隐含波动率模型细节，需要自行回测定标。

### 3.5 国盛低估值高换手：用流动性修复估值因子衰退

**公开规则**

- 先取估值最低的 `50%` 转债作为候选池；
- 将转债分为偏债、平衡、偏股三个分域；
- 每个分域选择换手率最高的 `15` 只；
- 组合最多 `45` 只。

**机制**

低估值因子提供回归空间，高换手率要求市场已经出现资金关注。它不是追求最低估值，而是筛选“便宜且有人交易”的券，减少低估值陷阱和流动性约束。

**公开回测**

- 2018 年以来年化收益：约 `26%`
- 年化超额：约 `14.1%`

**证据评价**

公开摘要提供了较完整的构造方法，适合成为第二阶段对照组。需要核验估值最低 `50%` 的具体估值指标口径，以及换手率窗口。

### 3.6 分类型多因子：偏债、平衡、偏股分别建模

**公开规则线索**

- 常见分类指标是平价底价溢价率，即平价与债底之间的相对关系；
- 公开材料中可见一种分类口径：大于 `1.2` 为偏股型，`0.8` 至 `1.2` 为混合型，小于 `0.8` 为偏债型；
- 另一种更容易落地的替代做法是按平价排序三等分。

**机制**

- 偏债券更依赖 YTM、纯债溢价率、信用和剩余期限；
- 平衡券更适合双低、期权估值和联动因子；
- 偏股券更依赖正股趋势、波动、估值和行业风险偏好。

同一个因子在不同风格中的方向和强度未必一致。分层后再打分，比对全市场统一打分更符合可转债的混合资产属性。

**证据评价**

这是结构性改造，不是再加一个权重。适合在本项目建立可靠债底字段后实施。

### 3.7 浙商五类风格体系：更完整的研究方向

**公开规则线索**

- 因子池：115 个因子；
- 五类风格：估值、动量、波动率、流动性、量价相关性；
- 日频更新；
- 强调行业、市值、风格中性和非线性组合优化。

**机制**

- 估值：定价偏离和回归空间；
- 动量：短周期趋势；
- 波动率：风险定价和对高投机标的的规避；
- 流动性：市场深度和资金关注；
- 量价相关性：交易情绪和价量共振。

公开材料还指出，简单等权合成并不一定优于单一优势风格，应基于历史风险、`RankICIR`、夏普或冗余度优化子因子权重。

**证据评价**

适合作为中长期研究蓝图，不适合作为 MVP 直接照搬。115 个因子会显著提高数据、成本建模和过拟合控制要求。

### 3.8 择时模块：和横截面选券分开建模

公开研究中存在两种值得单独测试的择时方式：

1. **动量 + 估值择时**
   - 使用唐奇安通道；
   - 公开参数示例为 `N=120` 日、`M=60` 日；
   - 估值买入信号可使用转股价值、期权溢价率、平价底价溢价率；
   - 卖出信号可使用纯债溢价率。

2. **宏微观胜率赔率择时**
   - 微观因子贡献短期胜率，例如转债价格、期权时间价值、权益估值安全垫；
   - 宏观因子贡献极端行情下的赔率，例如流动性、利率、房地产和经济活跃度；
   - 根据预测收益率正负进行满仓或空仓。

横截面选券回答“买什么”，择时回答“现在是否值得持有这类资产”。两者应分开回测，避免把仓位风控混进个券评分。

## 4. 因子优先级

建议按数据可得性和机制清晰度分三批推进。

### 第一批：优先加入回测

| 因子 | 方向 | 机制 | 对当前 MVP 的意义 |
| --- | --- | --- | --- |
| 转债价格 | 越低越好，但需信用过滤 | 债底缓冲 | 已包含在双低中 |
| 转股溢价率 | 越低越好 | 股性传导、相对平价性价比 | 已包含在双低中 |
| 双低历史分位数 | 越低越好 | 适配估值中枢变化 | 当前缺失 |
| 转债自身 20 日动量 | 需回测方向 | 捕捉转债交易趋势 | 当前缺失 |
| 转债相对正股涨跌偏离 | 低反应或过度反应需分别测试 | 捕捉转债-正股预期差 | 当前缺失 |
| 转债成交额或换手率 | 过滤或增强 | 流动性、资金关注、可执行性 | 当前过滤字段仍不稳定 |
| 强赎、ST、到期、余额 | 过滤 | 避免结构性风险 | 已部分实现 |

### 第二批：债底和分层可靠后加入

| 因子 | 方向 | 机制 |
| --- | --- | --- |
| YTM | 越高越好 | 偏债券持有收益和保护 |
| 纯债溢价率 | 越低越好 | 债底保护 |
| 平价底价溢价率 | 用于分层 | 区分偏债、平衡、偏股 |
| 隐含波动率 | 低估优先 | 内嵌期权估值 |
| 隐含波动率 - 正股实际波动率 | 越低越值得关注 | 识别期权相对低估 |

### 第三批：数据稳定后研究

| 因子 | 用途 |
| --- | --- |
| 正股 PB、EP、成长、盈利 | 正股质量和风格增强 |
| 行业中性、市值中性 | 控制无意风格暴露 |
| 下修、回购、强赎事件 | 独立事件驱动增强 |
| 宏观流动性和估值因子 | 资产级择时 |

## 5. 对当前项目的建议

当前配置已经实现：

- 双低因子：`35%`
- 正股 20 日动量：`30%`
- 正股低波：`20%`
- 正股小市值：`15%`
- 价格、余额、成交额、强赎、ST、到期过滤
- Top20 等权持有

建议不要直接覆盖现有配置。先将现有版本固定为基线，再建立多个可比较的实验组合：

### 实验 A：现有 MVP 基线

保持当前 `35/30/20/15` 不变，用于比较新增机制是否真的改善样本外表现。

### 实验 B：双低五因子增强

在双低基础上增加：

- 双低历史分位数；
- 隐含波动率；
- 转债自身动量。

首轮可先用等权合成，避免在历史数据不足时过早优化权重。

### 实验 C：联动增强

在当前 MVP 上增加：

- 转债相对正股 `5/10/20` 日涨跌偏离；
- 转债相对正股波动偏离；
- 转债成交额或换手率过滤。

重点验证“正股已经上涨但转债反应不足”的券是否存在稳定超额，而不是预先假定方向。

### 实验 D：分层模型

按偏债、平衡、偏股分层后：

- 偏债层：YTM、纯债溢价率、余额、期限；
- 平衡层：双低、历史分位数、隐含波动率；
- 偏股层：正股动量、转债动量、联动偏离、行业暴露。

每层固定配额或动态配额，再做全组合风险控制。

### 实验 E：独立择时

先做简单、可解释版本：

- 中证转债或等权转债指数；
- `120` 日趋势过滤；
- 估值分位数过高时降低仓位；
- 信用风险事件密集时降低仓位。

择时模块只控制总仓位，不改变横截面因子排序。

## 6. 回测必须补上的约束

公网回测常见的不足，正好对应本项目的工程优先级：

- 使用公告日而不是报告期，避免财务因子未来函数；
- 处理退市、到期、强赎、停牌、无法成交和一字涨跌；
- 保存历史转股价和下修记录，避免用当前转股价回看历史；
- 使用可成交价格并建模滑点；
- 对低余额、低成交额、低换手标的施加硬过滤；
- 统计换手率、容量和单券冲击成本；
- 将信用风险过滤与 alpha 排序分开；
- 进行滚动样本外验证，不用一次全样本结果直接定权重；
- 对比中证转债指数、全市场等权、经典双低和当前 MVP。
