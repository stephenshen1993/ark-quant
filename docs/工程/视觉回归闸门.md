# Web 视觉回归闸门

> 状态：当前工程基准
> 职责：记录全站真实浏览器视觉回归的唯一入口、基准、失败产物与更新规则。
> 真源范围：账户、计划、更新日志三页的浏览器可见行为和视觉验收方式。
> 不负责：定义业务规则、替代更新日志数据契约测试或要求跨平台全像素一致。
> 最后核对：2026-08-06

## 1. 唯一入口

```bash
# 默认启动隔离 SQLite、随机本地端口，并依次运行全部视口
scripts/ui_smoke.py

# 定位单一视口
scripts/ui_smoke.py --viewport wide
scripts/ui_smoke.py --viewport desktop
scripts/ui_smoke.py --viewport narrow

# 仅在人工调试时复用已启动的正式应用
scripts/ui_smoke.py --base-url http://127.0.0.1:8000
```

`scripts/ui_smoke.py` 是唯一最高层真实浏览器入口。默认模式不会读取人工维护的
`data/ark_quant.db`；账户、计划和更新日志都通过正式应用与真实页面接受检查。默认单元测试仍保留更新日志字段白名单、日期排序和工程元数据隔离等数据契约，但不再用读取
HTML/CSS 源码或查找固定中文正文的方式冒充视觉回归。

## 2. 视觉基准

| 名称 | CSS 视口 | 重点 |
| --- | --- | --- |
| `wide` | `1512 × 749` | 更新日志桌面基准的关键坐标与全部计算样式 |
| `desktop` | `1440 × 1000` | 全部计算样式、共享侧栏和阅读列在中间桌面尺寸下的比例 |
| `narrow` | `390 × 900` | 全部自适应计算样式、`64px` 顶栏、`22px` 内容边距、元信息重排、键盘焦点与无横向裁切 |

`wide` 的关键锚点允许 `2px` 误差：侧栏宽 `179px`；阅读列
`x=429px, width=833px, top=80px`；页头到日志流 `61px`；日期组间距
`72px`；日期头高 `44px`；元信息列宽 `86px`；列间距 `22px`；正文竖线
`x=537px`；正文起点 `x=562px`。三个视口都会读取颜色、字号、行高、字重和分割线等浏览器计算样式；窄屏使用父规格指定的自适应字号，基准来自父规格 #44。

闸门还验证以下用户可见结果：

- 三页均能通过共享导航访问，URL、刷新、返回和 `aria-current` 状态正确。
- 账户日期输入与账户明细可操作；计划详情可通过键盘展开并恢复。
- 更新日志具有一个页标题、日期标题和日志文章语义，内容来自真实数据流。
- 页面、控件、文字和宽表没有无滚动容器的横向裁切或溢出。
- 浏览器 console error 与 page error 均为空。

截图只用于人工复核和同尺寸半透明叠加，不以跨平台字体抗锯齿敏感的全像素硬比较作为唯一判断。

## 3. 产物

默认产物目录为 `outputs/ui-smoke/`，可用 `--output-dir` 覆盖。

| 产物 | 含义 |
| --- | --- |
| `<视口>-account.png` | 账户页成功截图 |
| `<视口>-plan.png` | 计划页成功截图 |
| `<视口>-changelog.png` | 更新日志成功截图，可与同尺寸参考图叠加 |
| `<视口>-failure.png` | 失败发生时的当前页面截图 |
| `<视口>-failure.txt` | 失败页面当时的可见文本 |
| `<视口>-failure.json` | 检查名、错误、`expected`/`actual` 差异、console/page error、页面文本和截图路径 |
| `server.log` | 隔离应用启动日志；使用 `--base-url` 时不生成 |

失败 JSON 中的 `differences` 是结构化数组。每项至少包含 `metric`、`expected`、
`actual` 和 `tolerance`，用于直接判断偏差位置，不必先阅读脚本源码。

## 4. 基准更新规则

1. 先确认产品视觉规格确实改变，并在对应 Issue 或规格中记录新基准；内容变化本身不构成视觉基准变更。
2. 在同一提交中更新正式页面和闸门常量，运行全部三个视口，并人工复核同尺寸截图叠加。
3. 不得仅为让测试通过而放宽 `2px` 容差、删除坐标/样式检查或改成元素存在性断言。
4. 字体栈、浏览器版本或运行平台变化时，先判断几何与换行是否真实改变；不得把抗锯齿差异升级为全像素失败。
5. `outputs/ui-smoke/` 是本地生成物，不提交为工程真源。参考值以本文件、父规格和脚本常量为准。
