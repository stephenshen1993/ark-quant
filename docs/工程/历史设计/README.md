# 历史工程设计

> 状态：历史工程索引
> 职责：索引已经完成、暂停或未继续执行的工程方案与规格。
> 真源范围：历史设计的存放位置与使用方式。
> 不负责：描述当前实现或形成当前待办。
> 最后核对：2026-07-18

这里保存已经完成或未继续执行的工程方案与规格，帮助追溯当时的判断；它们不是当前功能的真源，也不自动形成待办。

| 目录 | 内容 | 使用方式 |
| --- | --- | --- |
| `方案/` | 任务拆分、实施顺序和验证计划 | 需要理解历史改动范围时查阅 |
| `规格/` | 当时的界面、数据或可靠性设计 | 需要追溯设计取舍时查阅 |

使用规则：

- 投资规则以 `docs/体系/` 和 `docs/策略/` 为准；当前工具行为以代码、测试和 `docs/工程/`、`docs/使用/` 的当前文档为准。
- 历史方案与规格若仍有价值，应提炼结论回写正式文档；不要直接按旧清单继续执行。
- 新增工程记录使用 `YYYY-MM-DD-主题.md`，并在开头标明状态、适用范围和后续真源。
