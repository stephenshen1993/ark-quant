# Convertible Bond Data Probe Design

> 状态：历史设计，不是当前实现真源。

## Scope

Add a read-only probe under `strategies/convertible_bond/`. It checks whether
convertible-bond research fields are currently obtainable. It does not rank
bonds, rebalance portfolios, place trades, or run backtests.

## Data Sources

- Core: AKShare `bond_zh_cov()`. Failure makes the command exit non-zero, but a
  failure report is still written.
- Enhanced: AKShare `bond_cb_jsl(cookie=JSL_COOKIE)` when `JSL_COOKIE` exists.
  Missing credentials or endpoint failure only produce warnings.
- Optional: Tushare `cb_basic()` and `cb_daily()` when the package and
  `TUSHARE_TOKEN` exist. Missing package, token, or permissions only produce
  warnings.
- Stock momentum sample: for a configurable sample of stock codes from the
  core table, fetch recent A-share history and check whether 20-day momentum is
  computable. This sample does not imply full-market coverage.

## Output And Safety

Write `data/output/cb_data_probe_report.md` on every run. Include runtime
versions, source classifications, successes, failures, field lists, missing
rates, samples, field support, stock sample coverage, and feasibility
conclusions. Read credentials from `.env`; never log or render their values.
