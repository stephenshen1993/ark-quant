# 资金调拨层落地设计

> 状态：实施设计；以 `docs/体系/仓位与再平衡规则.md` 与 `docs/体系/交易执行规则.md` 为准，不新增投资规则。
> 日期：2026-07-21

## 目标

把已经确认的体系级资金调拨战术落为可重复计算、可审计的计划结果。它只处理顶层 A/B/C、A 内部股票/可转债/现金、现金池星型调拨和真实现金约束；不改股票或转债账户内的选标的、排序和订单规则。

## 方案选择

采用独立的纯规划器，再由现有计划 API 适配输出。

- 不直接改写旧 `rebalance.calc_targets` 并沿用旧 `stock/bond/changqian/cash_pool` 语义；该路径无法表达 B、C、`A_exec`、顶层软硬偏离和部分可执行方案。
- 不在本阶段重做股票/转债订单生成或页面交互；它们继续消费本次已批准且立即可执行的资金调入金额，后续单独接入。
- 不建立执行状态机、资金来源归因或跨计划待办。计划后真实成交、赎回和到账仍由下一次事实快照重新吸收。

## 输入与输出

规划器输入为：A/B/C 及 A 内部当前金额、现金池真实可转账现金、温度 `t`、检查类型（`monthly_contribution`、`quarterly`、`a_internal`、`b_recovery`、`ad_hoc`）、本次真实新增本金、B 的 QDII 单次真实申购上限、额度来源与核对时间、C 的申赎颗粒度、可转债有效候选数。

检查类型、真实新增本金和 B 的单次申购事实属于人发起本次计划时确认的上下文，和温度一起保存；不能由旧账户金额、历史低配或未来可能额度推断。缺少 B 的申购事实时，B 一律按不可买处理；缺少海外账户快照时，完整资金调拨计划停止生成。

规划器输出为结构化字典，至少包含：

- 顶层理想目标、当前金额、偏离、外侧带宽、完整半带宽方案与部分可执行方案；
- `A_current`、`Delta_A`、`Q_out`、`A_exec` 与 A 内部股票/可转债/现金目标；
- 可转债候选不足时的安全阀现金增量；若同日完整榜单不可用，则 A 内部调入状态为暂停，不能把候选数默认成 `20`；
- 每个对象的完整缺口、动作资格、立即可执行金额、未补足金额与原因；
- 只经过现金池的星型资金调拨动作，以及共享即时现金上限校验；
- 阻断性输入错误和人工复核提示。

所有金额均来自已成为事实的快照；未到账赎回、预计卖出所得和未来新增本金不得增加本次即时可用现金。

## 规则落实

1. 顶层目标使用 `A=70%-5%×clamp(t/50,0,1)`、`B=15%+5%×clamp(t/50,0,1)`、`C=15%`。
2. A 内部按三锚点分段线性映射；若顶层方案中 A 净调出，仅扣除该净调出形成 `A_exec`。A 净调入不预支未到账资金。
3. 月度检查只把真实新增本金和当前可用现金分给低配对象，绝不卖出老仓；季度/临时顶层检查只有严格越过“相对目标 10%、绝对 3 个百分点封顶”的外侧带宽，才按统一比例缩放进入半带宽。
4. B 不可申购时删除其调入，其他调入不扩容，高配调出按原比例缩小；没有可执行调入时不卖高配仓。
5. A 内部股票与可转债各自仅在完整净调整缺口达到 1,000 元后进入调拨检查。候选不足 20 只的可转债目标按安全阀缩减，缺口转入现金，不重新均分；缺少同日完整榜单时暂停 A 内部调入，不假设候选数。
6. 顶层与 A 内部共享现金池的即时可转账现金。现金不足时先按同层有效缺口比例分配；无法形成合规动作时再按目标偏离率排序。计划不建立待办。

## 集成边界

新规划器位于独立模块，`app/routers/plans.py` 只负责获取、校验输入和序列化结果。账户上下文增加检查类型、真实新增本金和 B 申购事实字段；当前 `/api/plan/transfer` 保留既有基础字段，同时新增结构化的体系级调拨字段；`/api/plan` 使用相同计算结果，避免两个接口各算一套规则。

账户内股票与可转债订单在本阶段只继续使用其当前账户资金与已存在的订单逻辑。对“调拨后预算”的完整衔接、订单取整、费用和页面展现属于下一实施任务，不能以此阻塞资金调拨层的正确落地。

## 验收

- 极低/中性/极高温度下顶层与 A 内部目标守恒。
- 月度新增本金不生成任何老仓卖出。
- 顶层未越带宽时季度检查不生成老仓卖出。
- 越带宽时半带宽方案统一缩放并守恒。
- B 受限时生成收支平衡的部分可执行方案，不向其他目标重分配。
- A 净调出正确缩减 `A_exec`；A 净调入不预支。
- 可转债候选不足时只增加现金目标。
- 所有即时调出合计不超过真实现金，所有调拨都经现金池。
- API 回归测试保持现有输入日期和策略数据安全停机语义。

## 明确不在本阶段

- 券商、基金或 QDII 自动申赎；
- 成交跟踪、跨日执行、资金来源归因或待办；
- 有知有行账本迁移、绩效计算；
- 股票/转债账户内选标的规则或正式转债候选升级；
- 新增投资参数或修改体系真源。
