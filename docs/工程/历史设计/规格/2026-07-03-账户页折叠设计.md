# 账户页手风琴重设计 — 2026-07-03

> 状态：历史设计，不是当前实现真源。

## 问题

上次清理把账户列表删了，导致页面变成"总览 + 两个大表格 + 三个卡片"的平铺堆叠，没有信息层级，用户打开页面不知道该看哪。

### 关键设计决策

1. **总资产：纯数字**。删除占比条和图例——列表行已有颜色+金额+占比。
2. **更新时间：账户级**。每个账户独立记录更新时间，在列表行展示。
3. **手风琴：同时只展开一个**。stock/cb 点行展开持仓编辑区，展开一个时其他自动折叠。
4. **简单账户：内联编辑**。点金额 → 变输入框 → 失焦自动保存。业界标准模式（Stripe/Vercel）。
5. **长钱/资金/海外无 `▸`**。视觉上区分"可展开"和"内联编辑"两种交互。
6. **行情自动加载**。打开账户页即拉取 stock + cb 现价（维持上次改动）。

### 交互细节

| 账户类型 | 展开方式 | 编辑方式 | 保存方式 |
|---|---|---|---|
| stock | 手风琴 `▸`/`▾` | 表格（股数编辑、新增行、删除行） | 手动点击"保存" |
| cb | 手风琴 `▸`/`▾` | 表格（张数编辑、新增行、删除行） | 手动点击"保存" |
| 长钱 | 无 | 内联编辑（点数字变输入框） | 失焦自动保存 |
| 资金 | 无 | 内联编辑 | 失焦自动保存 |
| 海外 | 无 | 内联编辑 | 失焦自动保存 |

### 数据流

- `load()` → 拉取 account snapshot + positions + quotes（并行），渲染列表
- 展开 stock/cb → 表格已预填充（数据在 Alpine state 中），行情已加载
- 编辑股数 → 实时重算市值和占比，按市值降序排列
- 点击"保存" → POST positions + POST snapshot，显示"已保存" 2 秒
- 内联编辑失焦 → POST snapshot（不带持仓），静默保存

### 更新时间数据来源

| 账户类型 | 更新于 | 数据来源 |
|---|---|---|
| stock/cb | 持仓最后保存日 | `GET /api/positions/{strategy}` 返回的 `position_date` |
| 长钱/资金/海外 | 最后修改日 | `GET /api/account/latest` 返回的 `snapshot_date` |

不新增 DB 字段，用已有数据推导。

### 边界情况

- **无数据**：`snap` 为 null 时，总资产显示 ¥0，列表行金额显示 "—"
- **持仓为空**：展开 stock/cb 时，表格区显示"暂无持仓"，现金输入框仍可编辑
- **行情加载失败**：现价列显示 "—"，市值和占比不计算
