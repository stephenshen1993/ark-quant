# 交易计划余额分项展示 — 2026-07-03

> 状态：历史设计，不是当前实现真源。

## 背景

交易计划产出后，用户看到"交易后余额"一个数字，但不知道：
- 卖出回笼了多少、买入了多少
- 调拨计划预留了多少转出资金
- 实际还能动用多少钱

需把余额拆成三个分项。

## 设计

### 余额明细组件

每个策略区（转债/股票），在订单卡片下方显示，出入金都三行全显：

```
┌─ 余额明细 ────────────────────────────────────────────────────────┐
│  账面余额         ¥14,900         │  账面余额         ¥5,000      │
│  待转出(调拨)     -¥14,810        │  待转入(调拨)    +¥14,810     │
│  实际可用              ¥90        │  实际可用        ¥19,810      │
│  ← 出金账户                      │  ← 入金账户                   │
└──────────────────────────────────────────────────────────────────┘
```

- 正 delta：标签"待转入(调拨)"，金额前加 `+`
- 负 delta：标签"待转出(调拨)"，金额前加 `-`
- delta = 0：隐藏该行

### 数据流

`POST /api/plan/{strategy}/size-orders` 返回的 `summary` 扩展三个字段：

| 字段 | 计算 |
|---|---|
| `book_balance` | `cash + sells - buys` |
| `transfer_delta` | 调拨计划中该账户的 delta（带符号），0 则不显示 |
| `cash_left` | `book_balance + transfer_delta` |

### 前端展示

订单卡片后面紧跟余额明细，用小号表格：

```html
<div class="mt-3 pt-3 border-t border-gray-100 text-xs">
  <div class="flex justify-between"><span class="text-gray-400">账面余额</span><span class="tabular-nums" x-text="fmtMoney(summary.book_balance)"></span></div>
  <div class="flex justify-between" x-show="summary.transfer_out > 0"><span class="text-gray-400">待转出(调拨)</span><span class="tabular-nums text-orange-500" x-text="'-¥' + summary.transfer_out.toLocaleString()"></span></div>
  <div class="flex justify-between font-medium"><span class="text-gray-400">实际可用</span><span class="tabular-nums" x-text="fmtMoney(summary.cash_left)"></span></div>
</div>
```
