# 01 当前账户状态 module 与持久化

> 状态：已完成（2026-08-08）
> 前置：无
> 后续：02 HTTP adapter 与计划生命周期

## 目标

建立逐账户“当前状态”真源，让现金、持仓、金额、版本与数据时间通过一个深 module 读取和更新，不再由页面或调用方拼接快照。

## 范围

- 新增当前账户状态 module 的读取、普通更新、确认不变和旧数据补录 interface。
- 当前版本按数据日期优先、同日版本优先选择。
- 证券账户现金与持仓保持同一版本并原子写入。
- 返回缺失、已记录、已确认空仓、零金额和估值不可用等明确状态。
- 为证券代码唯一性、非负有限数值和账户类型增加集中校验。
- 提供 `expected_version` 并检测过期写入。
- 保留并兼容既有历史数据，不删除记录。

## 不做

- 不改生产页面。
- 不定义 HTTP 文案或视觉结构。
- 不实现自动券商同步。

## 验收

- 后写入旧日期不替换当前状态。
- 缺失账户的旧数据补录只进入历史版本，不创建当前状态或 operational snapshot。
- 缺失不回退为零金额或空持仓。
- 证券账户任一写入失败时现金与持仓全部回滚。
- 同账户同证券代码只存在一条当前持仓。
- 过期版本更新被拒绝且不覆盖新状态。
- 单元测试通过 module interface 验证行为，不依赖内部 SQL 细节。
