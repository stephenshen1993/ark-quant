# 03 账户总览与单账户编辑界面

> 状态：已完成（2026-08-08）
> 前置：02 HTTP adapter 与计划生命周期
> 后续：04 迁移收口与回归验收

## 目标

把生产账户页从全局事实日批量录入改成逐账户当前数据总览与单账户编辑工作台，落实原型 A 的结构。

## 范围

- 导航使用“账户”，页面标题使用“账户数据”。
- 总览先显示逐账户就绪度，再展示现有组合与账户层级。
- 删除主流程中的全局日期选择器、roll-forward 草稿和全账户批量保存。
- 从总览进入独立单账户编辑视图。
- 证券账户打开即预填现金与全部当前持仓；金额账户打开即预填金额。
- 保存区展示变化摘要，并在“确认数据仍准确”与“保存账户数据”之间切换。
- 支持单只清仓、全部持仓清空确认、整账户清零确认、重复代码校验、保存成功留页、失败保留草稿和冲突重载。
- 行情缺失时保留原始数据编辑与保存能力。
- 桌面使用编辑区加 sticky 保存核对区；`390px` 使用单列纵向持仓记录。

## 不做

- 不复制 prototype switcher、状态选择器或内存假数据。
- 不新增账户历史浏览入口。
- 不改变组合与账户层级。

## 验收

- 首次打开已有账户不出现空白持仓表单。
- 缺失、零金额和已确认空仓三态文案与数值不同。
- 普通更新一次点击保存；全部持仓清空与整账户清零分别二次确认，清空持仓不得连带清空现金。
- 未保存修改离开时提醒。
- 保存成功留在当前账户并显示新数据时间和计划影响。
- `390px` 无横向滚动，所有输入、删除、添加、取消与主操作可访问。
