# AQ-UXR-2 — 事实日切换与保存必须保持同一数据身份

**What to build:** 让账户事实日成为加载和保存的同一数据身份：变更日期后读取对应日期的事实，加载、错误或未解决编辑期间不给保存通道，永不把旧日期账户行静默写入新日期。

**Blocked by:** AQ-UXR-1 — 账户加载失败不得冒充投资事实。

**Status:** completed（本地票据；GitHub 发布曾因集成权限 403 失败）

- [x] 日期变更会为新日期重新读取账户汇总、持仓与报价，并显示明确 loading/error 状态及重试。
- [x] 未保存编辑的日期切换有明确、可恢复门禁；不得静默丢弃、迁移或错误保存编辑值。
- [x] 新日期数据确认前以及保存进行中禁止提交；保存载荷与当前已加载事实日一致。
- [x] 保存成功后刷新账户事实与就绪度；失败保留输入并在表单附近显示可恢复错误。
- [x] 请求拦截回归测试覆盖旧行误写风险、加载/错误/dirty 保存门禁和重复保存防护。
