# AQ-UXR-1 — 账户加载失败不得冒充投资事实

**What to build:** 让使用者能可靠区分账户事实加载失败、真实空账户和已加载事实；任何关键账户请求失败时，页面不再宣称“事实已就绪”或有效零资产，并在页面内提供可用的重试入口。

**Blocked by:** None — can start immediately.

**Status:** completed（本地票据；GitHub 发布曾因集成权限 403 失败）

- [x] 对账户汇总、持仓和报价的非成功响应及网络失败，页面明确显示失败、隔离事实结论和资产数值，并可就地重试。
- [x] 真实空账户仍作为独立、非错误的状态呈现；不与加载失败混淆。
- [x] 重试后重新读取账户事实与计划事实就绪度；已加载成功事实不因短暂失败被伪造为零值。
- [x] 现有最高层账户 API、页面行为和真实浏览器闸门覆盖三类状态与可见重试行为。
