## 四、潜在风险与局限

### 1. 小盘风格集中

国内部分可转债和小市值合计占比较高，风格切换时可能长期跑输大盘，例如 2017 年、2021 年初。

评价：这是主动选择，不是缺陷。方案已明确将此列为“体系边界”，且经历过极端回撤，有心理准备。

### 2. 策略依赖外部

可转债和小市值策略来自“回测验证的版本”，依赖策略提供者的持续迭代。如果策略失效或提供者停止更新，需要及时发现。

建议：保持年度审视，关注策略相对基准的表现，但不因短期波动轻易调整。

### 3. 海外部分的汇率风险

海外长钱以美元等外币计价，人民币升值时会产生账面汇兑损失。

评价：这是分散化的代价，方案已明确接受。

### 4. 参数的历史依赖性

现金公式中的 20%、可转债公式中的 30%/0.4% 等参数，基于历史数据和经验设定。未来市场结构变化时，可能需要调整。

评价：任何量化系统都有此局限。方案保留了年度审视的迭代入口。

### 5. 风险溢价不等于每年兑现

SBBI 的风险溢价模型说明，承担更高风险的资产长期可能获得更高补偿，但这种补偿并不会线性、稳定、逐年兑现。小盘股溢价可能多年缺席，股票风险溢价可能伴随深度回撤，信用风险溢价也可能在违约周期中集中暴露。

建议：把风险溢价作为长期配置依据，而不是短期表现承诺。年度复盘应重点检查体系是否仍在正确承担预期风险，而不是只看某一年是否跑赢。
