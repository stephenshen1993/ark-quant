# Web 看板说明

> 用途：说明本地 Web 看板的启动方式、页面分工、数据来源和使用注意事项。看板是日常录入账户状态、查看策略榜单和生成执行计划的主入口。

## 启动

准备环境：

```bash
python3 -m venv .venv
source .venv/bin/activate
python3 -m pip install -r requirements.txt
```

启动看板：

```bash
python3 run_app.py
```

打开：

```text
http://127.0.0.1:8000
```

开发时也可以直接使用：

```bash
uvicorn app.main:app --host 127.0.0.1 --port 8000 --reload
```

## 页面分工

### 账户总览

账户总览用于查看整体资产结构和维护账户状态。

列表页展示：

- 总资产
- 快照日期
- 各账户金额、占比和持仓数量

详情页分账户维护：

- 广发账户：股票持仓、持仓资产、可用现金、总资产。
- 华泰账户：转债持仓、持仓资产、可用现金、总资产。
- 长钱账户：国内基金或长期安全垫总资产。
- 资金账户：现金池余额。
- 海外长钱：海外长期资产总资产。

股票和转债账户详情页会拉取报价，按持仓数量估算持仓资产，并在报价加载后按持仓市值排序。

### 本期计划

本期计划用于把体系级资金调拨和策略内部订单放在同一个页面查看。

页面包含：

- 缺失数据提醒。
- 适用开盘执行日。
- 资金调拨步骤。
- 转债订单。
- 股票订单。

计划页读取同一个 T 日的账户快照、全市场温度快照、可转债榜单/订单和股票榜单/订单。策略订单的口径是：基于 T 日收盘数据，生成 T+1 日开盘可执行计划。若任一输入缺失或日期不一致，页面会停止生成交易计划并提示需要更新的项目。国内再平衡公式见 `docs/system/investment_system.md`，账户口径见 `docs/system/accounting_model.md`。

### 榜单

榜单页用于查看策略候选池。

当前包含：

- 转债 Top 20
- 股票 Top 20
- 数据基准日选择
- Markdown 导出

榜单页展示的是策略候选结果，不等同于最终下单清单。最终执行应以本期计划和订单输出为准。

榜单页的日期口径同样是：基于 T 日收盘，适用 T+1 日开盘执行。

## 数据来源

| 页面 | 后端 API | 主要来源 |
| --- | --- | --- |
| 账户总览 | `/api/account/summary` | 账户上下文 + 各账户最新快照 |
| 账户历史 | `/api/account/history` | 账户级快照聚合历史 |
| 单账户保存 | `/api/account/{account_id}/snapshot` | 指定账户资产快照 |
| 持仓详情 | `/api/positions/{strategy}` | 数据库持仓快照 |
| 持仓报价 | `/api/positions/{strategy}/quotes` | 腾讯行情或策略数据封装 |
| 单个代码补全 | `/api/positions/{strategy}/quote` | 腾讯行情或策略数据封装 |
| 榜单日期 | `/api/rankings/{strategy}/dates` | 策略运行入库结果 |
| 榜单内容 | `/api/rankings/{strategy}/{data_date}` | 策略运行入库结果 |
| 本期计划 | `/api/plan` | 本地温度快照 + 同日账户聚合视图 + 同日订单 + 体系再平衡 |

`strategy` 当前取值为 `cb` 或 `stock`。

## 账户录入流程

1. 打开账户总览。
2. 确认账户快照日期；全市场温度由本期计划自动读取有知有行官网。
3. 进入广发账户，确认股票持仓，录入可用现金。
4. 进入华泰账户，确认转债持仓，录入可用现金。
5. 进入长钱账户、资金账户、海外长钱，录入对应金额。
6. 返回账户总览，检查总资产和占比。

股票和转债账户详情页输入可用现金后会保存对应账户快照；长钱、资金账户、海外长钱在列表内联编辑后也只保存各自账户。全市场温度保存为本地快照，生成计划时默认复用已保存快照；需要刷新时才访问有知有行官网。

## 持仓维护流程

股票和转债持仓支持在详情页维护：

- 修改已有持仓数量。
- 添加新持仓代码。
- 删除持仓行。
- 点击“保存持仓”写入当天持仓快照。

注意：

- 新增代码后会尝试自动补全名称和价格。
- 持仓表按实时估算市值降序排列。
- 股票数量单位为股。
- 转债数量单位为张。
- 实盘执行后必须及时更新持仓，否则下一次计划会基于旧持仓计算。

## 金额显示

默认币种为人民币，金额单位为元。

当前 UI 约定：

- 详情页、表格、订单使用 `¥` + 两位小数。
- 总览列表中的大额账户金额可使用 `¥xx.xx万`。
- 输入框使用 `¥` 前缀，用户只输入数字。
- 字段名不同时写“元”和数值后缀“元”。

详细口径见 `docs/system/accounting_model.md`。

## 常见问题

### 刷新页面后数据没了

账户快照需要保存到数据库。详情页金额输入会自动保存，列表页也可以点击“保存账户”确认一次。如果页面刷新后没有显示，先检查后端服务是否仍连接同一个本地数据库。

### 本期计划提示缺少数据

通常是以下原因之一：

- 还没有账户快照。
- 没有计划日期对应的可转债榜单或订单。
- 没有计划日期对应的股票榜单或订单。

先录入账户，再运行同一个 T 日的对应策略生成榜单和订单。

### 榜单和订单不一致

榜单是候选池，订单是结合当前持仓、现金和取整规则后的执行结果。实际操作以订单和本期计划为准。

### 页面金额和券商显示有差异

看板持仓资产依赖当前可得报价，券商可能使用不同刷新频率、昨收价、盘中价或四舍五入口径。可用现金以券商为准，持仓估值用于体系级决策和执行辅助。
